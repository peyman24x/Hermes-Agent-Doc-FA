## 🚀 اجرا

### روی سیستم لوکال (بدون نیاز به اینترنت و سرور)

فایل `index.html` را با دابل‌کلیک در هر مرورگری باز کنید. تمام.

### انتشار روی GitHub Pages

1. یک مخزن جدید بسازید (مثلاً `hermes-docs-fa`).
2. محتوای این پوشه را در آن push کنید:

   ```bash
   git init
   git add .
   git commit -m "مرجع فارسی مستندات Hermes Agent"
   git branch -M main
   git remote add origin https://github.com/<username>/hermes-docs-fa.git
   git push -u origin main
   ```

3. در تنظیمات مخزن: **Settings ← Pages ← Build and deployment** و گزینهٔ **Deploy from a branch**، شاخهٔ `main` و پوشهٔ `/ (root)` را انتخاب کنید.
4. پس از چند دقیقه سایت روی `https://<username>.github.io/hermes-docs-fa/` در دسترس است.

### انتشار روی Cloudflare Pages

1. وارد [داشبورد Cloudflare Pages](https://dash.cloudflare.com/?to=/:account/pages) شوید و **Create a project → Direct Upload** را بزنید (یا مخزن گیت را وصل کنید).
2. پوشهٔ `hermes-docs-fa` را آپلود کنید — بدون هیچ تنظیم بیلد (Framework preset: `None`، Build command: خالی، Output directory: `/`).
3. دامنهٔ اختصاصی هم از همان‌جا قابل اتصال است.

## 🔁 روند افزودن ترجمهٔ جدید (برای مشارکت‌کنندگان)

1. متن اصلی صفحه را از `_source/pages/` بردارید (تفکیک‌شده از `llms-full.txt` رسمی).
2. یک فایل HTML با قالب صفحات موجود بسازید — ساده‌ترین راه، کپی یکی از صفحات فعلی و جایگزینی محتواست. فقط این‌ها را تنظیم کنید:
   - `data-root` در تگ `<html>` (عمق نسبی نسبت به ریشه: `..` یا `../..`)
   - `<title>`، بردکرامب، لینک «نسخهٔ اصلی» و فوتر
   - لینک‌های قبلی/بعدی در `.pager`
3. در `assets/nav-data.js` پرچم `d` آن صفحه را از `0` به `1` تغییر دهید — سایدبار همهٔ صفحات، کاتالوگ صفحهٔ اصلی و نوار پیشرفت به‌طور خودکار به‌روز می‌شوند.

**اصول ترجمه:** وفاداری کامل به متن اصلی (هیچ بخشی حذف یا خلاصه نمی‌شود) · فارسی روان و ساده · دستورها و کدها بدون هیچ تغییری · لینک صفحات ترجمه‌نشده به نسخهٔ انگلیسی رسمی.
