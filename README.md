<a id="about"></a>
## 🎯 دربارهٔ پروژه

این پروژه، **مرجع فارسیِ** مستندات رسمی Hermes Agent است: تمام ۲۰۷ صفحهٔ مستندات در ۹ بخش موضوعی، با همان ترتیب و ساختار سایت اصلی، به فارسیِ روان و فنی ترجمه می‌شود — بدون خلاصه‌سازی، با دستورها و کدهای دست‌نخورده در جعبه‌های قابل‌کپی.

| | |
|:---|:---|
| 📚 **پوشش** | هر ۲۰۷ صفحهٔ مستندات رسمی — از شروع کار تا مرجع توسعه‌دهنده |
| 🌍 **همین حالا قابل استفاده** | هم آنلاین، هم آفلاین روی سیستم شما |
| ⚡ **نیازها** | هیچ؛ فقط یک مرورگر (نه سرور، نه بیلد، نه نصب) |
| 🔄 **پیشرفت زنده** | نوار پیشرفت خودکار در [صفحهٔ اصلی سایت](https://doc.hermes.peyman24x.ir) |

> ⚠️ ترجمه‌ای **غیررسمی** برای جامعهٔ فارسی‌زبان است؛ برای مرجع همیشه‌به‌روز، [متن اصلی لاتین](https://hermes-agent.nousresearch.com/docs/) معتبر است.

<a id="features"></a>
## ✨ امکانات کلیدی

| قابلیت | توضیح |
|:---|:---|
| 🔤 **ترجمهٔ وفادار و روان** | هیچ بخشی حذف یا خلاصه نمی‌شود؛ اصطلاح فنی = معادل فارسی + اصل لاتین در اولین کاربرد |
| 📋 **کپی یک‌کلیکی دستورها** | همهٔ کدها بدون هیچ تغییری، چپ‌به‌راست و ایزوله، با دکمهٔ کپی |
| ↔️ **راست‌چین هوشمند** | متن فارسی RTL؛ کد، نام فایل و مقادیر خودکار LTR |
| 🌙 **حالت شب/روز و چاپ** | با ذخیرهٔ انتخاب کاربر + استایل اختصاصی خروجی PDF |
| 🧭 **ناوبری حرفه‌ای** | سایدبار داینامیک با هایلایت صفحهٔ فعال، لینک قبلی/بعدی، جستجوی فهرست |
| 🔗 **بدون لینک مرده** | صفحاتِ هنوز-ترجمه‌نشده مستقیم به نسخهٔ انگلیسی رسمی می‌روند |

## 🚀 شروع سریع

سه راه استفاده — هر سه یک نتیجه:

| روش | مناسب برای | چطور |
|:---|:---|:---|
| 💻 **لوکال** | مطالعهٔ آفلاین | فایل `index.html` را **دابل‌کلیک** کنید. تمام! |

| ☁️ **Cloudflare Pages** | انتشار با دامنهٔ اختصاصی | راهنما در همان فایل — بدون هیچ تنظیم بیلد |

> 💬 می‌خواهید در ترجمه مشارکت کنید؟ روند ۳مرحله‌ای افزودن صفحهٔ جدید در [DEPLOYMENT.md](DEPLOYMENT.md) و جزئیات کامل (چک‌لیست ۷ مرحله‌ای، واژه‌نامهٔ مصطلحات، اولویت‌ها) در [WORKLOG.md](WORKLOG.md) آمده است.
