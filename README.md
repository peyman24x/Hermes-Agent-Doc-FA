# مرجع فارسی Hermes Agent 🪽

ترجمهٔ فارسی، حرفه‌ای و کاملِ مستندات رسمی [Hermes Agent](https://hermes-agent.nousresearch.com/docs/) — آمادهٔ انتشار روی **GitHub Pages** یا **Cloudflare Pages** و قابل استفادهٔ کاملاً آفلاین روی سیستم لوکال.

## اجرا

- **لوکال:** کافی است `index.html` را با دابل‌کلیک در مرورگر باز کنید — بدون نیاز به سرور.
- **انتشار:** کل این پوشه را در یک مخزن گیت بگذارید و GitHub Pages (یا Cloudflare Pages) را روی شاخهٔ اصلی فعال کنید. سایت کاملاً استاتیک است و به بیلد یا سرور نیاز ندارد.

## ساختار پروژه

```
hermes-docs-fa/
├── index.html              ← صفحهٔ اصلی: کاتالوگ کامل + نوار پیشرفت ترجمه
├── assets/
│   ├── style.css           ← طراحی مشترک (راست‌چین، حالت شب/روز، چاپ)
│   ├── main.js             ← اسکریپت مشترک (کپی کد، سایدبار، تم، موبایل)
│   └── nav-data.js         ← دادهٔ ناوبری: عنوان فارسی همهٔ ۲۰۷ صفحه + وضعیت ترجمه
├── getting-started/        ← بخش شروع کار (نصب، شروع سریع، …)
├── user-guide/             ← کار با Hermes (داکر، …) + features/ + messaging/
├── integrations/  guides/  developer-guide/  reference/   ← ساختار مطابق سایت اصلی
└── _source/                ← متن اصلی دانلودشده (llms-full) برای مرجع ترجمه
```

## روند ترجمه (برای ادامهٔ کار)

1. متن اصلی هر صفحه در `_source/pages/` موجود است (تفکیک‌شده از `llms-full.txt` سایت رسمی).
2. صفحهٔ HTML با قالب موجود ساخته می‌شود (نمونه: `getting-started/installation.html`).
3. در `assets/nav-data.js` مقدار `d` آن صفحه از `0` به `1` تغییر می‌کند — سایدبار، کاتالوگ و نوار پیشرفت صفحهٔ اصلی به‌طور خودکار به‌روز می‌شوند.

## اصول ترجمه

- متن فارسی روان و ساده؛ وفاداری کامل به متن اصلی (هیچ بخشی حذف یا خلاصه نمی‌شود).
- ساختار عناوین و بخش‌بندی عیناً مطابق سایت اصلی.
- دستورها، کد، نام فایل‌ها و مقادیر فنی **بدون هیچ تغییری** در جعبه‌های کد چپ‌به‌راست با دکمهٔ کپی.
- اصطلاحات فنی با معادل فارسی روان + اصطلاح لاتین در اولین کاربرد.
- لینک صفحاتی که هنوز ترجمه نشده‌اند به نسخهٔ انگلیسیِ رسمی اشاره می‌کند تا هیچ لینکی مرده نباشد.

> ⚠️ این یک ترجمهٔ غیررسمی برای جامعهٔ فارسی‌زبان است؛ برای مرجع همیشه‌به‌روز، متن اصلی لاتین معتبر است.
