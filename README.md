## ✨ امکانات

- 📚 **پوشش کامل** — هر ۲۰۷ صفحهٔ مستندات رسمی در ۹ بخش موضوعی، با ترتیب و ساختار عیناً مطابق سایت اصلی
- 🔤 **ترجمهٔ وفادار و روان** — بدون خلاصه‌سازی یا حذف؛ اصطلاح فنی = معادل فارسی + اصل لاتین در اولین کاربرد
- 📋 **جعبه‌های کد قابل‌کپی** — همهٔ دستورها بدون هیچ تغییری، چپ‌به‌راست و با دکمهٔ کپی یک‌کلیکی
- ↔️ **راست‌چین کامل** — متن فارسی RTL؛ کد، نام فایل‌ها و مقادیر به‌صورت ایزوله LTR
- 🌙 **حالت شب/روز** با ذخیرهٔ انتخاب کاربر + استایل اختصاصی چاپ/PDF
- 🧭 **ناوبری هوشمند** — سایدبار داینامیک با هایلایت صفحهٔ فعال، فهرست پیشرفت زندهٔ ترجمه، لینک قبلی/بعدی
- 🔗 **بدون لینک مرده** — صفحات هنوز-ترجمه‌نشده مستقیم به نسخهٔ انگلیسی رسمی لینک می‌شوند
- ⚡ **کاملاً استاتیک** — نه بیلد، نه سرور، نه وابستگی؛ HTML/CSS/JS خالص
