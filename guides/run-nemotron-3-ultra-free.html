اجرای رایگان Nemotron 3 Ultra در Hermes Agent

‏Nous Research به ائتلاف Nemotron از آزمایشگاه‌های پیشروی AI راه یافته که با NVIDIA روی پیشبرد مدل‌های بنیادی open frontier کار می‌کنند. به افتخار این اتفاق، با Nebius شراکت کردیم تا Nemotron 3 Ultra را برای دو هفته ‏(‏۴ تا ۱۸ ژوئن) روی Nous Portal رایگان کنیم. برای همین امروز امتحانش کنید، دستورالعمل زیر را دنبال کنید.

📌

پیشنهاد محدود
tier ی nvidia/nemotron-3-ultra:free از ‏۴ تا ۱۸ ژوئن در دسترس است. برچسب :free است که آن را روی طرح بدون‌هزینه نگه می‌دارد — دقیقاً همان گونه را بردارید.

هر نصبی که fits تان است بردارید. برنامهٔ دسکتاپ ساده‌ترین است — بدون نیاز به ترمینال. اگر اهل ترمینال هستید، نصب خط فرمانی درست پایین‌ترش است.

۱ گزینهٔ A — برنامهٔ دسکتاپ ‏(توصیه‌شده)

ساده‌ترین مسیر: نصب‌کنندهٔ یک‌کلیکی با راه‌اندازی هدایت‌شده و کلیکی. بدون ترمینال.

۱. دانلود و نصب

نصب‌کنندهٔ Hermes Desktop را برای macOS یا Windows دانلود و باز کنید. در اولین اجرا خودش راه‌اندازی‌اش را کامل می‌کند ‏(معمولاً زیر یک دقیقه).

۲. اتصال Nous Portal

وقتی برنامه باز شد صفحهٔ «Let's get you set up» را می‌بینید. روی Nous Portal کلیک کنید ‏(با نشان Recommended). مرورگرتان باز می‌شود — یک حساب Nous Portal بسازید ‏(یا وارد شوید)، طرح Free را انتخاب و به هرمس دسترسی بدهید. برنامه خودکار وصل می‌شود.

۳. انتخاب مدل رایگان Nemotron 3 Ultra

بعد از اتصال، برنامه کارت Default model را نشان می‌دهد. روی Change کلیک کنید، عبارت nemotron 3 ultra را جستجو و گونه‌ای را انتخاب کنید که نشان Free tier دارد:

nvidia/nemotron-3-ultra:free

برچسب :free همان چیزی است که آن را روی tier بدون‌هزینه نگه می‌دارد — همان گونه را بردارید.

۴. شروع گفتگو

روی Start chatting کلیک کنید. تمام — دارید رایگان با Nemotron 3 Ultra حرف می‌زنید.

۲ گزینهٔ B — خط فرمان

ترمینال را ترجیح می‌دهید؟

۱. نصب Hermes Agent

روی macOS/Linux/WSL2/Android اجرا کنید:

curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

روی Windows:

iex (irm https://hermes-agent.nousresearch.com/install.ps1)

ترجیح می‌دهید اول مرورش کنید؟ install.sh را دانلود، بازبینی و بعد اجرا کنید.

بعد از پایان، شل تان را دوباره بار کنید:

source ~/.bashrc   # or source ~/.zshrc

۲. اجرای Quick Setup

hermes setup

گزینهٔ Quick Setup را انتخاب کنید. هرمس یک تب مرورگر باز می‌کند و منتظر می‌ماند شما مراحل بعد را تمام کنید.

۳. ساخت حساب Nous Portal

در مرورگر یک حساب Nous Portal بسازید ‏(یا وارد شوید) و طرح Free را بردارید.

۴. اتصال حساب

وقتی برای اتصال حسابتان به Hermes Agent پرسید، روی Connect کلیک کنید. بعد از لینک شدن تأییدیه می‌بینید.

۵. انتخاب مدل رایگان Nemotron 3 Ultra

به ترمینال برگردید. از فهرست مدل‌ها این را انتخاب کنید:

nvidia/nemotron-3-ultra:free

برچسب :free همان چیزی است که آن را روی tier بدون‌هزینه نگه می‌دارد؛ پس حتماً همان گونه را بردارید.

۶. شروع گفتگو

بقیهٔ مراحل Quick Setup را کامل کنید و بعد اجرا کنید:

hermes

تمام — دارید رایگان با Nemotron 3 Ultra حرف می‌زنید.

۳ سوئیچ بعداً به آن

قبلاً با مدل دیگری راه‌اندازی کرده‌اید؟

  • برنامهٔ دسکتاپ: انتخاب‌گر مدل را باز کنید، nemotron 3 ultra را جستجو و گونهٔ Free tier را انتخاب کنید.
  • CLI / TUI: هر وقت خواستید داخل نشست با ‎/model nvidia/nemotron-3-ultra:free‎ سوئیچ کنید یا ‎/model‎ را اجرا کنید تا انتخاب‌گر باز شود و از فهرست بردارید.

۴ عیب‌یابی

  • مدل در فهرست دیده نمی‌شود؟مطمئن شوید اتصال Nous Portal را کامل کرده‌اید و روی طرح Free هستید. در CLI فرمان hermes portal info تأیید می‌کند وارد شده‌اید و از مسیر Nous عبور می‌کنید.
  • گونهٔ اشتباه را برداشتید؟دوباره nvidia/nemotron-3-ultra:free را انتخاب کنید — پسوند :free برای ماندن روی tier بدون‌هزینه الزامی است.
  • مرورگر باز نشد / روی host راه‌دور هستید ‏(CLI)؟راه‌حل‌های port-forwarding را در OAuth روی SSH / Host های راه‌دور ببینید.

۵ ببینید نیز

  • برنامهٔ دسکتاپ — برنامهٔ بومی یک‌کلیکی ‏(macOS، ‏Windows، ‏Linux)
  • اجرای Hermes Agent با Nous Portal — مرور کامل Portal: مدل‌ها، Tool Gateway و تأیید
  • یکپارچه‌سازی Nous Portal — داخل اشتراک چه چیزی هست
  • شروع سریع — از نصب تا گفتگو زیر ۵ دقیقه
