استفاده از حالت صوتی

این راهنما همراهِ عملیِ مرجع قابلیت حالت صوتی است.

اگر صفحهٔ قابلیت توضیح می‌دهد حالت صوتی چه‌کارهایی می‌کند، این راهنما نشان می‌دهد چطور واقعاً خوب از آن استفاده کنید.

💡

Nous Portal هم LLM و هم TTS را با یک OAuth پوشش می‌دهد — حالت صوتی سرتاسری کار می‌کند بدون هیچ اعتبارنامهٔ اضافه.

۱ حالت صوتی برای چه چیزی مناسب است

حالت صوتی مخصوصاً وقتی مفید است که:

  • گردش‌کار CLI بدون‌دست می‌خواهید
  • پاسخ‌های گفتاری در تلگرام یا دیسکورد می‌خواهید
  • می‌خواهید هرمس برای گفتگوی زنده در یک کانال صوتی دیسکورد بنشیند
  • وقتی راه می‌روید به‌جای تایپ‌کردن، ثبت سریع ایده، دیباگ یا رفت‌وبرگشت می‌خواهید

۲ راه‌اندازی حالت صوتی‌تان را انتخاب کنید

در هرمس واقعاً سه تجربهٔ صوتی متفاوت وجود دارد.

حالتبهترین کاربردپلتفرم
حلقهٔ میکروفون تعاملیاستفادهٔ شخصی بدون‌دست هنگام کدنویسی یا تحقیقCLI
پاسخ‌های صوتی در چتپاسخ‌های گفتاری در کنار پیام‌رسانی عادیتلگرام، دیسکورد
بات کانال صوتی زندهگفتگوی زندهٔ گروهی یا شخصی در یک VCکانال‌های صوتی دیسکورد

یک مسیر خوب:

  1. اول متن را راه بیندازید
  2. دوم پاسخ‌های صوتی را فعال کنید
  3. آخر — اگر تجربهٔ کامل را می‌خواهید — سراغ کانال‌های صوتی دیسکورد بروید

۳ گام ۱: اول مطمئن شوید هرمس عادی کار می‌کند

قبل از دست‌زدن به حالت صوتی، مطمئن شوید که:

  • هرمس بالا می‌آید
  • ارائه‌دهندهٔ شما پیکربندی شده
  • ایجنت می‌تواند به پرامپت‌های متنی به‌طور عادی جواب بدهد
hermes

چیزی ساده بپرسید:

What tools do you have available?

اگر این هنوز محکم نیست، اول حالت متنی را درست کنید.

۴ گام ۲: اکستراهای درست را نصب کنید

میکروفون و پخش CLI

cd ~/.hermes/hermes-agent && uv pip install -e ".[voice]"

پلتفرم‌های پیام‌رسانی

cd ~/.hermes/hermes-agent && uv pip install -e ".[messaging]"

TTS پریمیوم ElevenLabs

cd ~/.hermes/hermes-agent && uv pip install -e ".[tts-premium]"

NeuTTS محلی (اختیاری)

python -m pip install -U neutts[all]

همه‌چیز

cd ~/.hermes/hermes-agent && uv pip install -e ".[all]"

۵ گام ۳: نصب وابستگی‌های سیستمی

macOS

brew install portaudio ffmpeg opus
brew install espeak-ng

Ubuntu / Debian

sudo apt install portaudio19-dev ffmpeg libopus0
sudo apt install espeak-ng

چرا این‌ها مهم‌اند:

  • portaudio ← ورودی میکروفون / پخش برای حالت صوتی CLI
  • ffmpeg ← تبدیل صوت برای TTS و تحویل پیام‌رسانی
  • opus ← پشتیبانی کدک صوتی دیسکورد
  • espeak-ng ← بک‌اند phonemizer برای NeuTTS

۶ گام ۴: انتخاب ارائه‌دهندگان STT و TTS

هرمس هم پشتهٔ گفتار محلی و هم ابری را پشتیبانی می‌کند.

ساده‌ترین / ارزان‌ترین راه‌اندازی

از STT محلی و Edge TTS رایگان استفاده کنید:

  • ارائه‌دهندهٔ STT: local
  • ارائه‌دهندهٔ TTS: edge

این معمولاً بهترین نقطهٔ شروع است.

نمونهٔ فایل محیطی

به ~/.hermes/.env اضافه کنید:

# گزینه‌های STT ابری (local به کلید نیازی ندارد)
GROQ_API_KEY=***
VOICE_TOOLS_OPENAI_KEY=***

# TTS پریمیوم (اختیاری)
ELEVENLABS_API_KEY=***

توصیه‌های ارائه‌دهنده

تبدیل گفتار به متن

  • local ← بهترین پیش‌فرض برای حریم خصوصی و استفادهٔ بدون‌هزینه
  • groq ← رونویسی ابری بسیار سریع
  • openai ← پشتیبان پولی خوب

تبدیل متن به گفتار

  • edge ← رایگان و برای بیشتر کاربران کافی
  • neutts ← TTS محلی/روی‌دستگاه رایگان
  • elevenlabs ← بهترین کیفیت
  • openai ← حدوسط خوب
  • mistral ← چندزبانه، Opus بومی

اگر از hermes setup استفاده می‌کنید

اگر در جادوگر راه‌اندازی NeuTTS را انتخاب کنید، هرمس چک می‌کند neutts از قبل نصب هست یا نه. اگر نباشد، جادوگر به شما می‌گوید NeuTTS به پکیج پایتونیِ neutts و پکیج سیستمیِ espeak-ng نیاز دارد، پیشنهاد می‌دهد خودش نصب‌شان کند، espeak-ng را با مدیر پکیج پلتفرم‌تان نصب می‌کند و بعد این را اجرا می‌کند:

python -m pip install -U neutts[all]

اگر آن نصب را رد کنید یا شکست بخورد، جادوگر به Edge TTS برمی‌گردد.

۷ گام ۵: پیکربندی پیشنهادی

voice:
  record_key: "ctrl+b"
  submit_mode: "direct"  # در TUI: direct | draft
  max_recording_seconds: 120
  auto_tts: false
  beep_enabled: true
  silence_threshold: 200
  silence_duration: 3.0

stt:
  provider: "local"
  local:
    model: "base"

tts:
  provider: "edge"
  edge:
    voice: "en-US-AriaNeural"

این یک پیش‌فرض محافظه‌کارانهٔ خوب برای بیشتر آدم‌هاست.

در TUI، voice.submit_mode کنترل می‌کند بعد از رونویسی چه اتفاقی بیفتد:

  • direct (پیش‌فرض) رونویسی را بلافاصله ارسال می‌کند.
  • draft رونویسی را در ادیتور می‌گذارد تا قبل از زدن Enter بتوانید ویرایش یا لغوش کنید.

برای پیش‌نویس‌های صوتیِ قابل‌ویرایش، این را ست کنید:

voice:
  submit_mode: "draft"

اگر به‌جایش TTS محلی می‌خواهید، بلوک tts را به این تغییر دهید:

tts:
  provider: "neutts"
  neutts:
    ref_audio: ''
    ref_text: ''
    model: neuphonic/neutts-air-q4-gguf
    device: cpu

۸ حالت استفاده ۱: حالت صوتی CLI

۹ روشنش کنید

هرمس را اجرا کنید:

hermes

داخل CLI:

/voice on

گردش ضبط

کلید پیش‌فرض:

  • Ctrl+B

گردش‌کار:

  1. Ctrl+B را بزنید
  2. حرف بزنید
  3. صبر کنید تشخیص سکوت ضبط را خودکار متوقف کند
  4. هرمس رونویسی می‌کند و پاسخ می‌دهد
  5. اگر TTS روشن باشد، جواب را با صدا می‌گوید
  6. حلقه می‌تواند برای استفادهٔ پیوسته خودکار از نو شروع شود

فرمان‌های مفید

/voice
/voice on
/voice off
/voice tts
/voice status

گردش‌کارهای خوب CLI

دیباگ سرِپایی

بگویید:

I keep getting a docker permission error. Help me debug it.

بعد بدون‌دست ادامه دهید:

  • «خطای آخر را دوباره بخوان»
  • «علت ریشه را با اصطلاحات ساده‌تر توضیح بده»
  • «حالا فیکس دقیق را بده»

تحقیق / طوفان فکری

عالی برای:

  • راه رفتن هنگام فکر کردن
  • املا کردن ایده‌های نیمه‌شکل
  • خواستن از هرمس که افکارتان را بلادرنگ ساختار بدهد

دسترس‌پذیری / نشست‌های کم‌تایپ

اگر تایپ‌کردن ناخوشایند است، حالت صوتی یکی از سریع‌ترین راه‌ها برای ماندن در حلقهٔ کامل هرمس است.

۱۰ تنظیم رفتار CLI

آستانهٔ سکوت

اگر هرمس خیلی تند شروع/متوقف می‌شود، تنظیمش کنید:

voice:
  silence_threshold: 250

آستانهٔ بالاتر = حساسیت کمتر.

مدت سکوت

اگر بین جمله‌ها زیادی مکث می‌کنید، بیشترش کنید:

voice:
  silence_duration: 4.0

کلید ضبط

اگر Ctrl+B با ترمینال یا عادت‌های tmux شما تداخل دارد:

voice:
  record_key: "ctrl+space"

۱۱ حالت استفاده ۲: پاسخ‌های صوتی در تلگرام یا دیسکورد

این حالت ساده‌تر از کانال‌های صوتی کامل است.

هرمس یک بات چت عادی می‌ماند ولی می‌تواند پاسخ‌ها را با صدا بگوید.

اجرای گیت‌وی

hermes gateway

روشن‌کردن پاسخ‌های صوتی

داخل تلگرام یا دیسکورد:

/voice on

یا

/voice tts

حالت‌ها

حالتمعنی
offفقط متن
voice_onlyفقط وقتی کاربر پیام صوتی فرستاده حرف می‌زند
allهر پاسخی را با صدا می‌گوید

کی از کدام حالت استفاده کنیم

  • /voice on اگر پاسخ گفتاری فقط برای پیام‌های شروع‌شده با صدا می‌خواهید
  • /voice tts اگر همهٔ وقت یک دستیار کاملاً گفتاری می‌خواهید

گردش‌کارهای خوب پیام‌رسانی

دستیار تلگرام روی گوشی‌تان

استفاده کنید وقتی:

  • از سیستم‌تان دورید
  • می‌خواهید پیام صوتی بفرستید و جواب‌های گفتاری سریع بگیرید
  • می‌خواهید هرمس مثل یک دستیار تحقیق یا عملیات قابل‌حمل عمل کند

DMهای دیسکورد با خروجی گفتاری

مفید وقتی تعامل خصوصی بدون رفتار منشنِ کانال سرور می‌خواهید.

۱۲ حالت استفاده ۳: کانال‌های صوتی دیسکورد

این پیشرفته‌ترین حالت است.

هرمس به یک VC دیسکورد می‌رود، به گفتار کاربر گوش می‌دهد، آن را رونویسی می‌کند، خط لولهٔ عادی ایجنت را اجرا می‌کند و پاسخ‌ها را داخل کانال با صدا برمی‌گرداند.

۱۳ مجوزهای موردنیاز دیسکورد

علاوه بر راه‌اندازی عادی بات متنی، مطمئن شوید بات این‌ها را دارد:

  • Connect
  • Speak
  • ترجیحاً Use Voice Activity

همچنین intent های ممتاز را در Developer Portal فعال کنید:

  • Presence Intent
  • Server Members Intent
  • Message Content Intent

۱۴ عضویت و خروج

در یک کانال متنی دیسکورد که بات حاضر است:

/voice join
/voice leave
/voice status

وقتی عضو شد چه اتفاقی می‌افتد

  • کاربران در VC حرف می‌زنند
  • هرمس مرزهای گفتار را تشخیص می‌دهد
  • رونوشت‌ها در کانال متنی مرتبط پست می‌شوند
  • هرمس با متن و صدا پاسخ می‌دهد
  • کانال متنی همان جایی است که /voice join در آن صادر شده

بهترین شیوه‌ها برای استفاده از VC دیسکورد

  • DISCORD_ALLOWED_USERS را محدود نگه دارید
  • اول از یک کانال مخصوص بات/تست استفاده کنید
  • قبل از امتحان‌کردن حالت VC مطمئن شوید STT و TTS در حالت صوتیِ چت متنیِ عادی کار می‌کنند

۱۵ توصیه‌های کیفیت صدا

راه‌اندازی با بهترین کیفیت

  • STT: large-v3 محلی یا whisper-large-v3 روی Groq
  • TTS: ElevenLabs

راه‌اندازی با بهترین سرعت / راحتی

  • STT: base محلی یا Groq
  • TTS: Edge

راه‌اندازی کاملاً بدون‌هزینه

  • STT: محلی
  • TTS: Edge

۱۶ خرابی‌های رایج

«دستگاه صوتی پیدا نشد»

portaudio را نصب کنید.

«بات می‌رود داخل ولی چیزی نمی‌شنود»

چک کنید:

  • شناسهٔ کاربر دیسکوردتان در DISCORD_ALLOWED_USERS باشد
  • میوت نباشید
  • intent های ممتاز فعال باشند
  • بات مجوزهای Connect/Speak داشته باشد

«رونویسی می‌کند ولی حرف نمی‌زند»

چک کنید:

  • پیکربندی ارائه‌دهندهٔ TTS
  • کلید API / سهمیهٔ ElevenLabs یا OpenAI
  • نصب ffmpeg برای مسیرهای تبدیل Edge

«Whisper خروجی نامفهوم می‌دهد»

امتحان کنید:

  • محیط ساکت‌تر
  • silence_threshold بالاتر
  • ارائه‌دهنده/مدل STT متفاوت
  • گفته‌های کوتاه‌تر و واضح‌تر

«در DMها کار می‌کند ولی در کانال‌های سرور نه»

این اغلب سیاست منشن است.

به‌طور پیش‌فرض، بات در کانال‌های متنی سرور دیسکورد به یک @mention نیاز دارد مگر اینکه چیز دیگری پیکربندی شده باشد.

۱۷ راه‌اندازی پیشنهادی هفتهٔ اول

اگر کوتاه‌ترین مسیر تا موفقیت را می‌خواهید:

  1. هرمس متنی را راه بیندازید
  2. hermes setup tts را اجرا کنید تا پشتیبانی صوتی فعال شود
  3. از حالت صوتی CLI با STT محلی + Edge TTS استفاده کنید
  4. بعد /voice on را در تلگرام یا دیسکورد فعال کنید
  5. فقط بعد از آن، حالت VC دیسکورد را امتحان کنید

این توالی سطح دیباگ را کوچک نگه می‌دارد.
