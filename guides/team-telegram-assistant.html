راه‌اندازی دستیار تیمی تلگرام

این آموزش راه‌اندازی باتی تلگرامی با موتور Hermes Agent را قدم‌به‌قدم نشان می‌دهد که چند عضو تیم می‌توانند استفاده کنند. آخرِ کار تیم یک دستیار AI مشترک خواهد داشت که می‌تواند برای کمک دربارهٔ کد، تحقیق، مدیریت سیستم و هر چیز دیگری پیامش بدهند — با احراز هویت per-کاربر.

۱ چه چیزی می‌سازیم

باتی تلگرامی که:

  • هر عضو مجاز تیم می‌تواند برای کمک DM بدهد — بازبینی کد، تحقیق، فرمان‌های شل، عیب‌یابی
  • روی سرور شما اجرا می‌شود با دسترسی کامل به ابزارها — ترمینال، ویرایش فایل، جستجوی وب، اجرای کد
  • نشست‌های per-کاربر — هر نفر زمینهٔ گفتگوی خودش را دارد
  • پیش‌فرض امن — فقط کاربران تأییدشده می‌توانند تعامل کنند، با دو روش احراز
  • وظایف زمان‌بندی‌شده — استندآپ‌های روزانه، چک سلامت و یادآوری‌ها که به کانال تیم تحویل می‌شوند

پیش‌نیازها

قبل از شروع مطمئن شوید:

  • Hermes Agent روی سرور یا VPS نصب شده ‏(نه لپ‌تاپ شما — بات باید همیشه روشن بماند). اگر هنوز نصب نکرده‌اید راهنمای نصب را دنبال کنید.
  • یک حساب تلگرام برای خودتان ‏(مالک بات)
  • یک ارائه‌دهندهٔ LLM پیکربندی‌شده — حداقل یک کلید API برای OpenAI، ‏Anthropic یا ارائه‌دهندهٔ پشتیبانی‌شدهٔ دیگر در ~/.hermes/.env
💡

یک VPS پنج‌دلاری‌در-ماه برای اجرای گیت‌وی به‌قدر کافی است. خود هرمس سبک است — فراخوانی‌های API ی LLM است که هزینه دارد و آن‌ها راه‌دور اتفاق می‌افتند.

۲ گام ۱: ساخت بات تلگرام

هر بات تلگرامی از @BotFather شروع می‌شود — بات رسمی تلگرام برای ساخت بات.

  1. تلگرام را باز کنید و عبارت ‎@BotFather‎ را جستجو کنید یا به t.me/BotFather بروید
  2. ‏/newbot را بفرستید — BotFather دو چیز می‌پرسد:
    • نام نمایشی — چیزی که کاربران می‌بینند ‏(مثل Team Hermes Assistant)
    • نام کاربری — باید به bot ختم شود ‏(مثل myteam_hermes_bot)
  3. توکن بات را کپی کنید — BotFather چنین چیزی پاسخ می‌دهد: 
    Use this token to access the HTTP API:
7123456789:AAH1bGciOiJSUzI1NiIsInR5cCI6Ikp...
    این توکن را نگه دارید — در گام بعد لازمش دارید.
  4. توضیح ست کنید ‏(اختیاری ولی توصیه‌شده): 
    /setdescription
    بات را انتخاب و چیزی شبیه این وارد کنید: 
    Team AI assistant powered by Hermes Agent. DM me for help with code, research, debugging, and more.
  5. فرمان‌های بات را ست کنید ‏(اختیاری — منوی فرمان به کاربران می‌دهد): 
    /setcommands
    بات را انتخاب و این را بچسبانید: 
    new - Start a fresh conversation
model - Show or change the AI model
status - Show session info
help - Show available commands
stop - Stop the current task
⚠️

توکن بات را محرمانه نگه دارید. هر کسی که توکن را داشته باشد کنترل بات را در دست می‌گیرد. اگر لو رفت، با ‎/revoke‎ در BotFather توکن جدید بسازید.

۳ گام ۲: پیکربندی گیت‌وی

دو گزینه دارید: ویزارد راه‌اندازی تعاملی ‏(توصیه‌شده) یا پیکربندی دستی.

گزینهٔ A: راه‌اندازی تعاملی ‏(توصیه‌شده)

hermes gateway setup

همه‌چیز را با انتخاب با کلیدهای جهت‌دار قدم‌به‌قدم می‌برد. گزینهٔ Telegram را بردارید، توکن بات را بچسبانید و شناسهٔ کاربر تان را وقتی پرسید وارد کنید.

گزینهٔ B: پیکربندی دستی

این خطوط را به ~/.hermes/.env اضافه کنید:

# Telegram bot token from BotFather
TELEGRAM_BOT_TOKEN=7123456789:AAH1bGciOiJSUzI1NiIsInR5cCI6Ikp...

# Your Telegram user ID (numeric)
TELEGRAM_ALLOWED_USERS=123456789

پیدا کردن شناسهٔ کاربری

شناسهٔ کاربری تلگرام شما یک مقدار عددی است ‏(نه نام کاربری). برای پیدا کردنش:

  1. در تلگرام به @userinfobot پیام بدهید
  2. فوراً شناسهٔ عددی شما را پاسخ می‌دهد
  3. آن عدد را در TELEGRAM_ALLOWED_USERS کپی کنید
📌

شناسه‌های کاربری تلگرام عدد‌های دائمی مثل 123456789 هستند. با ‎@username‎ تان که می‌تواند عوض شود فرق دارند. همیشه برای allowlist از شناسهٔ عددی استفاده کنید.

۴ گام ۳: اجرای گیت‌وی

تست سریع

اول گیت‌وی را در پیش‌زمینه اجرا کنید تا مطمئن شوید همه‌چیز کار می‌کند:

hermes gateway

خروجی چنین چیزی می‌بینید:

[Gateway] Starting Hermes Gateway...
[Gateway] Telegram adapter connected
[Gateway] Cron scheduler started (tick every 60s)

تلگرام را باز، بات تان را پیدا و یک پیام بفرستید. اگر جواب داد، در کار هستید. برای توقف Ctrl+C را بزنید.

تولید: نصب به‌عنوان سرویس

برای استقرار دائمی که از ری‌بوت جان سالم ببرد:

hermes gateway install
sudo hermes gateway install --system   # Linux only: boot-time system service

این یک سرویس پس‌زمینه می‌سازد: به‌طور پیش‌فرض سرویس کاربری systemd روی لینوکس، یا سرویس launchd روی macOS، یا سرویس سیستمیِ زمان-بوت لینوکس اگر ‎--system‎ بدهید.

# Linux — manage the default user service
hermes gateway start
hermes gateway stop
hermes gateway status

# View live logs
journalctl --user -u hermes-gateway -f

# Keep running after SSH logout
sudo loginctl enable-linger $USER

# Linux servers — explicit system-service commands
sudo hermes gateway start --system
sudo hermes gateway status --system
journalctl -u hermes-gateway -f
# macOS — manage the service
hermes gateway start
hermes gateway stop
tail -f ~/.hermes/logs/gateway.log
💡

‏PATH در macOS:plist ی launchd PATH ی شل شما را هنگام نصب ثبت می‌کند تا زیرفرایندهای گیت‌وی ابزارهایی مثل Node.js و ffmpeg را پیدا کنند. اگر بعداً ابزار جدیدی نصب کردید hermes gateway install را دوباره اجرا کنید تا plist به‌روز شود.

تأیید در حال اجرا بودن

hermes gateway status

بعد یک پیام تست به بات تان در تلگرام بفرستید. باید ظرف چند ثانیه پاسخ بگیرید.

۵ گام ۴: راه‌اندازی دسترسی تیم

حالا به هم‌تیمی‌ها دسترسی بدهید. دو رویکرد هست.

رویکرد A: allowlist ایستا

شناسهٔ کاربری تلگرامی تک‌تک اعضا را جمع کنید ‏(بگویید به @userinfobot پیام بدهند) و به‌صورت فهرست جدا-با-کاما اضافه کنید:

# In ~/.hermes/.env
TELEGRAM_ALLOWED_USERS=123456789,987654321,555555555

بعد از تغییرات گیت‌وی را ری‌استارت کنید:

hermes gateway stop && hermes gateway start

رویکرد B: جفت‌سازی DM ‏(توصیه‌شده برای تیم‌ها)

جفت‌سازی DM انعطاف‌پذیرتر است — لازم نیست از قبل شناسه‌های کاربری جمع کنید. این‌طوری کار می‌کند:

  1. هم‌تیمی به بات DM می‌دهد — چون روی allowlist نیست، بات با کد جفت‌سازی یک‌بارمصرف پاسخ می‌دهد: 
    🔐 Pairing code: XKGH5N7P
Send this code to the bot owner for approval.
  2. هم‌تیمی کد را به شما می‌فرستد ‏(از هر کانالی — اسلک، ایمیل، حضوری)
  3. شما روی سرور تأییدش می‌کنید: 
    hermes pairing approve telegram XKGH5N7P
  4. وارد شد — بات بلافاصله شروع به پاسخ به پیام‌هایش می‌کند

مدیریت کاربران جفت‌شده:

# See all pending and approved users
hermes pairing list

# Revoke someone's access
hermes pairing revoke telegram 987654321

# Clear expired pending codes
hermes pairing clear-pending
💡

جفت‌سازی DM برای تیم‌ها ایده‌آل است چون برای افزودن کاربر جدید لازم نیست گیت‌وی ری‌استارت شود. تأییدها بلافاصله اثر می‌کنند.

ملاحظات امنیتی

  • هرگز GATEWAY_ALLOW_ALL_USERS=true را روی باتی با دسترسی ترمینال ست نکنید — هر کسی بات تان را پیدا کند می‌تواند روی سرورتان فرمان اجرا کند
  • کدهای جفت‌سازی بعد از ۱ ساعت منقضی می‌شوند و از تصادف رمزنگاری‌شده استفاده می‌کنند
  • محدودیت نرخ جلوی حملات brute-force را می‌گیرد: ۱ درخواست per کاربر per ۱۰ دقیقه، حداکثر ۳ کد در انتظار per پلتفرم
  • بعد از ۵ تلاش ناموفق تأیید، پلتفرم به قفل ۱ ساعته می‌رود
  • همهٔ داده‌های جفت‌سازی با مجوزهای chmod 0600 ذخیره می‌شوند

۶ گام ۵: پیکربندی بات

کانال خانگی ست کنید

کانال خانگی جایی است که بات نتایج کارهای cron و پیام‌های پیش‌دستانه را تحویل می‌دهد. بدون آن، وظایف زمان‌بندی‌شده جایی برای فرستادن خروجی ندارند.

گزینهٔ ۱: فرمان ‎/sethome‎ را در هر گروه یا گفتگوی تلگرامی که بات عضوش است بزنید.

گزینهٔ ۲: دستی در ~/.hermes/.env ست کنید:

TELEGRAM_HOME_CHANNEL=-1001234567890
TELEGRAM_HOME_CHANNEL_NAME="Team Updates"

برای پیدا کردن شناسهٔ کانال، ‏@userinfobot را به گروه اضافه کنید — شناسهٔ گفتگوی گروه را گزارش می‌دهد.

نمایش پیشرفت ابزار را پیکربندی کنید

کنترل کنید بات هنگام استفاده از ابزارها چقدر جزئیات نشان دهد. در ~/.hermes/config.yaml:

display:
  tool_progress: new    # off | new | all | verbose
حالتچه می‌بینید
offفقط پاسخ‌های تمیز — بدون فعالیت ابزار
newوضعیت کوتاه برای هر فراخوانی ابزار جدید ‏(توصیه‌شده برای پیام‌رسانی)
allهر فراخوانی ابزار با جزئیات
verboseخروجی کامل ابزار شامل نتایج فرمان‌ها

کاربران می‌توانند per-نشست با فرمان ‎/verbose‎ در چت هم عوضش کنند.

شخصیت با SOUL.md ست کنید

نحوهٔ ارتباط بات را با ویرایش ~/.hermes/SOUL.md سفارشی کنید.

راهنمای کامل در استفاده از SOUL.md با هرمس.

# Soul
You are a helpful team assistant. Be concise and technical.
Use code blocks for any code. Skip pleasantries — the team
values directness. When debugging, always ask for error logs
before guessing at solutions.

زمینهٔ پروژه اضافه کنید

اگر تیم تان روی پروژه‌های مشخصی کار می‌کند فایل‌های زمینه بسازید تا بات استک تان را بشناسد:

<!-- ~/.hermes/AGENTS.md -->
# Team Context
- We use Python 3.12 with FastAPI and SQLAlchemy
- Frontend is React with TypeScript
- CI/CD runs on GitHub Actions
- Production deploys to AWS ECS
- Always suggest writing tests for new code
📌

فایل‌های زمینه در system prompt هر نشست تزریق می‌شوند. موجز نگهشان دارید — هر کاراکتر از بودجهٔ توکن تان حساب می‌شود.

۷ گام ۶: راه‌اندازی وظایف زمان‌بندی‌شده

با گیت‌وی در حال اجرا می‌توانید وظایف تکرارشونده‌ای زمان‌بندی کنید که نتایج را به کانال تیم تحویل دهند.

خلاصهٔ استندآپ روزانه

به بات در تلگرام پیام بدهید:

Every weekday at 9am, check the GitHub repository at
github.com/myorg/myproject for:
1. Pull requests opened/merged in the last 24 hours
2. Issues created or closed
3. Any CI/CD failures on the main branch
Format as a brief standup-style summary.

ایجنت خودکار کار cron می‌سازد و نتایج را به گفتگویی که درخواست کردید ‏(یا کانال خانگی) تحویل می‌دهد.

چک سلامت سرور

Every 6 hours, check disk usage with 'df -h', memory with 'free -h',
and Docker container status with 'docker ps'. Report anything unusual —
partitions above 80%, containers that have restarted, or high memory usage.

مدیریت وظایف زمان‌بندی‌شده

# From the CLI
hermes cron list          # View all scheduled jobs
hermes cron status        # Check if scheduler is running

# From Telegram chat
/cron list                # View jobs
/cron remove <job_id>     # Remove a job
⚠️

پرامپت‌های کار cron در نشست‌های کاملاً تازه بدون هیچ حافظه‌ای از گفتگوهای قبلی اجرا می‌شوند. مطمئن شوید هر پرامپت همهٔ زمینهٔ موردنیاز ایجنت را دارد — مسیر فایل‌ها، URL ها، آدرس‌های سرور و دستورالعمل‌های روشن.

۸ نکات تولید

برای امنیت از Docker استفاده کنید

روی بات مشترک تیمی، Docker را backend ترمینال کنید تا فرمان‌های ایجنت داخل کانتینر اجرا شوند نه روی host شما:

# In ~/.hermes/.env
TERMINAL_ENV=docker
TERMINAL_DOCKER_IMAGE=nikolaik/python-nodejs:python3.11-nodejs20

یا در ~/.hermes/config.yaml:

terminal:
  backend: docker
  container_cpu: 1
  container_memory: 5120
  container_persistent: true

این‌طوری حتی اگر کسی از بات بخواهد چیزی مخرب اجرا کند، سیستم host شما محافظت می‌شود.

گیت‌وی را پایش کنید

# Check if the gateway is running
hermes gateway status

# Watch live logs (Linux)
journalctl --user -u hermes-gateway -f

# Watch live logs (macOS)
tail -f ~/.hermes/logs/gateway.log

هرمس را به‌روز نگه دارید

از تلگرام ‎/update‎ را به بات بفرستید — آخرین نسخه را می‌کشد و ری‌استارت می‌شود. یا از سرور:

hermes update
hermes gateway stop && hermes gateway start

محل لاگ‌ها

چه چیزیمحل
لاگ‌های گیت‌ویjournalctl --user -u hermes-gateway ‏(لینوکس) یا ~/.hermes/logs/gateway.log ‏(macOS)
خروجی کارهای cron~/.hermes/cron/output/{job_id}/{timestamp}.md
تعاریف کارهای cron~/.hermes/cron/jobs.json
داده‌های جفت‌سازی~/.hermes/pairing/
تاریخچهٔ نشست‌ها~/.hermes/sessions/

۹ قدم‌های بعدی

یک دستیار تلگرامی تیمی کارا دارید. مسیرهای بعدی:

  • راهنمای امنیت — عمیق‌تر در احراز هویت، ایزوله‌سازی کانتینر و تأیید فرمان
  • گیت‌وی پیام‌رسانی — مرجع کامل معماری گیت‌وی، مدیریت نشست و فرمان‌های چت
  • راه‌اندازی تلگرام — جزئیات مخصوص-پلتفرم شامل پیام‌های صوتی و TTS
  • وظایف زمان‌بندی‌شده — زمان‌بندی پیشرفتهٔ cron با گزینه‌های تحویل و عبارات cron
  • فایل‌های زمینه — AGENTS.md، ‏SOUL.md و cursorrules. برای دانش پروژه
  • شخصیت — پیش‌فرض‌های شخصیت داخلی و تعریف persona ی سفارشی
  • پلتفرم‌های بیشتر — همان گیت‌وی می‌تواند هم‌زمان دیسکورد، اسلک و واتساپ را هم اجرا کند

سؤال یا مشکل؟ روی گیت‌هاب issue باز کنید — مشارکت خوش‌آمد است.
