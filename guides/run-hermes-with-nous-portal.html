اجرا با Nous Portal

این راهنما شما را قدم‌به‌قدم برای اجرای Hermes Agent روی اشتراکِ Nous Portal همراهی می‌کند — از ثبت‌نام تا تأیید اینکه هر ابزار درست مسیریابی می‌شود. اگر فقط نگاه کلی دربارهٔ این‌که Portal چیست و اشتراک چه چیزهایی دارد می‌خواهید، صفحهٔ یکپارچگی Nous Portal را ببینید. این صفحه، سناریوی گام‌به‌گام انجام کار است.

۱ پیش‌نیازها

  • Hermes Agent نصب شده باشد (شروع سریع)
  • یک مرورگر وب روی ماشینی که راه‌اندازی می‌کنید (یا port forwarding با SSH — به OAuth روی SSH / میزبان راهن نگاهی بیندازید)
  • حدود ۵ دقیقه

به این‌ها نیاز ندارید: کلید OpenAI، کلید Anthropic، حساب Firecrawl، حساب FAL، حساب Browser Use یا هر اعتبارنامهٔ دیگری مختص یک فروشنده خاص. این دقیقاً فلسفهٔ ماجرا است.

۲ گام ۱: گرفتن اشتراک

portal.nousresearch.com/manage-subscription را باز کنید، ثبت‌نام کنید و یک پلن انتخاب کنید.

از قبل اشتراک دارید؟ به گام ۲ بروید.

۳ گام ۲: اجرای راه‌اندازی یک‌باره

hermes setup --portal

این تنها فرمان پنج کار انجام می‌دهد:

  1. مرورگر شما را برای ورود OAuth به portal.nousresearch.com باز می‌کند
  2. توکن refresh را در ~/.hermes/auth.json ذخیره می‌کند
  3. model.provider: nous را در ~/.hermes/config.yaml تنظیم می‌کند
  4. یک مدل ایجنتی پیش‌فرض انتخاب می‌کند (anthropic/claude-sonnet-4.6 یا مشابه آن)
  5. گیت‌وی ابزار را برای جستجوی وب، تولید تصویر، TTS و اتوماسیون مرورگر روشن می‌کند

وقتی تمام شد، به ترمینال‌تان برمی‌گردید و آمادهٔ چت هستید.

اگر با SSH به یک سرور وصل هستم چه؟

OAuth به مرورگر نیاز دارد، اما callback از نوع loopback روی ماشینی اجرا می‌شود که هرمس روی آن در حال اجراست. دو گزینه دارید:

# گزینهٔ A: port forwarding با SSH (پیشنهادی)
ssh -N -L 8642:127.0.0.1:8642 user@remote-host    # در یک ترمینال محلی
hermes setup --portal                              # روی ماشین راه‌دور، URL چاپ‌شده را در مرورگر محلی‌تان باز کنید

# گزینهٔ B: ورود با device-code (از Cloud Shell، Codespaces و EC2 Instance Connect کار می‌کند)
hermes auth add nous --type oauth
# سپس برای متصل‌کردن ارائه‌دهنده + گیت‌وی، دوباره hermes setup --portal را اجرا کنید

برای راهنمای کامل شامل زنجیره‌های ProxyJump، mosh/tmux و نکات ریز ControlMaster، به OAuth روی SSH / میزبان راهن نگاهی بیندازید.

۴ گام ۳: تأیید اینکه کار کرد

hermes portal info

باید این را ببینید:

  Nous Portal
  ───────────
  Auth:    ✓ logged in
  Portal:  https://portal.nousresearch.com
  Model:   ✓ using Nous as inference provider

  Tool Gateway
  ────────────
  Web search & extract  via Nous Portal
  Image generation      via Nous Portal
  Text-to-speech        via Nous Portal
  Browser automation    via Nous Portal

اگر هر خطی چیزی غیر از «via Nous Portal» نشان داد یا خط auth گفت «not logged in»، مستقیم به بخش عیب‌یابی در پایین صفحه بروید.

۵ گام ۴: اجرای اولین گفتگو

hermes chat

چیزی امتحان کنید که هم مدل و هم گیت‌وی ابزار را درگیر کند:

Hey, search the web for "Hermes Agent release notes" and summarize the top 3 hits.

باید ببینید هرمس web_search را فراخوانی می‌کند (با پشتوانهٔ Firecrawl، از طریق گیت‌وی) و با یک خلاصه پاسخ می‌دهد. اگر جستجو اجرا شود و پاسخ منطقی باشد، کار تمام است — Portal سرتاسر سیم‌کشی شده است.

۶ گام ۵: مدل واقعاً مورد نظرتان را انتخاب کنید

hermes setup --portal در زمان راه‌اندازی اجازه می‌دهد مدلی انتخاب کنید، اما فلسفهٔ کل اشتراک دسترسی به کاتالوگ کامل است — هر وقت خواستید در میانهٔ نشست با /model عوضش کنید:

/model anthropic/claude-sonnet-4.6     # بهترین مدل ایجنتی همه‌کاره
/model openai/gpt-5.4                  # استدلال قوی + فراخوانی ابزار
/model google/gemini-2.5-pro           # پنجرهٔ زمینهٔ عظیم
/model deepseek/deepseek-v3.2          # کدزن به‌صرفه
/model anthropic/claude-opus-4.6       # سنگین‌وزن برای مسائل سخت

یا انتخاب‌گر (picker) را باز کنید و مرور کنید:

/model

پیش‌فرض دیگری را برای همیشه انتخاب کنید:

# در ترمینال‌تان، خارج از هر نشستی
hermes config set model.default anthropic/claude-sonnet-4.6

برای کار ایجنتی Hermes-4 را انتخاب نکنید

Hermes-4-70B و Hermes-4-405B روی Portal با تخفیف‌های سنگین موجودند، اما آن‌ها مدل‌های چت/استدلال هستند، نه مدل‌های تنظیم‌شده برای فراخوانی ابزار. در حلقه‌های چندمرحله‌ای ایجنت به مشکل می‌خورند. آن‌ها را برای کارهای گفتگو/پژوهش از طریق پروکسی اشتراک از ابزارهای غیرایجنتی استفاده کنید. برای خودِ Hermes Agent، به همان مدل‌های ایجنتی مرزیِ بالا وفادار بمانید.

صفحهٔ info خود Portal هم همین هشدار را دارد — این راهنمای رسمی Nous است، نه صرفاً نظر سمت هرمس.

۷ گام ۶ (اختیاری): سفارشی‌سازی مسیریابی گیت‌وی ابزار

فعال‌سازی گیت‌وی برای هر ابزار اختیاری است، نه همه‌یا‌هیچ. اگر از قبل حساب Browserbase دارید و می‌خواهید هم‌زمان که جستجوی وب و تولید تصویر را از مسیر Nous می‌فرستید، از همان ادامه دهید، این پشتیبانی می‌شود:

hermes tools
# → جستجوی وب        → "Nous Subscription"     (پیشنهادی)
# → تولید تصویر      → "Nous Subscription"     (پیشنهادی)
# → مرورگر           → "Browserbase"           (کلید فعلی شما)
# → TTS              → "Nous Subscription"     (پیشنهادی)

این ردیف‌ها حتی قبل از ورود به Nous Portal در hermes tools دیده می‌شوند — اگر بدون نشست فعال «Nous Subscription» را انتخاب کنید، هرمس ورود به Portal را درجا انجام می‌دهد (بدون تغییر ارائه‌دهندهٔ استنتاج یا بقیهٔ ابزارهای‌تان).

ترکیب‌تان را با این تأیید کنید:

hermes portal tools

مسیریابیِ هر ابزار را جداگانه می‌بینید — via Nous Portal برای آن‌هایی که از مسیر اشتراک می‌روند، و نام شریک (browserbase، firecrawl و…) برای آن‌هایی که از کلیدهای خودتان استفاده می‌کنند.

۸ گام ۷ (اختیاری): فعال‌کردن حالت صوتی

چون گیت‌وی ابزار شامل TTS مربوط به OpenAI است، حالت صوتی بدون کلید جداگانهٔ OpenAI کار می‌کند:

hermes setup tts
# → برای TTS گزینهٔ "Nous Subscription" را انتخاب کنید
# → یک بک‌اند speech-to-text انتخاب کنید (faster-whisper محلی رایگان است، بدون نیاز به راه‌اندازی)

بعد در هر نشست روی پلتفرم پیام‌رسانی (تلگرام، دیسکورد، سیگنال و…) یک پیام صوتی بفرستید و هرمس آن را پیاده‌سازی می‌کند، پاسخ می‌دهد و با صدای سنتزشده جواب می‌دهد — همه روی اشتراک Portal‌تان.

۹ گام ۸ (اختیاری): کرون و گردش‌کارهای همیشه‌روشن

اشتراک Portal برای کارهای کرون و پردازش گروهی هم به همان شکلی که برای چت تعاملی کار می‌کند، کار می‌کند — توکن refresh از نوع OAuth به‌طور خودکار دوباره استفاده می‌شود. تنظیم اضافی لازم نیست؛ فقط کارهای کرون را زمان‌بندی کنید و صورت‌حسابشان به اشتراک‌تان می‌رود.

hermes cron create "0 9 * * *" \
  "Search the web for top AI news and summarize the 5 most important stories" \
  --name "Daily AI news"

کار کرون بدون حضور شما اجرا می‌شود و مدل + جستجوی وب + خلاصه‌سازی را همگی از طریق اشتراک Portal‌تان فراخوانی می‌کند.

۱۰ پروفایل‌ها و راه‌اندازی‌های چندکاربره

اگر از پروفایل‌های هرمس استفاده می‌کنید (مثلاً یک پیکربندی جدا برای هر پروژه)، توکن refresh مربوط به Portal به‌طور خودکار از طریق یک مخزن توکن مشترک بین همهٔ پروفایل‌ها به اشتراک گذاشته می‌شود. روی هر پروفیلی یک‌بار وارد شوید و بقیه خودکار آن را برمی‌دارند.

برای راه‌اندازی‌های تیمی که چند آدم یک ماشین را به اشتراک می‌گذارند، هر فرد حساب Portal خودش را دارد → هر پوشهٔ خانه ~/.hermes/auth.json خودش را دارد → هیچ اشتراک توکنی بین کاربران نیست. این همان مرز درست است.

۱۱ عیب‌یابی

hermes portal info بعد از hermes setup --portal می‌گوید «not logged in»

جریان OAuth کامل نشده است. دوباره اجرایش کنید:

hermes portal

اگر مرورگرتان باز نمی‌شود یا callback شکست می‌خورد، احتمالاً روی یک میزبان راه‌دور/بدون‌سر (headless) هستید — برای راه‌حل‌های port forwarding به OAuth روی SSH نگاهی بیندازید.

«Model: currently openrouter» (یا ارائه‌دهندهٔ دیگری) به‌جای «using Nous as inference provider»

پیکربندی محلی‌تان جابه‌جا شده است. OAuth کار کرده ولی model.provider هنوز به ارائه‌دهندهٔ دیگری اشاره می‌کند. راه‌حل:

hermes config set model.provider nous

یا به‌صورت تعاملی:

hermes model
# Nous Portal را انتخاب کنید

با hermes portal info دوباره تأیید کنید.

ابزارهای گیت‌وی ابزار به‌جای «via Nous Portal» نام شریک را نشان می‌دهند

پیکربندیِ هر-ابزار روی گیت‌وی اولویت دارد. اجرا کنید:

hermes tools
# برای هر ابزاری که می‌خواهید از گیت‌وی برود "Nous Subscription" را انتخاب کنید

بعضی کاربران عمداً ترکیبی استفاده می‌کنند — مثلاً وب را از مسیر Nous می‌فرستند ولی برای مرورگر از کلید Browserbase خودشان استفاده می‌کنند. اگر عمدی است، دست نزنید. اگر نه، همین فرمان درستش می‌کند.

«Re-authentication required» در میانهٔ نشست

توکن refresh مربوط به Portal شما باطل شده است (تغییر رمز، لغو دستی، انقضای نشست). توکن حالا به‌طور محلی قرنطینه شده تا هرمس بی‌نهایت آن را دوباره استفاده نکند. فقط دوباره وارد شوید:

hermes auth add nous

قرنطینه با ورود مجددِ موفق خودکار پاک می‌شود.

مدل مورد نظرم در انتخاب‌گر /model نیست

کاتالوگ Portal بر فهرست مدل‌های OpenRouter (بیش از ۳۰۰ مدل) به‌علاوهٔ مدل‌هایی که از طریق ارائه‌دهندگان اختصاصی یا ثانویه سرویس می‌شوند تکیه دارد. اگر مدلی غایب است، اسلاگِ OpenRouter‌سبک را مستقیم تایپ کنید:

/model anthropic/claude-opus-4.6
/model openai/o1-2025-12-17

اگر مدلی واقعاً در دسترس نیست، یک ایشو باز کنید — بیشتر خلأها پیکربندی مسیریابی‌ای هستند که می‌توانیم به‌روزرسانی کنیم.

صورت‌حساب در حساب Portal‌ام ظاهر نمی‌شود

hermes portal info می‌گوید واقعاً از مسیر Portal می‌روید یا از ارائه‌دهندهٔ دیگری. علت‌های رایج:

  • model.provider روی openrouter/anthropic/غیره تنظیم شده به‌جای nous
  • شکست در refresh فرایند OAuth که باعث شده به ارائه‌دهندهٔ پیکربندی‌شدهٔ دیگری برگردد
  • چند پروفایل هرمس دارید و اشتباهی از پروفایل دیگری استفاده می‌کنید (hermes profile list را چک کنید)

لغو دسترسی و شروع از صفر

hermes auth logout nous       # توکن refresh محلی را پاک می‌کند
# سپس دوباره setup را اجرا کنید یا اشتراک را از رابط وب Portal حذف کنید

۱۲ آنچه به دست می‌آورید، به زبان اعداد

بدون Portalبا Portal
۱× کلید OpenRouter / Anthropic / OpenAI در .env۱× توکن refresh از نوع OAuth، بدون کلید در .env
۱× کلید Firecrawl برای وبوب از مسیر گیت‌وی
۱× کلید FAL برای تولید تصویرتولید تصویر از مسیر گیت‌وی
۱× کلید Browser Use / Browserbase برای مرورگرمرورگر از مسیر گیت‌وی
۱× کلید OpenAI برای TTS / حالت صوتیTTS از مسیر گیت‌وی
۵ داشبورد جداگانه، شارژ حساب و صورت‌حساب‌های جداگانه۱ اشتراک، ۱ صورت‌حساب
بین ماشین‌ها: بازتولید هر ۵ کلیدبین ماشین‌ها: یک‌بار OAuth مجدد

معامله همین است. اگر به‌هرحال بیش از دو مورد از این بک‌اندها را استفاده می‌کنید، اشتراک هزینهٔ خودش را درمی‌آورد.

۱۳ همچنین ببینید

  • صفحهٔ یکپارچگی Nous Portal — نگاه کلی به آنچه در اشتراک هست
  • گیت‌وی ابزار — جزئیات کامل هر ابزارِ مسیریابی‌شده از گیت‌وی
  • پروکسی اشتراک — استفاده از اشتراک Portal از ابزارهای غیرهرمسی
  • حالت صوتی — راه‌اندازی گفتگوهای صوتی روی اشتراک Portal
  • OAuth روی SSH — الگوهای ورود راه‌دور / بدون‌سر
  • پروفایل‌ها — به‌اشتراک‌گذاری یک ورود Portal بین چند پیکربندی هرمس
