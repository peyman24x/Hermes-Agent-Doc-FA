گوگل جِمینای

‏Hermes Agent از Google Gemini به‌عنوان ارائه‌دهندهٔ بومی از طریق ‏Google AI Studio / Gemini API پشتیبانی می‌کند — نه نقطهٔ پایانی سازگار-OpenAI. این اجازه می‌دهد هرمس حلقهٔ پیام و ابزار داخلیِ شکل-OpenAI خود را به API ی بومی generateContent ی Gemini ترجمه کند در حالی که فراخوانی ابزار، استریم، ورودی‌های چندوجهی و متادیتای پاسخ مخصوص Gemini حفظ می‌شود.

۱ پیش‌نیازها

  • کلید API ی Google AI Studio — در aistudio.google.com/apikey بسازید
  • پروژهٔ Google Cloud با صورتحساب فعال — برای استفادهٔ ایجنتی توصیه می‌شود. tier رایگان Gemini برای نشست‌های طولانی ایجنتی خیلی کوچک است چون هرمس ممکن است به‌ازای هر نوبت کاربر چندین فراخوانی مدل بزند.
  • Hermes نصب‌شده — برای ارائه‌دهندهٔ بومی Gemini هیچ بستهٔ پایتونی اضافه لازم نیست.
💡

مسیر کلید API:GOOGLE_API_KEY یا GEMINI_API_KEY را ست کنید. هرمس برای ارائه‌دهندهٔ gemini هر دو نام را چک می‌کند.

۲ شروع سریع

# Add your Gemini API key
echo "GOOGLE_API_KEY=..." >> ~/.hermes/.env

# Select Gemini as your provider
hermes model
# → Choose "More providers..." → "Google AI Studio"
# → Hermes checks your key tier and shows Gemini models
# → Select a model

# Start chatting
hermes chat

اگر ویرایش مستقیم config را ترجیح می‌دهید، URL پایهٔ بومی Gemini API را استفاده کنید:

model:
  default: gemini-3-flash-preview
  provider: gemini
  base_url: https://generativelanguage.googleapis.com/v1beta

۳ پیکربندی

بعد از اجرای hermes model فایل ~/.hermes/config.yaml تان شامل:

model:
  default: gemini-3-flash-preview
  provider: gemini
  base_url: https://generativelanguage.googleapis.com/v1beta

و در ~/.hermes/.env:

GOOGLE_API_KEY=...

API ی بومی Gemini

نقطهٔ پایانی توصیه‌شده:

https://generativelanguage.googleapis.com/v1beta

هرمس این نقطهٔ پایانی را تشخیص و آداپتور بومی Gemini خودش را می‌سازد. درون، هرمس حلقهٔ ایجنت را همچنان در پیام‌های شکل-OpenAI نگه می‌دارد و بعد هر درخواست را به اسکیمای بومی Gemini ترجمه می‌کند:

  • messages[] ← contents[] ی Gemini
  • system prompt ها ← systemInstruction ی Gemini
  • اسکیماهای ابزار ← functionDeclarations ی Gemini
  • نتایج ابزار ← بخش‌های functionResponse ی Gemini
  • پاسخ‌های استریمی ← chunk های استریم شکل-OpenAI برای حلقهٔ هرمس
📌

امضاهای تفکر Gemini 3:برای استفادهٔ ابزار در Gemini 3، هرمس مقادیر thoughtSignature ی چسبیده به بخش‌های فراخوانی-تابع را حفظ و در نوبت ابزار بعدی دوباره پخش می‌کند. مسیر حیاتی اعتبارسنجی گردش‌کارهای چندمرحله‌ای ایجنت همین است.

‏Gemini 3 ممکن است امضاهای تفکر را به بخش‌های دیگری از پاسخ هم بچسباند. آداپتور بومی هرمس امروز برای حلقه‌های ابزاری ایجنت بهینه شده، پس هنوز هر امضای غیر-فراخوانی-ابزار را با وفاداری کامل سطح-بخش دوباره پخش نمی‌کند.

نقطهٔ پایانی بومی را ترجیح دهید

گوگل یک نقطهٔ پایانی سازگار-OpenAI هم دارد:

https://generativelanguage.googleapis.com/v1beta/openai/

برای نشست‌های ایجنتی هرمس، نقطهٔ پایانی بومی Gemini بالا را ترجیح دهید. هرمس آداپتور بومی Gemini دارد تا استفادهٔ چندنوبتی ابزار، نتایج فراخوانی ابزار، استریم، ورودی‌های چندوجهی و متادیتای پاسخ Gemini را مستقیماً روی API ی generateContent نگاشت کند. نقطهٔ پایانی سازگار-OpenAI همچنان وقتی مفید است که خاصاً سازگاری API ی OpenAI لازم دارید.

اگر قبلاً GEMINI_BASE_URL را روی URL ی ‎/openai گذاشته بودید، حذف یا عوضش کنید:

GEMINI_BASE_URL=https://generativelanguage.googleapis.com/v1beta

۴ مدل‌های موجود

انتخاب‌گر hermes model مدل‌های Gemini نگهداری‌شده در رجیستری ارائه‌دهندهٔ هرمس را نشان می‌دهد. انتخاب‌های رایج:

مدلشناسهنکته‌ها
Gemini 3.1 Pro Previewgemini-3.1-pro-previewقوی‌ترین مدل preview وقتی موجوده
Gemini 3 Pro Previewgemini-3-pro-previewمدل قدرتمند reasoning و کدنویسی
Gemini 3 Flash Previewgemini-3-flash-previewپیش‌فرض توصیه‌شده با توازن سرعت/توانایی
Gemini 3.1 Flash Lite Previewgemini-3.1-flash-lite-previewسریع‌ترین / ارزان‌ترین گزینه وقتی موجوده

موجودی مدل‌ها با زمان تغییر می‌کند. اگر مدلی غایب شد یا برای کلید شما فعال نبود، hermes model را دوباره اجرا و از فهرست فعلی بردارید.

📌

شناسه‌های مدل:وقتی provider: gemini دارید از شناسه‌های بومی Gemini مثل gemini-3-flash-preview استفاده کنید نه شناسه‌های سبک-OpenRouter مثل google/gemini-3-flash-preview.

نام‌های مستعار latest

گوگل نام‌های مستعار متحرک برای خانواده‌های Pro و Flash منتشر می‌کند. مقدار gemini-pro-latest و gemini-flash-latest کاربردی است وقتی می‌خواهید گوگل بدون تغییر config ی هرمس شما مدل را خودکار جلو ببرد.

نام مستعارالان ردیابی می‌کندنکته‌ها
gemini-pro-latestآخرین مدل Gemini Proبهترین وقتی پیش‌فرض فعلی Pro ی گوگل را می‌خواهید
gemini-flash-latestآخرین مدل Gemini Flashبهترین وقتی پیش‌فرض فعلی Flash ی گوگل را می‌خواهید
 
model:
  default: gemini-pro-latest
  provider: gemini
  base_url: https://generativelanguage.googleapis.com/v1beta

اگر بازتولیدپذیری سخت‌گیرانه می‌خواهید، شناسه‌های صریح مثل gemini-3.1-pro-preview یا gemini-3-flash-preview را ترجیح دهید.

Gemma از طریق Gemini API

گوگل مدل‌های Gemma را هم از طریق Gemini API expose می‌کند. هرمس این‌ها را به‌عنوان مدل‌های گوگل می‌شناسد ولی مدخل‌های Gemma با throughput خیلی کم را از انتخاب‌گر پیش‌فرض مخفی می‌کند تا کاربران جدید تصادفی مدلی از tier ارزیابی را برای نشست طولانی ایجنتی انتخاب نکنند.

شناسه‌های ارزیابی کاربردی:

مدلشناسهنکته‌ها
Gemma 4 31B ITgemma-4-31b-itمدل Gemma بزرگ‌تر؛ برای ارزیابی سازگاری و کیفیت کاربردی
Gemma 4 26B A4B ITgemma-4-26b-a4b-itگونهٔ کوچک‌تر پارامتر-فعال وقتی موجوده

این مدل‌ها بهترین برخورد به‌عنوان گزینه‌های ارزیابی روی کلیدهای Gemini API دارند. قیمت‌گذاری Gemma API ی گوگل فقط-tier-رایگان است و سقف مصرف نسبت به مدل‌های Gemini تولیدی کم است، پس استفادهٔ پایدار ایجنتی هرمس معمولاً باید به یک مدل Gemini پرداختی، استقرار خودمیزبان یا ارائه‌دهندهٔ دیگری با سهمیه مناسب برسد.

برای استفاده از مدلی Gemma که از انتخاب‌گر مخفی است مستقیم ستش کنید:

model:
  default: gemma-4-31b-it
  provider: gemini
  base_url: https://generativelanguage.googleapis.com/v1beta

۵ سوئیچ مدل وسط نشست

در طول گفتگو از فرمان ‎/model‎ استفاده کنید:

/model gemini-3-flash-preview
/model gemini-flash-latest
/model gemini-3-pro-preview
/model gemini-pro-latest
/model gemma-4-31b-it
/model gemini-3.1-flash-lite-preview

اگر هنوز Gemini را پیکربندی نکرده‌اید، از نشست خارج و اول hermes model را اجرا کنید. ‏‎/model‎ بین ارائه‌دهنده‌ها و مدل‌های از-قبل-پیکربندی‌شده سوئیچ می‌کند؛ کلید API جدید جمع نمی‌کند.

تشخیص

hermes doctor

داکتور این‌ها را چک می‌کند:

  • آیا GOOGLE_API_KEY یا GEMINI_API_KEY موجوده
  • آیا credential های ارائه‌دهندهٔ پیکربندی‌شده قابل حلهستند

۶ گیت‌وی ‏(پلتفرم‌های پیام‌رسانی)

‏Gemini با همهٔ پلتفرم‌های گیت‌وی هرمس کار می‌کند ‏(Telegram، ‏Discord، ‏Slack، ‏WhatsApp، ‏LINE، ‏Feishu و...). Gemini را به‌عنوان ارائه‌دهنده پیکربندی و بعد گیت‌وی را عادی اجرا کنید:

hermes gateway setup
hermes gateway start

گیت‌وی config.yaml را می‌خواند و همان پیکربندی ارائه‌دهندهٔ Gemini را استفاده می‌کند.

۷ عیب‌یابی

«Gemini native client requires an API key»

هرмос… ببخشید، هرمس کلید API ی قابل استفاده پیدا نکرد. یکی از این دو را در ~/.hermes/.env اضافه کنید:

GOOGLE_API_KEY=...
# or
GEMINI_API_KEY=...

بعد hermes model را دوباره اجرا کنید.

«This Google API key is on the free tier»

هرمس هنگام راه‌اندازی کلیدهای Gemini API را آزمایش می‌کند. سهمیه‌های tier رایگان بعد از چند دور گفتگوی ایجنتی تمام می‌شوند چون استفاده از ابزار، ‏retry ها، فشرده‌سازی و کارهای کمکی ممکن است به چندین فراخوانی مدل نیاز داشته باشند.

روی پروژهٔ Google Cloud متصل به کلیدتان صورتحساب را فعال کنید، در صورت نیاز کلید را از نو بسازید و بعد hermes model را اجرا کنید.

«404 model not found»

مدل انتخابی برای حسابتان، منطقه یا کلید موجود نیست. hermes model را دوباره اجرا و مدل دیگری از فهرست فعلی بردارید.

مدل Gemma در hermes model نشان داده نمی‌شود

هرمس ممکن است به‌طور پیش‌فرض مدل‌های Gemma ی کم-throughput را از انتخاب‌گر مخفی کند. اگر عامدانه می‌خواهید یکی را ارزیابی کنید شناسه مدل را مستقیم در ~/.hermes/config.yaml ست کنید.

«429 quota exceeded» روی Gemma

مدل‌های Gemma از طریق Gemini API برای ارزیابی خوب‌اند ولی سقف‌های tier رایگان Gemini API شان کم است. برای تست سازگاری استفاده‌شان کنید و برای نشست‌های پایدار ایجنتی به مدل Gemini ی پرداختی یا ارائه‌دهندهٔ دیگری سوئیچ کنید.

نقطهٔ پایانی سازگار-OpenAI پیکربندی شده

در ~/.hermes/.env چک کنید:

GEMINI_BASE_URL=https://generativelanguage.googleapis.com/v1beta/openai/

به نقطهٔ پایانی بومی تغییرش دهید یا بازنویسی را حذف کنید:

GEMINI_BASE_URL=https://generativelanguage.googleapis.com/v1beta

فراخوانی ابزار با خطای schema شکست می‌خورد

هرمس را ارتقا دهید و hermes model را دوباره اجرا کنید. آداپتور بومی Gemini اسکیماهای ابزار را برای قالب سخت‌گیرتر function-declaration ی Gemini پاک‌سازی می‌کند؛ نسخه‌های قدیمی یا نقاط پایانی سفارشی ممکن است نه.
