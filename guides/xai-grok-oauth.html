xAI Grok OAuth (SuperGrok)

Hermes Agent از xAI Grok از طریق یک جریان ورود OAuth با کد دستگاه (device code) مبتنی بر مرورگر روی accounts.x.ai پشتیبانی می‌کند؛ یا با اشتراک SuperGrok‏ (grok.com) یا با اشتراک X Premium+‏ (حساب X متصل‌شده). نیازی به ‏XAI_API_KEY نیست — یک‌بار وارد شوید و هرمس نشست شما را در پس‌زمینه به‌طور خودکار تازه می‌کند.

وقتی با حساب X دارای Premium+ وارد می‌شوید، xAI وضعیت اشتراک را به‌طور خودکار به نشست xAI شما پیوند می‌زند؛ پس جریان OAuth درست مثل مشترکین مستقیم SuperGrok کار می‌کند.

ترنسپورت همان آداپتور ‏codex_responses را دوباره استفاده می‌کند (xAI نقطهٔ پایانی به سبک Responses عرضه کرده است)، پس استدلال، فراخوانی ابزار، استریم و کش پرامپت بدون هیچ تغییری در آداپتور کار می‌کنند.

همین توکن bearer OAuth را همهٔ سطوح مستقیم به xAI در هرمس هم دوباره استفاده می‌کنند — TTS، تولید تصویر، تولید ویدیو و رونویسی — پس یک ورود واحد هر چهار مورد را پوشش می‌دهد.

۲ پیش‌نیازها

  • Python 3.9+‏
  • Hermes Agent نصب شده باشد
  • یک اشتراک فعال SuperGrok روی حساب xAI شما، یا اشتراک X Premium+ روی حساب X که با آن وارد می‌شوید (xAI اشتراک را خودکار پیوند می‌زند)
  • مرورگری در دسترس، در هر جایی که بتوانید URL تأیید چاپ‌شده را باز کنید
⚠️ xAI ممکن است دسترسی OAuth API را بر اساس سطح اشتراک محدود کند

بک‌اند xAI فهرست مجاز خودش را روی سطح OAuth API اعمال می‌کند و دیده شده که مشترکین استاندارد SuperGrok را با ‏HTTP 403 رد می‌کند (ایشوی #26847 را ببینید) با این‌که اشتراک درون‌برنامه‌ای فعال است. اگر ورود OAuth در مرورگر موفق بود ولی استنتاج 403 برگرداند، ‏XAI_API_KEY را ست کنید و به مسیر کلید API بروید (‏provider: xai) — آن سطح امروز مشمول همین محدودسازی نیست.

# Launch the provider and model picker

بعد از اولین ورود، اعتبارنامه‌ها زیر ‏~/.hermes/auth.json ذخیره می‌شوند و پیش از انقضا به‌طور خودکار تازه می‌شوند.

۴ ورود دستی

می‌توانید بدون عبور از انتخابگر مدل، ورود را فعال کنید:

hermes auth add xai-oauth

نشست‌های ریموت / بدون سر

روی سرورها، کانتینرها، کنسول‌های فقط-مرورگری (Cloud Shell، Codespaces، EC2 Instance Connect) یا نشست‌های SSH که هرمس نمی‌تواند در آن‌ها مرورگری محلی باز کند، هرمس URL تأیید xAI و کد کاربر را چاپ می‌کند. URL را در هر مرورگری روی لپ‌تاپ خود یا در کنسول ابری باز کنید، اگر پرسید کد را وارد کنید و هرمس تا وقتی xAI ورود را تأیید کند پینگ می‌زند. هیچ تونل SSH یا شنوندهٔ callback محلی لازم نیست.

hermes auth add xai-oauth --no-browser
# Open the printed verification URL in your browser.

همین جریان کد دستگاه وقتی از داشبورد وب یا اپلیکیشن دسکتاپ وارد می‌شوید هم اعمال می‌شود: هرمس URL تأیید و کد کاربر را نشان می‌دهد، بعد در پس‌زمینه پینگ می‌زند تا وقتی شما دسترسی را تأیید کنید.

۵ ورود چطور کار می‌کند

  1. هرمس از ‏auth.x.ai یک کد دستگاه درخواست می‌کند.
  2. شما URL تأیید را باز می‌کنید، وارد می‌شوید، اگر پرسید کد نمایش‌داده‌شده را وارد می‌کنید و دسترسی را تأیید می‌کنید.
  3. هرمس تا تأیید به xAI پینگ می‌زند، بعد توکن‌ها را در ‏~/.hermes/auth.json ذخیره می‌کند.
  4. از آن به بعد هرمس توکن دسترسی را در پس‌زمینه تازه نگه می‌دارد — شما وارد می‌مانید تا وقتی ‏hermes auth logout xai-oauth را اجرا کنید یا از تنظیمات حساب xAI خود دسترسی را لغو کنید.

۶ بررسی وضعیت ورود

hermes doctor

بخش ‏◆ Auth Providers وضعیت فعلی همهٔ ارائه‌دهندگان را نشان می‌دهد، از جمله ‏xai-oauth.

۷ تغییر مدل

hermes model
# → Select "xAI Grok OAuth (SuperGrok / X Premium+)"
# → Pick from the model list (grok-4.6 is pinned to the top)

یا مدل را مستقیم ست کنید:

hermes config set model.default grok-4.6
hermes config set model.provider xai-oauth

۸ مرجع پیکربندی

بعد از ورود، ‏~/.hermes/config.yaml شامل این خواهد بود:

model:
  default: grok-4.6
  provider: xai-oauth
  base_url: https://api.x.ai/v1

نام‌های مستعار ارائه‌دهنده

همهٔ موارد زیر به ‏xai-oauth حل می‌شوند:

hermes --provider xai-oauth        # canonical
hermes --provider grok-oauth       # alias
hermes --provider x-ai-oauth       # alias
hermes --provider xai-grok-oauth   # alias

۹ ابزارهای مستقیم به xAI ‏(TTS / تصویر / ویدیو / رونویسی / جستجوی X)

وقتی با OAuth وارد شده باشید، هر ابزار مستقیم به xAI همان توکن bearer را خودکار دوباره استفاده می‌کند — هیچ راه‌اندازی جداگانه‌ای لازم نیست مگر این‌که ترجیح بدهید از کلید API استفاده کنید.

برای انتخاب بک‌اند هر ابزار:

hermes tools
# → Text-to-Speech       → "xAI TTS"
# → Image Generation     → "xAI Grok Imagine (image)"
# → Video Generation     → "xAI Grok Imagine"
# → X (Twitter) Search   → "xAI Grok OAuth (SuperGrok / X Premium+)"

اگر توکن‌های OAuth از قبل ذخیره باشند، انتخابگر تأییدش می‌کند و از پرامپت اعتبارنامه می‌پرد. اگر نه OAuth ست باشد نه ‏XAI_API_KEY، انتخابگر منویی با ۳ گزینه می‌دهد: ورود OAuth، چسباندن کلید API، یا رد شدن.

ℹ️ تولید ویدیو به‌صورت پیش‌فرض خاموش است

تول‌ست ‏video_gen به‌صورت پیش‌فرض غیرفعال است. قبل از این‌که ایجنت بتواند ‏video_generate را صدا بزند، آن را در ‏hermes tools ← ‏🎬 Video Generation فعال کنید (Space را بزنید). وگرنه ممکن است ایجنت به مهارت همراهِ ComfyUI برگردد که آن هم برای تولید ویدیو تگ شده است.

ℹ️ جستجوی X وقتی اعتبارنامهٔ xAI موجود باشد خودکار فعال می‌شود

تول‌ست ‏x_search هر وقت اعتبارنامه‌های xAI (توکن OAuth مربوط به SuperGrok / X Premium+ یا ‏XAI_API_KEY) پیکربندی شده باشند خودکار فعال می‌شود. اگر این را نمی‌خواهید، صریحاً از طریق ‏hermes tools ← ‏🐦 X (Twitter) Search (Space را بزنید) غیرفعالش کنید. این ابزار از طریق ‏x_search داخلیِ API Responses در xAI مسیریابی می‌شود — با هر دو کار می‌کند: ورود OAuth مربوط به SuperGrok / X Premium+ یا ‏XAI_API_KEY پولی؛ و وقتی هر دو پیکربندی شده باشند OAuth را ترجیح می‌دهد (به‌جای هزینهٔ API از سهمیهٔ اشتراک شما استفاده می‌کند). وقتی هیچ اعتبارنامهٔ xAI پیکربندی نشده باشد، اسکیمای ابزار از دید مدل پنهان است، فارغ از این‌که تول‌ست فعال باشد یا نه.

۱۱ عیب‌یابی

توکن منقضی شده — ورود دوباره به‌طور خودکار انجام نمی‌شود

هرمس توکن را قبل از هر نشست و دوباره به‌صورت واکنشی هنگام 401 تازه می‌کند. اگر تازه‌سازی با ‏invalid_grant شکست بخورد (توکن refresh باطل شده یا حساب چرخش خورده)، هرمس به‌جای کرش کردن، یک پیام re-auth دسته‌بندی‌شده نشان می‌دهد.

وقتی شکست تازه‌سازی قطعی است (HTTP 4xx، ‏invalid_grant، دسترسی باطل‌شده و غیره)، هرمس توکن refresh را مرده علامت می‌زند و به‌صورت محلی قرنطینه‌اش می‌کند — فراخوانی‌های بعدی از تلاشِ بی‌فایده برای تازه‌سازی می‌پرند به‌جای این‌که همان 401 را مدام تکرار کنند. ایجنت یک پیام واحد «نیاز به احراز هویت دوباره» نشان می‌دهد و تا وقتی دوباره وارد شوید کنار می‌ایستد.

رفع: ‏hermes auth add xai-oauth را دوباره اجرا کنید تا یک ورود تازه شروع شود. قرنطینه در تبادل موفق بعدی پاک می‌شود.

مهلت مجوزدهی تمام شده است

تأیید کد دستگاه یک بازهٔ انقضای محدود دارد (xAI در پاسخ کد دستگاه ‏expires_in ست می‌کند، معمولاً در حد چند ده دقیقه). اگر ورود را به‌موقع تأیید نکنید، هرمس خطای timeout می‌دهد.

رفع: ‏hermes auth add xai-oauth (یا ‏hermes model) را دوباره اجرا کنید. جریان از نو شروع می‌شود.

ورود از سرور ریموت

در نشست‌های SSH یا کانتینر، هرمس به‌جای باز کردن مرورگر URL تأیید و کد کاربر را چاپ می‌کند. آن URL را در مرورگری روی لپ‌تاپ خود یا در یک کنسول ابری باز کنید — برای xAI Grok OAuth هیچ port forward از SSH لازم نیست.

hermes auth add xai-oauth --no-browser

برای ارائه‌دهندگان با بازگردانی روی loopback (اسپاتیفای، سرورهای MCP) راهنمای OAuth روی SSH / میزبان راه‌دور را ببینید.

HTTP 403 بعد از ورود موفق (سطح اشتراک / مجوز)

OAuth در مرورگر تمام شده، توکن‌ها ذخیره شده‌اند، ولی استنتاج یا تازه‌سازی توکن ‏HTTP 403 برمی‌گرداند با پیامی شبیه «The caller does not have permission to execute the specified operation».

این مشکل توکنِ کهنه نیست — اجرای دوبارهٔ ‏hermes model تغییری نمی‌دهد. دیده شده بک‌اند xAI دسترسی OAuth API را به سطوح خاصی از SuperGrok محدود می‌کند، با این‌که اشتراک درون‌برنامه‌ای فعال است (ایشوی #26847).

رفع: ‏XAI_API_KEY را ست کنید و به مسیر کلید API بروید:

export XAI_API_KEY=xai-...
hermes config set model.provider xai

یا اگر مسیر OAuth برایتان لازم است، اشتراک‌تان را در x.ai/grok ارتقا دهید.

خطای «هیچ اعتبارنامهٔ xAI پیدا نشد» در زمان اجرا

مخزن احراز هویت هیچ مدخلی برای ‏xai-oauth ندارد و ‏XAI_API_KEY هم ست نیست. هنوز وارد نشده‌اید یا فایل اعتبارنامه حذف شده است.

رفع: ‏hermes model را اجرا کنید و ارائه‌دهندهٔ xAI Grok OAuth را انتخاب کنید، یا ‏hermes auth add xai-oauth را اجرا کنید.

۱۲ خروج

برای حذف همهٔ اعتبارنامه‌های ذخیره‌شدهٔ xAI Grok OAuth:

hermes auth logout xai-oauth

این کار هم مدخل OAuth تک‌نمونه‌ای در ‏auth.json و هم ردیف‌های استخر اعتبارنامه برای ‏xai-oauth را پاک می‌کند. اگر فقط می‌خواهید یک مدخل استخر را حذف کنید از ‏hermes auth remove xai-oauth <index|id|label> استفاده کنید (برای دیدن آن‌ها ‏hermes auth list xai-oauth را اجرا کنید).
