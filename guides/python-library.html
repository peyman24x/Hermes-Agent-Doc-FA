استفاده از هرمس به‌عنوان کتابخانهٔ پایتون

هرمس فقط یک ابزار CLI نیست. می‌توانید AIAgent را مستقیم import کنید و به‌صورت برنامه‌پذیر در اسکریپت‌ها، اپ‌های وب یا خطوط لولهٔ اتوماسیون خودتان استفاده‌اش کنید. این راهنما نحوهٔ کار را نشان می‌دهد.

۱ نصب

‏Hermes را کلون کنید و محیط توسعهٔ ویرایشی پشتیبانی‌شده‌اش را بسازید:

git clone https://github.com/NousResearch/hermes-agent.git
cd hermes-agent
uv sync

برنامهٔ خودتان را با uv run python your_app.py از داخل همان checkout اجرا کنید. هرمس برای نصب‌های requirements.txt هیچ wheel یا source distribution پشتیبانی‌شده‌ای منتشر نمی‌کند.

💡

همان متغیرهای محیطی که CLI استفاده می‌کند هنگام استفاده از هرمس به‌عنوان کتابخانه هم لازم‌اند. حداقل OPENROUTER_API_KEY را ست کنید ‏(یا OPENAI_API_KEY / ANTHROPIC_API_KEY اگر دسترسی مستقیم ارائه‌دهنده دارید).

۲ استفادهٔ پایه

ساده‌ترین راه استفاده از هرمس متد chat() است — پیام بدهید، رشته بگیرید:

from run_agent import AIAgent

agent = AIAgent(
    model="anthropic/claude-sonnet-4.6",
    quiet_mode=True,
)
response = agent.chat("What is the capital of France?")
print(response)

‏chat() کل حلقهٔ گفتگو را درون هندل می‌کند — فراخوانی‌های ابزار، ‏retry ها، همه‌چیز — و فقط متن پاسخ نهایی را برمی‌گرداند.

⚠️

هر وقت هرمس را در کد خودتان جاسازی می‌کنید quiet_mode=True را ست کنید. بدون آن ایجنت اسپینرهای CLI، نشانگرهای پیشرفت و بقیهٔ خروجی ترمینال را چاپ می‌کند که خروجی برنامه‌تان را شلوغ می‌کند.

۳ کنترل کامل گفتگو

برای کنترل بیشتر روی گفتگو مستقیماً از run_conversation() استفاده کنید. دیکشنری حاوی پاسخ کامل، تاریخچهٔ پیام و متادیتا برمی‌گرداند:

agent = AIAgent(
    model="anthropic/claude-sonnet-4.6",
    quiet_mode=True,
)

result = agent.run_conversation(
    user_message="Search for recent Python 3.13 features",
    task_id="my-task-1",
)

print(result["final_response"])
print(f"Messages exchanged: {len(result['messages'])}")

دیکشنری برگشتی شامل:

  • final_response — پاسخ متنی نهایی ایجنت
  • messages — تاریخچهٔ کامل پیام‌ها ‏(سیستم، کاربر، دستیار، فراخوانی‌های ابزار)

‏(task_id ای که می‌دهید روی نمونهٔ ایجنت برای ایزوله‌سازی VM ذخیره می‌شود ولی در دیکشنری بازگشتی echo نمی‌شود.)

می‌توانید پیام سیستم سفارشی هم بدهید که برای همان فراخوانی system prompt ی گذرا را بازنویسی می‌کند:

result = agent.run_conversation(
    user_message="Explain quicksort",
    system_message="You are a computer science tutor. Use simple analogies.",
)

۴ پیکربندی ابزارها

کنترل کنید ایجنت به کدام تول‌ست‌ها دسترسی دارد با enabled_toolsets یا disabled_toolsets:

# Only enable web tools (browsing, search)
agent = AIAgent(
    model="anthropic/claude-sonnet-4.6",
    enabled_toolsets=["web"],
    quiet_mode=True,
)

# Enable everything except terminal access
agent = AIAgent(
    model="anthropic/claude-sonnet-4.6",
    disabled_toolsets=["terminal"],
    quiet_mode=True,
)
💡

وقتی ایجنتی مینیمال و قفل‌شده می‌خواهید ‏(مثلاً فقط جستجوی وب برای بات تحقیق) از enabled_toolsets استفاده کنید. وقتی بیشتر قابلیت‌ها را می‌خواهید ولی بعضی خاص باید محدود شوند ‏(مثلاً بدون دسترسی ترمینال در محیط مشترک) از disabled_toolsets.

گفتگوهای چندنوبتی

وضعیت گفتگو را در چند نوبت با پاس دادن تاریخچهٔ پیام نگه دارید:

agent = AIAgent(
    model="anthropic/claude-sonnet-4.6",
    quiet_mode=True,
)

# First turn
result1 = agent.run_conversation("My name is Alice")
history = result1["messages"]

# Second turn — agent remembers the context
result2 = agent.run_conversation(
    "What's my name?",
    conversation_history=history,
)
print(result2["final_response"])  # "Your name is Alice."

پارامتر conversation_history فهرست messages از نتیجهٔ قبلی را می‌پذیرد. ایجنت داخلی از آن کپی می‌گیرد، پس فهرست اصلی شما هرگز mutate نمی‌شود.

ذخیرهٔ مسیرها ‏(Trajectories)

ذخیرهٔ trajectory را فعال کنید تا گفتگوها در قالب ShareGPT ثبت شوند — برای تولید دادهٔ آموزشی یا عیب‌یابی:

agent = AIAgent(
    model="anthropic/claude-sonnet-4.6",
    save_trajectories=True,
    quiet_mode=True,
)

agent.chat("Write a Python function to sort a list")
# Saves to trajectory_samples.jsonl in ShareGPT format

هر گفتگو به‌عنوان یک خط JSONL ضمیمه می‌شود و جمع کردن dataset از اجراهای خودکار را آسان می‌کند.

system prompt ی سفارشی

از ephemeral_system_prompt استفاده کنید تا system prompt ی سفارشی ست کنید که رفتار ایجنت را هدایت می‌کند ولی در فایل‌های trajectory ذخیره نمی‌شود ‏(دادهٔ آموزشی‌تان تمیز می‌ماند):

agent = AIAgent(
    model="anthropic/claude-sonnet-4",
    ephemeral_system_prompt="You are a SQL expert. Only answer database questions.",
    quiet_mode=True,
)

response = agent.chat("How do I write a JOIN query?")
print(response)

برای ساختن ایجنت‌های تخصصی ایده‌آل است — بازبین کد، نویسندهٔ مستندات، دستیار SQL — همه با همان زیرساخت ابزاری.

۵ پردازش دسته‌ای

برای اجرای موازی پرامپت‌های زیاد، هرمس batch_runner.py را شامل می‌شود. نمونه‌های هم‌زمان AIAgent را با ایزوله‌سازی صحیح منابع مدیریت می‌کند:

python batch_runner.py --input prompts.jsonl --output results.jsonl

هر پرامپت task_id و محیط ایزولهٔ خودش را می‌گیرد. اگر منطق دسته‌ای سفارشی لازم دارید مستقیم با AIAgent خودتان بسازید:

import concurrent.futures
from run_agent import AIAgent

prompts = [
    "Explain recursion",
    "What is a hash table?",
    "How does garbage collection work?",
]

def process_prompt(prompt):
    # Create a fresh agent per task for thread safety
    agent = AIAgent(
        model="anthropic/claude-sonnet-4",
        quiet_mode=True,
        skip_memory=True,
    )
    return agent.chat(prompt)

with concurrent.futures.ThreadPoolExecutor(max_workers=3) as executor:
    results = list(executor.map(process_prompt, prompts))

for prompt, result in zip(prompts, results):
    print(f"Q: {prompt}\nA: {result}\n")
⚠️

همیشه یک نمونهٔ AIAgent جدید per رشته یا task بسازید. ایجنت وضعیت داخلی نگه می‌دارد ‏(تاریخچهٔ گفتگو، نشست‌های ابزار، شمارنده‌های تکرار) که برای اشتراک بین‌رشته‌ای thread-safe نیست.

۶ نمونه‌های یکپارچگی

نقطهٔ پایانی FastAPI

from fastapi import FastAPI
from pydantic import BaseModel
from run_agent import AIAgent

app = FastAPI()

class ChatRequest(BaseModel):
    message: str
    model: str = "anthropic/claude-sonnet-4"

@app.post("/chat")
async def chat(request: ChatRequest):
    agent = AIAgent(
        model=request.model,
        quiet_mode=True,
        skip_context_files=True,
        skip_memory=True,
    )
    response = agent.chat(request.message)
    return {"response": response}

بات دیسکورد

import discord
from run_agent import AIAgent

client = discord.Client(intents=discord.Intents.default())

@client.event
async def on_message(message):
    if message.author == client.user:
        return
    if message.content.startswith("!hermes "):
        query = message.content[8:]
        agent = AIAgent(
            model="anthropic/claude-sonnet-4",
            quiet_mode=True,
            skip_context_files=True,
            skip_memory=True,
            platform="discord",
        )
        response = agent.chat(query)
        await message.channel.send(response[:2000])

client.run("YOUR_DISCORD_TOKEN")

مرحلهٔ خط لولهٔ CI/CD

#!/usr/bin/env python3
"""CI step: auto-review a PR diff."""
import subprocess
from run_agent import AIAgent

diff = subprocess.check_output(["git", "diff", "main...HEAD"]).decode()

agent = AIAgent(
    model="anthropic/claude-sonnet-4",
    quiet_mode=True,
    skip_context_files=True,
    skip_memory=True,
    disabled_toolsets=["terminal", "browser"],
)

review = agent.chat(
    f"Review this PR diff for bugs, security issues, and style problems:\n\n{diff}"
)
print(review)

نکته‌های مهم

💡
  • اگر نمی‌خواهید فایل‌های AGENTS.md از پوشهٔ کاری به system prompt بار شوند skip_context_files=True را ست کنید.
  • برای جلوگیری از خواندن/نوشتن حافظهٔ پایدار skip_memory=True را ست کنید — برای نقطه‌های پایانی API بی‌وضعیت توصیه می‌شود.
  • پارامتر platform ‏(مثل "discord"، "telegram") راهنماهای قالب‌بندی مخصوص-پلتفرم را تزریق می‌کند تا ایجنت سبک خروجی‌اش را تطبیق دهد.
⚠️
  • ایمنی رشته‌ای:per رشته یا task یک AIAgent بسازید. هرگز نمونه‌ای را بین فراخوانی‌های هم‌زمان به اشتراک نگذارید.
  • پاک‌سازی منابع:ایجنت منابع را خودکار پاک می‌کند ‏(نشست‌های ترمینال، نمونه‌های مرورگر) وقتی گفتگو تمام می‌شود. اگر در فرایند بلندمدت اجرا می‌کنید مطمئن شوید هر گفتگو به‌طور عادی تمام می‌شود.
  • سقف تکرار:پیش‌فرض max_iterations=500 سخاوتمندانه است. برای پرسش‌وپاسخ ساده آن را پایین‌تر بیاورید ‏(مثلاً max_iterations=10) تا از حلقه‌های فراخوانی-ابزارِ بی‌مهار و کنترل هزینه جلوگیری شود.
