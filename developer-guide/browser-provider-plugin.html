پلاگین ارائه‌دهندهٔ مرورگر

پلاگین‌های ارائه‌دهندهٔ مرورگر یک بک‌اند مرورگر ابری ثبت می‌کنند که فراخوانی‌های ابزار browser_* در حالت ابری (navigate، click، screenshot و...) را سرویس می‌کند. ارائه‌دهندگان داخلی — Browserbase، Browser Use و Firecrawl — همگی به‌شکل پلاگین زیر plugins/browser/<name>/ عرضه می‌شوند. می‌توانید یکی جدید اضافه کنید یا یکی از همراه‌ها را بازنویسی کنید؛ کافی است دایرکتوری‌ای کنارشان بگذارید.

💡

بک‌اندهای مرورگر یکی از چند پلاگین بک‌اندی هستند که هرمس پشتیبانی می‌کند. بقیه (هر کدام با ABC خودشان) عبارت‌اند از پلاگین‌های ارائه‌دهندهٔ جستجوی وب (که این ABC آگاهانه از آن تقلید می‌کند)، تولید تصویر، تولید ویدیو، ارائه‌دهندگان حافظه، موتورهای زمینه، منابع رمز و ارائه‌دهندگان مدل. پلاگین‌های عمومی ابزار/هوک/CLI در ساخت پلاگین هرمس هستند.

۱ سازوکار کلی

یک ارائه‌دهندهٔ مرورگر مرور کردن را پیاده‌سازی نمی‌کند. او چرخهٔ حیات نشست را پیاده‌سازی می‌کند: ساخت نشست مرورگر راه دور، تحویل URL وب‌سوکت CDP و برچیدن نشست. پشتهٔ مرورگر خود هرمس (agent-browser + tools/browser_tool.py) به هر URL ای CDP که برگردانید وصل می‌شود و از همان‌جا صفحه را می‌راند — هر ارائه‌دهنده‌ای کل تول‌ست browser_* را مجانی می‌گیرد.

ارائه‌دهندهٔ فعال با browser.cloud_provider در config.yaml انتخاب می‌شود؛ دیسپچرِ tools/browser_tool.py یک lookup خالصِ رجیستری است و هیچ شرطِ مخصوصِ ارائه‌دهنده ندارد.

۲ کشف

هرمس بک‌اندهای مرورگر را در سه جا اسکن می‌کند:

  1. همراه — <repo>/plugins/browser/<name>/ (به‌طور خودکار با kind: backend بارگیری می‌شود)
  2. کاربر — ~/.hermes/plugins/browser/<name>/ (با plugins.enabled یا hermes plugins enable <name> فعال می‌شود)
  3. Pip — بسته‌هایی که نقطهٔ ورود hermes_agent.plugins اعلام می‌کنند

register(ctx) هر پلاگین ctx.register_browser_provider(...) را صدا می‌زند که نمونه را در رجیستری agent/browser_registry.py می‌گذارد.

۳ ساختار پوشه

plugins/browser/my-backend/
├── __init__.py     # نقطهٔ ورود register()
├── provider.py     # زیرکلاس BrowserProvider
└── plugin.yaml     # مانیفست با kind: backend و provides_browser_providers

plugin.yaml:

name: browser-my-backend
version: 1.0.0
description: "My cloud browser backend. Requires MY_BACKEND_API_KEY."
author: you
kind: backend
provides_browser_providers:
  - my-backend

__init__.py:

from plugins.browser.my_backend.provider import MyBackendProvider


def register(ctx) -> None:
    ctx.register_browser_provider(MyBackendProvider())

۴ کلاس پایهٔ انتزاعی BrowserProvider (ABC)

agent.browser_provider.BrowserProvider را پیاده‌سازی کنید. سه متد چرخهٔ حیات به‌علاوهٔ هویت:

from agent.browser_provider import BrowserProvider


class MyBackendProvider(BrowserProvider):
    @property
    def name(self) -> str:
        return "my-backend"          # مقدار پیکربندی browser.cloud_provider

    @property
    def display_name(self) -> str:
        return "My Backend"          # در hermes tools نشان داده می‌شود

    def is_available(self) -> bool:
        """بررسی ارزانِ فقط — حضور متغیر محیطی، ایمپورت‌شدنی بودن وابستگی.
        هیچ فراخوانی شبکه‌ای: در زمان ثبت ابزار و در هر بار رندرِ
        hermes tools اجرا می‌شود."""
        return bool(os.environ.get("MY_BACKEND_API_KEY"))

    def create_session(self, task_id: str) -> dict:
        """نشست مرورگر راه دور می‌سازد؛ قرارداد فرادادهٔ نشست را برمی‌گرداند."""
        session = my_api.create_browser(...)
        return {
            "session_name": f"my-backend-{task_id}",  # نام نشست یکتای agent-browser
            "bb_session_id": session.id,              # شناسهٔ نشست ارائه‌دهنده (برای پاک‌سازی)
            "cdp_url": session.cdp_ws_url,            # URL وب‌سوکت CDP
            "features": {"stealth": True},            # پرچم‌های قابلیتی که فعال کرده‌اید
        }

    def close_session(self, session_id: str) -> bool:
        """با شناسهٔ نشستِ ارائه‌دهنده خاتمه می‌دهد. در خطا لاگ می‌کند و False
        برمی‌گرداند — هرگز استثنا پرتاب نمی‌کند تا حلقهٔ پاک‌سازی دیسپچر
        به حرکتش ادامه دهد."""
        ...

    def emergency_cleanup(self, session_id: str) -> None:
        """برچیدن با بهترین تلاش، از هندلرهای atexit/سیگنال. نباید استثنا پرتاب کند."""
        ...

قرارداد فرادادهٔ نشست

create_session() باید دست‌کم session_name، bb_session_id، cdp_url و features را برگرداند. دو نکتهٔ ظریف که دانستنش می‌ارزد:

  • bb_session_id نام کلیدی میراثی است که عیناً برای سازگاری با گذشته با tools/browser_tool.py نگه داشته شده — صرف‌نظر از فروشنده، شناسهٔ نشستِ ارائه‌دهندهٔ شما را نگه می‌دارد. نامش را عوض نکنید.
  • create_session() می‌تواند استثنا پرتاب کند — ValueError برای اعتبارنامهٔ غایب، RuntimeError برای شکست‌های شبکه/API. دیسپچر این‌ها را به کاربر می‌رساند. این با close_session/emergency_cleanup فرق دارد که هرگز نباید استثنا پرتاب کنند.

یک کلید اختیاری external_call_id از صورتحساب گیت‌وی مدیریت‌شده پشتیبانی می‌کند.

get_setup_schema() — ردیف انتخاب‌گرِ hermes tools

این را بازنویسی کنید تا به‌عنوان گزینهٔ درجه‌یک در انتخاب‌گر Browser Automation ظاهر شوید، همراه پرامپت‌های کلید API و یک هوک نصب:

def get_setup_schema(self) -> dict:
    return {
        "name": "My Backend",
        "badge": "paid",
        "tag": "Cloud browser with stealth and proxies",
        "env_vars": [
            {"key": "MY_BACKEND_API_KEY",
             "prompt": "My Backend API key",
             "url": "https://mybackend.example"},
        ],
        "post_setup": "agent_browser",   # مطمئن می‌شود Chromium محلی نصب است (خود agent-browser از طریق npx resolve می‌شود)
    }

طبق استاندارد پروژه برای بک‌اندهای ابزار: اگر بک‌اندی نتواند از طریق hermes tools انتخاب و پیکربندی شود، تمام نشده — «این متغیر محیطی را دستی ست کنید» یک یکپارچه‌سازی نیست.

۵ کاربران آن را پیکربندی می‌کنند

browser:
  cloud_provider: my-backend

۶ پیاده‌سازی‌های مرجع

سه ارائه‌دهندهٔ همراه زیر plugins/browser/ مثال‌های مرجع‌اند، به ترتیب صعودی پیچیدگی: firecrawl (ساده‌ترین)، browser_use و browserbase (پرچم‌های قابلیتِ stealth/پروکسی/keep-alive با پشتیبانِ نرم وقتی قابلیت‌های پولی در دسترس نیستند). نزدیک‌ترین را کپی کنید.

۷ چک‌لیست

  • ☐ name حروف کوچک و پایدار است (مقدار پیکربندی‌ای است که کاربران می‌نویسند)
  • ☐ is_available() صفر فراخوانی شبکه انجام می‌دهد
  • ☐ create_session() قرارداد کامل فراداده را برمی‌گرداند (نام کلید bb_session_id دست‌نخورده)
  • ☐ close_session() / emergency_cleanup() هرگز استثنا پرتاب نمی‌کنند
  • ☐ get_setup_schema() متغیرهای محیطی شما را نمایان می‌کند تا hermes tools بتواند بک‌اند را پیکربندی کند
  • ☐ plugin.yaml مقدار kind: backend + provides_browser_providers را اعلام می‌کند
