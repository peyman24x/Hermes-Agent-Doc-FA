گسترش CLI

هرمس روی HermesCLI هوک‌های گسترشِ محافظت‌شده ارائه می‌دهد تا CLIهای پوششی بتوانند بدون بازنویسی متد run()ِ بیش از ۱۰۰۰ خط، ویجت، کلیدمیان‌بر و سفارشی‌سازی چیدمان اضافه کنند. این کار افزونهٔ شما را از تغییرهای داخلی جدا نگه می‌دارد.

۱ نقاط گسترش

پنج نقطهٔ گسترش (extension seam) در دسترس است:

هوکهدفچه زمانی بازنویسی کنید…
_get_extra_tui_widgets()تزریق ویجت به چیدمانوقتی به یک عنصر UI پایدار نیاز دارید (پنل، خط وضعیت، مینی‌پلیر)
_register_extra_tui_keybindings(kb, *, input_area)افزودن کلیدهای میان‌بروقتی به کلیدمیان‌بر نیاز دارید (بازوکردن پنل‌ها، کنترل پخش، میان‌برهای مودال)
_build_tui_layout_children(**widgets)کنترل کامل بر ترتیب ویجت‌هاوقتی باید ویجت‌های موجود را جابه‌جا یا درون‌هم بپیچید (به‌ندرت)
process_command()افزودن فرمان‌های اسلش سفارشیوقتی به پردازش /mycommand نیاز دارید (هوک از قبل موجود)
_build_tui_style_dict()استایل‌های سفارشی prompt_toolkitوقتی به رنگ‌ها یا استایل‌بندی سفارشی نیاز دارید (هوک از قبل موجود)

سه‌تای اول هوک‌های محافظت‌شدهٔ جدیدند. دو‌تای آخر از قبل وجود داشتند.

۲ شروع سریع: یک CLI پوششی

#!/usr/bin/env python3
"""my_cli.py — Example wrapper CLI that extends Hermes."""

from cli import HermesCLI
from prompt_toolkit.layout import FormattedTextControl, Window
from prompt_toolkit.filters import Condition


class MyCLI(HermesCLI):

    def __init__(self, **kwargs):
        super().__init__(**kwargs)
        self._panel_visible = False

    def _get_extra_tui_widgets(self):
        """Add a toggleable info panel above the status bar."""
        cli_ref = self
        return [
            Window(
                FormattedTextControl(lambda: "📊 My custom panel content"),
                height=1,
                filter=Condition(lambda: cli_ref._panel_visible),
            ),
        ]

    def _register_extra_tui_keybindings(self, kb, *, input_area):
        """F2 toggles the custom panel."""
        cli_ref = self

        @kb.add("f2")
        def _toggle_panel(event):
            cli_ref._panel_visible = not cli_ref._panel_visible

    def process_command(self, cmd: str) -> bool:
        """Add a /panel slash command."""
        if cmd.strip().lower() == "/panel":
            self._panel_visible = not self._panel_visible
            state = "visible" if self._panel_visible else "hidden"
            print(f"Panel is now {state}")
            return True
        return super().process_command(cmd)


if __name__ == "__main__":
    cli = MyCLI()
    cli.run()

اجرا:

cd ~/.hermes/hermes-agent
source .venv/bin/activate
python my_cli.py

۳ مرجع هوک‌ها

_get_extra_tui_widgets()

فهرستی از ویجت‌های prompt_toolkit برمی‌گرداند تا در چیدمان TUI درج شوند. ویجت‌ها بین فاصله‌انداز و نوار وضعیت ظاهر می‌شوند — بالای ناحیهٔ ورودی اما پایین خروجی اصلی.

def _get_extra_tui_widgets(self) -> list:
    return []  # پیش‌فرض: بدون ویجت اضافه

هر ویجت باید یک کانتینر prompt_toolkit باشد (مثلاً Window، ConditionalContainer، HSplit). برای قابل‌روشن‌وخاموش‌شدن ویجت‌ها از ConditionalContainer یا filter=Condition(...) استفاده کنید.

from prompt_toolkit.layout import ConditionalContainer, Window, FormattedTextControl
from prompt_toolkit.filters import Condition

def _get_extra_tui_widgets(self):
    return [
        ConditionalContainer(
            Window(FormattedTextControl("Status: connected"), height=1),
            filter=Condition(lambda: self._show_status),
        ),
    ]

_register_extra_tui_keybindings(kb, *, input_area)

بعد از آن‌که هرمس کلیدهای میان‌بر خودش را ثبت کرد و قبل از ساخته‌شدن چیدمان، فراخوانی می‌شود. کلیدهای میان‌برتان را به kb اضافه کنید.

def _register_extra_tui_keybindings(self, kb, *, input_area):
    pass  # پیش‌فرض: بدون کلیدمیان‌بر اضافه

پارامترها:

  • kb — نمونهٔ KeyBindings برای اپلیکیشن prompt_toolkit
  • input_area — ویجت اصلی TextArea، اگر لازم باشد ورودی کاربر را بخوانید یا دست‌کاری کنید
def _register_extra_tui_keybindings(self, kb, *, input_area):
    cli_ref = self

    @kb.add("f3")
    def _clear_input(event):
        input_area.text = ""

    @kb.add("f4")
    def _insert_template(event):
        input_area.text = "/search "

از تداخل با کلیدهای میان‌بر داخلی خودداری کنید: Enter (ارسال)، Escape Enter (خط جدید)، Ctrl-C (وقفه)، Ctrl-D (خروج)، Tab (پذیرش پیشنهاد خودکار). کلیدهای F2 به بالا و ترکیب‌های Ctrl عموماً امن‌اند.

_build_tui_layout_children(**widgets)

فقط وقتی این را بازنویسی کنید که به کنترل کامل بر ترتیب ویجت‌ها نیاز دارید. بیشتر گسترش‌ها باید به‌جایش از _get_extra_tui_widgets() استفاده کنند.

def _build_tui_layout_children(self, *, sudo_widget, secret_widget,
    approval_widget, clarify_widget, model_picker_widget=None,
    spinner_widget=None, spacer, status_bar, input_rule_top,
    image_bar, input_area, input_rule_bot, voice_status_bar,
    completions_menu) -> list:

پیاده‌سازی پیش‌فرض این را برمی‌گرداند (هر ویجتِ None فیلتر می‌شود):

[
    Window(height=0),       # لنگر
    sudo_widget,            # پرامپت رمز sudo (شرطی)
    secret_widget,          # پرامپت ورودی رمز (شرطی)
    approval_widget,        # تأیید فرمان خطرناک (شرطی)
    clarify_widget,         # رابط پرسش شفاف‌سازی (شرطی)
    model_picker_widget,    # پوشش انتخابگر مدل (شرطی)
    spinner_widget,         # اسپینر فکر کردن (شرطی)
    spacer,                 # فضای عمودی باقی‌مانده را پر می‌کند
    *self._get_extra_tui_widgets(),  # ویجت‌های شما اینجا قرار می‌گیرند
    status_bar,             # خط وضعیت مدل/توکن/زمینه
    input_rule_top,         # ─── حاشیهٔ بالای ورودی
    image_bar,              # نشانگر تصاویر پیوست‌شده
    input_area,             # ورودی متنی کاربر
    input_rule_bot,         # ─── حاشیهٔ پایین ورودی
    voice_status_bar,       # وضعیت حالت صوتی (شرطی)
    completions_menu,       # منوی کشویی تکمیل خودکار
]

۴ نمودار چیدمان

چیدمان پیش‌فرض از بالا به پایین:

  1. ناحیهٔ خروجی — تاریخچهٔ گفتگوی اسکرول‌شونده
  2. فاصله‌انداز
  3. ویجت‌های اضافه — از _get_extra_tui_widgets()
  4. نوار وضعیت — مدل، درصد زمینه، زمان سپری‌شده
  5. نوار تصویر — تعداد تصاویر پیوست‌شده
  6. ناحیهٔ ورودی — پرامپت کاربر
  7. وضعیت صدا — نشانگر ضبط
  8. منوی تکمیل‌ها — پیشنهادهای تکمیل خودکار

۵ نکته‌ها

  • نمایش را بی‌اعتبار کنید بعد از تغییر وضعیت: برای راه‌اندازی بازترسیم prompt_toolkit، self._invalidate() را صدا بزنید.
  • دسترسی به وضعیت ایجنت: self.agent، self.model و self.conversation_history همگی در دسترس‌اند.
  • استایل‌های سفارشی: _build_tui_style_dict() را بازنویسی کنید و ورودی‌هایی برای کلاس‌های استایل سفارشی‌تان اضافه کنید.
  • فرمان‌های اسلش: process_command() را بازنویسی کنید، فرمان‌های خودتان را پردازش کنید و برای بقیهٔ موارد super().process_command(cmd) را صدا بزنید.
  • run() را بازنویسی نکنید مگر آن‌که واقعاً ضروری باشد — هوک‌های گسترش دقیقاً برای اجتناب از همان جفت‌شدگی وجود دارند.
