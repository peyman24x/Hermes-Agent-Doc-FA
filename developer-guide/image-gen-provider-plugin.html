پلاگین تولید تصویر

پلاگین‌های تولید تصویر بک‌اندی را ثبت می‌کنند که به هر فراخوانی ابزار image_generate سرویس می‌دهد — DALL·E، gpt-image، Grok، Flux، Imagen، Stable Diffusion، fal، Replicate، یک سامانهٔ محلی ComfyUI، هر چیزی. ارائه‌دهندگان داخلی (OpenAI، OpenAI-Codex، xAI، FAL، Krea، DeepInfra، OpenRouter) همگی به‌شکل پلاگین عرضه می‌شوند. می‌توانید یک ارائه‌دهندهٔ جدید اضافه کنید یا یکی از موارد همراه را بازنویسی کنید، فقط با قرار دادن یک پوشه در plugins/image_gen/<name>/.

💡

تولید تصویر یکی از چند پلاگین بک‌اندی است که Hermes پشتیبانی می‌کند. بقیه (با ABCهای تخصصی‌تر) عبارت‌اند از پلاگین ارائه‌دهندهٔ حافظه، پلاگین موتور زمینه و پلاگین ارائه‌دهندهٔ مدل. پلاگین‌های عمومی ابزار/هوک/CLI در ساخت پلاگین هرمس توضیح داده شده‌اند.

۱ نحوهٔ کشف

هرمس بک‌اندهای تولید تصویر را در سه جا اسکن می‌کند:

  1. همراه بسته — <repo>/plugins/image_gen/<name>/ (به‌طور خودکار با kind: backend بارگذاری می‌شود، همیشه در دسترس)
  2. کاربر — ~/.hermes/plugins/image_gen/<name>/ (با انتخاب از طریق plugins.enabled)
  3. Pip — پکیج‌هایی که یک نقطهٔ ورودی hermes_agent.plugins اعلام می‌کنند

تابع register(ctx) هر پلاگین ctx.register_image_gen_provider(...) را صدا می‌زند — این کار آن را در رجیستریِ agent/image_gen_registry.py قرار می‌دهد. ارائه‌دهندهٔ فعال با image_gen.provider در config.yaml انتخاب می‌شود؛ hermes tools کاربر را قدم‌به‌قدم برای انتخاب راهنمایی می‌کند.

رَپِر ابزار image_generate از رجیستری ارائه‌دهندهٔ فعال را می‌گیرد و فراخوانی را به آنجا می‌فرستد. اگر هیچ ارائه‌دهنده‌ای ثبت نشده باشد، ابزار یک خطای راهنما نشان می‌دهد که به hermes tools اشاره می‌کند.

۲ ساختار پوشه

plugins/image_gen/my-backend/
├── __init__.py      # زیرکلاس ImageGenProvider + register()
└── plugin.yaml      # مانیفست با kind: backend

یک پلاگین همراه بسته در همین نقطه کامل است. پلاگین‌های کاربر در ~/.hermes/plugins/image_gen/<name>/ باید به plugins.enabled در config.yaml اضافه شوند (یا hermes plugins enable <name> را اجرا کنید).

۳ کلاس انتزاعی ImageGenProvider

زیرکلاسی از agent.image_gen_provider.ImageGenProvider بسازید. تنها اعضای الزامی، پراپرتی name و متد generate() هستند — بقیه پیش‌فرض‌های منطقی دارند:

# plugins/image_gen/my-backend/__init__.py
from typing import Any, Dict, List, Optional
import os

from agent.image_gen_provider import (
    DEFAULT_ASPECT_RATIO,
    ImageGenProvider,
    error_response,
    normalize_reference_images,
    resolve_aspect_ratio,
    save_b64_image,
    success_response,
)


class MyBackendImageGenProvider(ImageGenProvider):
    @property
    def name(self) -> str:
        # شناسهٔ پایدار برای استفاده در کانفیگ image_gen.provider. حروف کوچک، بدون فاصله.
        return "my-backend"

    @property
    def display_name(self) -> str:
        # برچسب انسانی که در `hermes tools` نشان داده می‌شود. اگر حذف شود به‌طور پیش‌فرض name.title() است.
        return "My Backend"

    def is_available(self) -> bool:
        # اگر اعتبارنامه‌ها یا وابستگی‌ها غایب‌اند False برگردانید.
        # گیتِ در دسترس‌بودن ابزار پیش از dispatch این را صدا می‌زند.
        if not os.environ.get("MY_BACKEND_API_KEY"):
            return False
        try:
            import my_backend_sdk  # noqa: F401
        except ImportError:
            return False
        return True

    def list_models(self) -> List[Dict[str, Any]]:
        # کاتالوگی که در انتخابگر مدل `hermes tools` نمایش داده می‌شود.
        return [
            {
                "id": "my-model-fast",
                "display": "My Model (Fast)",
                "speed": "~5s",
                "strengths": "Quick iteration",
                "price": "$0.01/image",
            },
            {
                "id": "my-model-hq",
                "display": "My Model (HQ)",
                "speed": "~30s",
                "strengths": "Highest fidelity",
                "price": "$0.04/image",
            },
        ]

    def default_model(self) -> Optional[str]:
        return "my-model-fast"

    def get_setup_schema(self) -> Dict[str, Any]:
        # متادیتا برای انتخابگر `hermes tools` — کلیدهایی که هنگام راه‌اندازی پرسیده می‌شوند.
        return {
            "name": "My Backend",
            "badge": "paid",        # اختیاری؛ به‌شکل برچسب کوتاه در انتخابگر نمایش داده می‌شود
            "tag": "One-line description shown under the name",
            "env_vars": [
                {
                    "key": "MY_BACKEND_API_KEY",
                    "prompt": "My Backend API key",
                    "url": "https://my-backend.example.com/api-keys",
                },
            ],
        }

    def capabilities(self) -> Dict[str, Any]:
        # اعلام کنید که این بک‌اند از image-to-image / ویرایش پشتیبانی می‌کند یا نه.
        # لایهٔ ابزار این را در اسکیمای داینامیک نشان می‌دهد تا مدل بداند
        # چه زمانی `image_url` پردازش می‌شود. پیش‌فرض (اگر این را
        # نیاورید) فقط-متنی است: {"modalities": ["text"], "max_reference_images": 0}.
        return {"modalities": ["text", "image"], "max_reference_images": 4}

    def generate(
        self,
        prompt: str,
        aspect_ratio: str = DEFAULT_ASPECT_RATIO,
        *,
        image_url: Optional[str] = None,
        reference_image_urls: Optional[List[str]] = None,
        **kwargs: Any,
    ) -> Dict[str, Any]:
        prompt = (prompt or "").strip()
        aspect_ratio = resolve_aspect_ratio(aspect_ratio)

        if not prompt:
            return error_response(
                error="Prompt is required",
                error_type="invalid_input",
                provider=self.name,
                prompt="",
                aspect_ratio=aspect_ratio,
            )

        # مسیریابی: اگر image_url (یا reference_image_urls) تنظیم شده باشد، فراخوانی
        # یک درخواست image-to-image / ویرایش است؛ در غیر این صورت text-to-image.
        # مسیر طی‌شده را از طریق فیلد `modality` در success_response گزارش کنید.
        sources = []
        if image_url:
            sources.append(image_url)
        sources.extend(normalize_reference_images(reference_image_urls) or [])
        modality = "image" if sources else "text"

        # ترتیب اولویت انتخاب مدل: متغیر محیطی → کانفیگ → پیش‌فرض. تابع کمکی
        # _resolve_model() در پلاگین داخلی openai یک مرجع خوب است.
        model_id = kwargs.get("model") or self.default_model() or "my-model-fast"

        try:
            import my_backend_sdk
            client = my_backend_sdk.Client(api_key=os.environ["MY_BACKEND_API_KEY"])
            if modality == "image":
                result = client.edit(
                    prompt=prompt,
                    model=model_id,
                    image_urls=sources,
                )
            else:
                result = client.generate(
                    prompt=prompt,
                    model=model_id,
                    aspect_ratio=aspect_ratio,
                )

            # دو شکل پشتیبانی می‌شود:
            #   - رشتهٔ URL: آن را به‌عنوان `image` برگردانید
            #   - دادهٔ base64: با save_b64_image() زیر $HERMES_HOME/cache/images/ ذخیره کنید
            if result.get("image_b64"):
                path = save_b64_image(
                    result["image_b64"],
                    prefix=self.name,
                    extension="png",
                )
                image = str(path)
            else:
                image = result["image_url"]

            return success_response(
                image=image,
                model=model_id,
                prompt=prompt,
                aspect_ratio=aspect_ratio,
                provider=self.name,
                modality=modality,
            )
        except Exception as exc:
            return error_response(
                error=str(exc),
                error_type=type(exc).__name__,
                provider=self.name,
                model=model_id,
                prompt=prompt,
                aspect_ratio=aspect_ratio,
            )


def register(ctx) -> None:
    """نقطهٔ ورود پلاگین — یک‌بار در زمان بارگذاری صدا زده می‌شود."""
    ctx.register_image_gen_provider(MyBackendImageGenProvider())

۴ plugin.yaml

name: my-backend
version: 1.0.0
description: My image backend — text-to-image via My Backend SDK
author: Your Name
kind: backend
requires_env:
  - MY_BACKEND_API_KEY

kind: backend همان چیزی است که پلاگین را به مسیر ثبتِ تولید تصویر هدایت می‌کند. requires_env هنگام hermes plugins install از کاربر پرسیده می‌شود.

۵ مرجع کلاس انتزاعی

قرارداد کامل در agent/image_gen_provider.py است. متدهایی که معمولاً بازنویسی می‌کنید:

عضوالزامیپیش‌فرضهدف
name✅—شناسهٔ پایدار استفاده‌شده در کانفیگ image_gen.provider
display_name—name.title()برچسب نمایش‌داده‌شده در hermes tools
is_available()—Trueگیت برای نبود اعتبارنامه/وابستگی
list_models()—[]کاتالوگ برای انتخابگر مدلِ hermes tools
default_model()—اولین مورد از list_models()پشتیبان وقتی هیچ مدلی پیکربندی نشده
get_setup_schema()—حداقلیمتادیتای انتخابگر + پرامپت‌های متغیر محیطی
generate(prompt, aspect_ratio, **kwargs)✅—خودِ فراخوانی

۶ قالب پاسخ

generate() باید دیکشنری‌ای برگرداند که با success_response() یا error_response() ساخته شده باشد. هر دو در agent/image_gen_provider.py توضیح داده شده‌اند.

موفقیت:

success_response(
    image=<url-or-absolute-path>,
    model=<model-id>,
    prompt=<echoed-prompt>,
    aspect_ratio="landscape" | "square" | "portrait",
    provider=<your-provider-name>,
    extra={...},  # فیلدهای اختیاری مخصوص بک‌اند
)

خطا:

error_response(
    error="human-readable message",
    error_type="provider_error" | "invalid_input" | "<exception class name>",
    provider=<your-provider-name>,
    model=<model-id>,
    prompt=<prompt>,
    aspect_ratio=<resolved aspect>,
)

رَپِر ابزار دیکشنری را JSON-سری می‌کند و به LLM می‌دهد. خطاها به‌عنوان نتیجهٔ ابزار به سطح می‌آیند؛ این LLM است که تصمیم می‌گیرد چگونه آن‌ها را به کاربر توضیح دهد.

۷ مدیریت خروجی base64 در برابر URL

بعضی بک‌اندها URL تصویر برمی‌گردانند (fal، Replicate)؛ بعضی دیگر payloadهای base64 (gpt-image-2 از OpenAI). برای حالت base64 از save_b64_image() استفاده کنید — این تابع در $HERMES_HOME/cache/images/<prefix>_<timestamp>_<uuid>.<ext> می‌نویسد و Path مطلق برمی‌گرداند. آن مسیر را (به‌شکل str) به‌عنوان image= در success_response() بدهید. تحویل گیت‌وی (حباب عکس تلگرام، پیوست دیسکورد) هم URLها و هم مسیرهای مطلق را می‌شناسد.

۸ بازنویسی‌های کاربر

یک پلاگین کاربر در ~/.hermes/plugins/image_gen/<name>/ با همان پراپرتی nameِ یک پلاگین همراه بیندازید و با hermes plugins enable <name> فعالش کنید — رجیستری last-writer-wins است، پس نسخهٔ شما جای داخلی را می‌گیرد. برای نشانه‌کردن پلاگین openai به یک پروکسی خصوصی، یا جای‌گذاری یک کاتالوگ مدل سفارشی مفید است.

۹ تست

export HERMES_HOME=/tmp/hermes-imggen-test
mkdir -p $HERMES_HOME/plugins/image_gen/my-backend
# …__init__.py و plugin.yaml را در آن پوشه کپی کنید…

export MY_BACKEND_API_KEY=your-test-key
hermes plugins enable my-backend

# آن را به‌عنوان ارائه‌دهندهٔ فعال انتخاب کنید
echo "image_gen:" >> $HERMES_HOME/config.yaml
echo "  provider: my-backend" >> $HERMES_HOME/config.yaml

# امتحانش کنید
hermes -z "Generate an image of a corgi in a spacesuit"

یا به‌شکل تعاملی: hermes tools ← «Image Generation» ← انتخاب my-backend ← در صورت درخواست، کلید API را وارد کنید.

۱۰ پیاده‌سازی‌های مرجع

  • plugins/image_gen/openai/__init__.py — gpt-image-2 در سه سطح low/medium/high به‌شکل سه شناسهٔ مدل مجازی که یک مدل API را با پارامترهای quality متفاوت به اشتراک می‌گذارند. نمونهٔ خوبی از مدل‌های سطح‌بندی‌شده زیر یک بک‌اند + زنجیرهٔ اولویت config.yaml.
  • plugins/image_gen/xai/__init__.py — Grok Imagine از طریق xAI. شکلی متفاوت (خروجی URL، کاتالوگ ساده‌تر).
  • plugins/image_gen/openai-codex/__init__.py — نوع Responses API به سبک Codex که SDK اوپن‌ای‌آی را با یک URL پایهٔ مسیریابی متفاوت بازاستفاده می‌کند.

۱۱ توزیع از طریق pip

# pyproject.toml
[project.entry-points."hermes_agent.plugins"]
my-backend-imggen = "my_backend_imggen_package"

my_backend_imggen_package باید یک تابع register سطح‌بالا در معرض بگذارد. برای راه‌اندازی کامل، توزیع از طریق pip را در راهنمای عمومی پلاگین ببینید.
