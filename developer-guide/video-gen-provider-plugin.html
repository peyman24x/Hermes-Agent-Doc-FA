پلاگین تولید ویدیو

پلاگین‌های ارائه‌دهندهٔ تولید ویدیو، بک‌اندی ثبت می‌کنند که تمام فراخوانی‌های ابزار video_generate را پاسخ می‌دهد. ارائه‌دهندگان داخلی (xAI، FAL، OpenRouter و DeepInfra) به‌صورت پلاگین عرضه می‌شوند. با قراردادن یک پوشه در plugins/video_gen/<name>/، ارائه‌دهندهٔ جدیدی اضافه کنید یا یکی از ارائه‌دهندگان همراه برنامه را جایگزین کنید.

💡 نکته

تولید ویدیو تقریباً خط‌به‌خط از الگوی پلاگین‌های ارائه‌دهندهٔ تولید تصویر پیروی می‌کند — اگر بک‌اند تولید تصویر ساخته‌اید، از قبل با ساختار آن آشنا هستید. تفاوت‌های اصلی عبارت‌اند از متد capabilities() برای اعلام نوع ورودی‌ها، نسبت‌های تصویر و مدت‌زمان‌ها، و یک قرارداد مسیریابی (برای تبدیل تصویر به ویدیو، image_url را بفرستید؛ برای تبدیل متن به ویدیو، آن را حذف کنید — ارائه‌دهنده در داخل خود نقطهٔ پایانی مناسب را انتخاب می‌کند).

۱ رابط یکپارچه (یک ابزار، دو نوع ورودی)

ابزار video_generate از طریق یک پارامتر، دو نوع ورودی را در دسترس قرار می‌دهد:

  • متن به ویدیو — فقط با prompt فراخوانی کنید. ارائه‌دهنده درخواست را به نقطهٔ پایانی متن‌به‌ویدیوی خود هدایت می‌کند.
  • تصویر به ویدیو — با prompt + image_url فراخوانی کنید. ارائه‌دهنده درخواست را به نقطهٔ پایانی تصویربه‌ویدیوی خود هدایت می‌کند.

ویرایش و افزایش طول ویدیو عمداً خارج از محدوده‌اند. بیشتر بک‌اندها از آن‌ها پشتیبانی نمی‌کنند و این ناهماهنگی باعث می‌شد توضیحات مختص هر بک‌اند به شرح ابزار ایجنت تحمیل شود.

۲ سازوکار کشف

هرمس در سه محل به‌دنبال بک‌اندهای تولید ویدیو می‌گردد:

  1. همراه برنامه — <repo>/plugins/video_gen/<name>/ (بارگذاری خودکار با kind: backend)
  2. کاربر — ~/.hermes/plugins/video_gen/<name>/ (فعال‌سازی اختیاری از طریق plugins.enabled)
  3. Pip — بسته‌هایی که یک نقطهٔ ورود hermes_agent.plugins اعلام می‌کنند

تابع register(ctx) هر پلاگین، ctx.register_video_gen_provider(...) را فراخوانی می‌کند. ارائه‌دهندهٔ فعال با video_gen.provider در config.yaml انتخاب می‌شود؛ بخش «تولید ویدیو» در hermes tools کاربران را در فرایند انتخاب راهنمایی می‌کند. برخلاف image_generate، هیچ بک‌اند قدیمی در درخت کد وجود ندارد — هر ارائه‌دهنده یک پلاگین است.

۳ ساختار پوشه

plugins/video_gen/my-backend/
├── __init__.py      # VideoGenProvider subclass + register()
└── plugin.yaml      # Manifest with kind: backend

۴ کلاس پایهٔ انتزاعی VideoGenProvider

از agent.video_gen_provider.VideoGenProvider زیرکلاس بسازید. موارد الزامی: ویژگی name و متد generate().

# plugins/video_gen/my-backend/__init__.py
from typing import Any, Dict, List, Optional
import os

from agent.video_gen_provider import (
    VideoGenProvider,
    error_response,
    success_response,
)


class MyVideoGenProvider(VideoGenProvider):
    @property
    def name(self) -> str:
        return "my-backend"

    @property
    def display_name(self) -> str:
        return "My Backend"

    def is_available(self) -> bool:
        return bool(os.environ.get("MY_API_KEY"))

    def list_models(self) -> List[Dict[str, Any]]:
        # Each entry is a model FAMILY — a name the user picks once.
        # Your provider's generate() routes within the family based on
        # whether image_url was passed.
        return [
            {
                "id": "fast",
                "display": "Fast",
                "speed": "~30s",
                "strengths": "Cheapest tier",
                "price": "$0.05/s",
                "modalities": ["text", "image"],  # advisory
            },
        ]

    def default_model(self) -> Optional[str]:
        return "fast"

    def capabilities(self) -> Dict[str, Any]:
        return {
            "modalities": ["text", "image"],
            "aspect_ratios": ["16:9", "9:16"],
            "resolutions": ["720p", "1080p"],
            "min_duration": 1,
            "max_duration": 10,
            "supports_audio": False,
            "supports_negative_prompt": True,
            "max_reference_images": 0,
        }

    def get_setup_schema(self) -> Dict[str, Any]:
        return {
            "name": "My Backend",
            "badge": "paid",
            "tag": "Short description shown in `hermes tools`",
            "env_vars": [
                {
                    "key": "MY_API_KEY",
                    "prompt": "My Backend API key",
                    "url": "https://mybackend.example.com/keys",
                },
            ],
        }

    def generate(
        self,
        prompt: str,
        *,
        model: Optional[str] = None,
        image_url: Optional[str] = None,
        reference_image_urls: Optional[List[str]] = None,
        duration: Optional[int] = None,
        aspect_ratio: str = "16:9",
        resolution: str = "720p",
        negative_prompt: Optional[str] = None,
        audio: Optional[bool] = None,
        seed: Optional[int] = None,
        **kwargs: Any,  # always ignore unknown kwargs for forward-compat
    ) -> Dict[str, Any]:
        # ROUTE: image_url presence picks the endpoint.
        if image_url:
            endpoint = "my-backend/image-to-video"
            modality_used = "image"
        else:
            endpoint = "my-backend/text-to-video"
            modality_used = "text"

        # ... call your API ...

        return success_response(
            video="https://your-cdn/output.mp4",
            model=model or "fast",
            prompt=prompt,
            modality=modality_used,
            aspect_ratio=aspect_ratio,
            duration=duration or 5,
            provider=self.name,
        )


def register(ctx) -> None:
    ctx.register_video_gen_provider(MyVideoGenProvider())

۶ طرح‌وارهٔ video_generate

ابزار برای همهٔ بک‌اندها یک طرح‌وارهٔ واحد ارائه می‌کند. ارائه‌دهندگان پارامترهایی را که پشتیبانی نمی‌کنند نادیده می‌گیرند.

پارامترکارکرد
promptدستور متنی (الزامی)
image_urlوقتی تنظیم شود: تصویر به ویدیو؛ وقتی حذف شود: متن به ویدیو
reference_image_urlsتصاویر مرجع سبک/شخصیت (وابسته به ارائه‌دهنده)
durationثانیه — ارائه‌دهنده مقدار را به محدودهٔ مجاز محدود می‌کند
aspect_ratio"16:9"، "9:16"، "1:1"، ... — ارائه‌دهنده مقدار را به محدودهٔ مجاز محدود می‌کند
resolution"480p" / "540p" / "720p" / "1080p" — ارائه‌دهنده مقدار را به محدودهٔ مجاز محدود می‌کند
negative_promptمحتوایی که باید از آن پرهیز شود (فقط Pixverse/Kling)
audioصدای بومی (ردهٔ قیمت‌گذاری Veo3 / Pixverse)
seedبازتولیدپذیری
modelجایگزینی مدل/خانوادهٔ فعال

متد capabilities() ارائه‌دهنده اعلام می‌کند کدام‌یک از این پارامترها اعمال می‌شوند. ایجنت قابلیت‌های بک‌اند فعال را در شرح ابزار می‌بیند؛ این شرح هنگام تغییر بک‌اند توسط کاربر از طریق hermes tools به‌صورت پویا بازسازی می‌شود.

۷ خانواده‌های مدل و مسیریابی نقطهٔ پایانی (الگوی FAL)

وقتی بک‌اند شما برای هر «مدل» چند نقطهٔ پایانی دارد — مانند FAL که در آن هر خانواده (Veo 3.1، Pixverse v6 و Kling O3) هم نشانی /text-to-video دارد و هم /image-to-video — هر خانواده را با یک ورودی در فهرست مدل‌ها نمایش دهید. متد generate() شما بر اساس ارسال‌شدن یا نشدن image_url، نقطهٔ پایانی مناسب را انتخاب می‌کند:

}

۸ ترتیب اولویت انتخاب

برای تنظیمات مدل در هر نمونه (به plugins/video_gen/fal/__init__.py مراجعه کنید):

  1. آرگومان کلیدواژه‌ای model= از فراخوانی ابزار
  2. متغیر محیطی <PROVIDER>_VIDEO_MODEL
  3. video_gen.<provider>.model در config.yaml
  4. video_gen.model در config.yaml (وقتی یکی از شناسه‌های شما باشد)
  5. default_model() ارائه‌دهنده

۹ ساختار پاسخ

success_response() و error_response() ساختار دیکشنری‌ای را تولید می‌کنند که همهٔ بک‌اندها برمی‌گردانند. از آن‌ها استفاده کنید — دیکشنری را دستی نسازید.

کلیدهای موفقیت: success، video (نشانی اینترنتی یا مسیر مطلق)، model، prompt، modality ("text" یا "image")، aspect_ratio، duration، provider، به‌علاوهٔ extra.

کلیدهای خطا: success، video (None)، error، error_type، model، prompt، aspect_ratio، provider.

۱۰ محل ذخیرهٔ فایل‌های خروجی

اگر بک‌اند شما base64 برمی‌گرداند، برای نوشتن آن در $HERMES_HOME/cache/videos/ از save_b64_video() استفاده کنید. برای بایت‌های خام حاصل از دریافت HTTP بعدی، از save_bytes_video() استفاده کنید. در غیر این صورت، نشانی اینترنتی سرویس بالادستی را مستقیماً برگردانید — گیت‌وی هنگام تحویل، نشانی‌های راه‌دور را پردازش می‌کند.

۱۱ آزمون

یک آزمون اولیه (smoke test) در tests/plugins/video_gen/test_<name>_plugin.py قرار دهید. آزمون‌های xAI و FAL این الگو را نشان می‌دهند — ثبت ارائه‌دهنده، بررسی فهرست مدل‌ها، آزمودن مسیریابی هم با image_url و هم بدون آن، و اطمینان از بازگشت پاسخ‌های خطای مناسب هنگام نبود اطلاعات احراز هویت.
