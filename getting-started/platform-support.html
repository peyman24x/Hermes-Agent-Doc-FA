پشتیبانی پلتفرم‌ها

هرمس ایجنت از پلتفرم‌ها و روش‌های توزیع زیادی پشتیبانی می‌کند، اما نمی‌توانیم از هر روش نصبِ ممکن پشتیبانی کنیم.

۱ ردهٔ ۱ (Tier 1)

تلاش می‌کنیم نصب و به‌روزرسانی روی این‌ها هرگز نشکند. مشکلات و رگرسیون‌های ردهٔ ۱ اولویت اول ما هستند و بر سایر پلتفرم‌ها مقدم‌اند.

سیستم‌عامل / معماریروش‌های نصبنکته‌ها
مک‌اواس (Apple Silicon) Hermes Desktop، install.sh
ویندوز ۱۰ / ۱۱ (x86_64، aarch64) Hermes Desktop، install.ps1 چند قابلیت در دسترس نیستند.
لینوکس / WSL2 (x86_64، aarch64) install.sh روی آخرین اوبونتو و WSL2 تست می‌کنیم. اگر توزیع شما glibc، systemd دارد و استاندارد سلسله‌مراتب فایل‌سیستم (FHS) را رعایت می‌کند، احتمالاً خیلی خوب کار می‌کند.
کانتینر داکر (x86_64، aarch64) docker pull نصب‌های داکری از hermes update پشتیبانی نمی‌کنند. به‌روزرسانی با اجرای ایمیج جدید انجام می‌شود.

۲ ردهٔ ۲ (Tier 2)

این پلتفرم‌ها فقط به‌صورت «در حد توان» و در همان درخت کد نگهداری می‌شوند. ممکن است انتشارها آن‌ها را بشکند و نمی‌توانیم قول بدهیم سریع تعمیرشان کنیم.

پرِ fix کردن مشکلات‌شان پذیرفته می‌شود، اما اولویت‌شان پایین‌تر از رفع مشکلات پلتفرم‌های ردهٔ ۱ است.

سیستم‌عامل / معماریروش‌های نصبنکته‌ها
اندروید (Termux) (aarch64) install.sh چند قابلیت در دسترس نیستند.
Nix (مک، لینوکس، NixOS) راهنمای Nix به‌واسطهٔ دردسرهای بسته‌بندی Node.js مرتب می‌شکند. موفق باشید! ♥

۳ پشتیبانی‌نشده

این پلتفرم‌ها و روش‌های توزیع پشتیبانی نمی‌شوند. پیشنهاد می‌کنیم به روش توزیع یا پلتفرم پشتیبانی‌شده مهاجرت کنید. ممکن است همین الان هم خراب باشند و ممکن است در آینده بیشتر خراب شوند. پرِ fix کردن آن‌ها پذیرفته نمی‌شود و هر کدی که سازگاری با آن‌ها را نگه دارد ممکن است هر لحظه حذف شود.

  • نصب از طریق AUR (اگر کمک کند ممکن است وصله‌ها را بالادستی کنیم ♥)
  • مک‌اواس روی پردازنده‌های x86 (اینتل)
  • نصب از طریق pypi (مثل uv tool install hermes-agent، pip install hermes-agent و غیره)
  • نصب از طریق brew (brew install hermes-agent)

اگر از روش توزیعِ پشتیبانی‌نشده استفاده می‌کنید، لطفاً راهنمای نصب را بخوانید تا ببینید چگونه به روش پشتیبانی‌شده سوییچ کنید.
