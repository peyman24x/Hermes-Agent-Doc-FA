شروع سریع — اولین گفتگو

این راهنما شما را از صفر به یک راه‌اندازی کاریِ هرمس می‌رساند که در استفادهٔ واقعی هم دوام می‌آورد. نصب می‌کنید، یک ارائه‌دهنده انتخاب می‌کنید، یک گفتگوی درست‌وحساب را تأیید می‌کنید، و دقیقاً می‌دانید وقتی چیزی خراب شد چه‌کار کنید.

🎬 ترجیح می‌دهید تماشا کنید؟ (نیازمند اینترنت)

گروه Onchain AI Garage یک آموزش جامع (Masterclass) از نصب، راه‌اندازی و فرمان‌های پایه تهیه کرده — همراه خوبی برای این صفحه است اگر دوست دارید ویدیویی پیش بروید. برای بیشتر، پلی‌لیست کامل Hermes Agent Tutorials & Use Cases را ببینید.

۱ این راهنما برای چه کسی است؟

  • تازه‌کار هستید و کوتاه‌ترین مسیرِ رسیدن به یک راه‌اندازی کاری را می‌خواهید
  • ارائه‌دهنده‌تان را عوض می‌کنید و نمی‌خواهید وقتتان صرف خطاهای پیکربندی شود
  • هرمس را برای یک تیم، بات یا گردش‌کار همیشه‌روشن راه‌اندازی می‌کنید
  • از «نصب شد، ولی هنوز هیچ کاری نمی‌کند» خسته شده‌اید

قاعدهٔ سرانگشتی: اگر هرمس نمی‌تواند یک گفتگوی عادی را کامل کند، هنوز قابلیت بیشتری اضافه نکنید. اول یک گفتگوی تمیز را کار بیندازید، بعد لایه‌های گیت‌وی، کرون، مهارت، صوت یا مسیریابی را اضافه کنید.

۳ گام ۱ — نصب Hermes Agent

با نصب‌کنندهٔ Hermes Desktop در مک یا ویندوز (توصیه‌شده)

برای نصب آسانِ هم‌زمانِ اپلیکیشن‌های خط فرمان و دسکتاپ، نصب‌کنندهٔ Hermes Desktop را از وب‌سایت ما دانلود و اجرا کنید.

بدون Hermes Desktop

برای نصبِ فقط-خط‌فرمان، این را اجرا کنید:

لینوکس / مک / WSL2 / اندروید (Termux)

bash
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

ویندوز (بومی)

در PowerShell اجرا کنید:

powershell
iex (irm https://hermes-agent.nousresearch.com/install.ps1)
💡 اندروید / Termux

اگر روی گوشی نصب می‌کنید، به راهنمای اختصاصی «Termux» مراجعه کنید؛ شامل مسیر دستیِ تست‌شده، امکانات جانبیِ پشتیبانی‌شده و محدودیت‌های فعلی مخصوص اندروید.

پس از پایان نصب، شل را دوباره بارگذاری کنید:

bash
source ~/.bashrc   # یا source ~/.zshrc

برای جزئیات کامل نصب، پیش‌نیازها و عیب‌یابی، به راهنمای نصب مراجعه کنید.

۴ گام ۲ — انتخاب ارائه‌دهنده

مهم‌ترین گام راه‌اندازی همین است. با hermes model به‌صورت تعاملی انتخاب را انجام دهید:

bash
hermes model
💡 آسان‌ترین مسیر: Nous Portal

یک اشتراک بیش از ۳۰۰ مدل را پوشش می‌دهد به‌علاوهٔ گیت‌وی ابزار (جستجوی وب، تولید تصویر، TTS، مرورگر ابری). روی یک نصب تازه:

bash
hermes setup --portal

این فرمان شما را وارد حساب می‌کند، Nous را به‌عنوان ارائه‌دهنده تنظیم می‌کند و گیت‌وی ابزار را در یک دستور فعال می‌کند.

ℹ️ حالت‌های راه‌اندازی (Setup)

روی یک نصب تازه، hermes setup سه حالت پیشنهاد می‌دهد:

  • راه‌اندازی سریع (Nous Portal) — ورود OAuth رایگان، بدون کلید API؛ یک مدل به‌علاوهٔ ابزارهای گیت‌وی ابزار را تنظیم می‌کند. مسیر سریعِ توصیه‌شده.
  • راه‌اندازی کامل — خودتان از میان همهٔ ارائه‌دهنده‌ها، ابزارها و گزینه‌ها عبور می‌کنید (کلیدهای خودتان را بیاورید).
  • تختهٔ خالی (Blank Slate) — همه‌چیز جز حداقلِ لازم برای اجرای یک ایجنت خاموش شروع می‌شود: ارائه‌دهنده و مدل، تول‌ست عملیات فایل، و تول‌ست ترمینال. بدون وب، مرورگر، اجرای کد، بینایی، حافظه، واگذاری، کرون، مهارت، پلاگین یا سرور MCP — و فشرده‌سازی، چک‌پوینت، مسیریابی هوشمند و ثبت حافظه همگی غیرفعال‌اند. پس از اعمالِ خط پایهٔ مینیمال، یکی از دو مسیر را انتخاب می‌کنید: «همه‌چیز خاموش شروع کن» (همین حالا با ایجنت مینیمال تمام کنید) یا «از تمام پیکربندی‌ها عبور کن» (ابزارها، مهارت‌ها، پلاگین‌ها، MCP و پیام‌رسانی را خودتان فعال کنید). این حالت را انتخاب کنید وقتی یک ایجنت مینیمالِ کاملاً کنترل‌شده می‌خواهید و قصد دارید دقیقاً و فقط چیزی را که لازم دارید فعال کنید.

حالت Blank Slate یک فهرست صریح platform_toolsets.cli به‌همراه agent.disabled_toolsets می‌نویسد، پس هیچ چیزی که انتخاب نکرده‌اید هرگز بارگذاری نمی‌شود — حتی بعد از hermes update. هر چیز را بعداً با hermes tools فعال کنید، مهارت‌ها را با hermes skills opt-in --sync بکارید، یا تنظیمات را با hermes setup agent تنظیم کنید.

برای اغلب کاربران تازه‌کار: یک ارائه‌دهنده انتخاب کنید و پیش‌فرض‌ها را بپذیرید، مگر اینکه بدانید چرا می‌خواهید تغییرشان دهید. کاتالوگ کامل ارائه‌دهندگان به‌همراه متغیرهای محیطی و مراحل راه‌اندازی در صفحهٔ «ارائه‌دهندگان» قرار دارد.

⛔ حداقل زمینه (Context): ۶۴ هزار توکن

هرمس ایجنت به مدلی با حداقل ۶۴٬۰۰۰ توکن زمینه نیاز دارد. مدل‌های با پنجرهٔ کوچک‌تر نمی‌توانند حافظهٔ کاریِ لازم برای گردش‌کارهای چندمرحله‌ایِ فراخوانی ابزار را حفظ کنند و هنگام راه‌اندازی رد می‌شوند. اغلب مدل‌های میزبانی‌شده (Claude، GPT، Gemini، Qwen، DeepSeek) به‌راحتی این حد را دارند. اگر مدل محلی اجرا می‌کنید، اندازهٔ زمینه را روی حداقل ۶۴K تنظیم کنید (مثلاً --ctx-size 65536 برای llama.cpp یا -c 65536 برای Ollama).

💡 بدون قفل‌شدگی

هر زمان خواستید می‌توانید با hermes model ارائه‌دهنده را عوض کنید. برای فهرست کامل همهٔ ارائه‌دهندگان و جزئیات راه‌اندازی به «ارائه‌دهندگان هوش مصنوعی» مراجعه کنید.

تنظیمات کجا ذخیره می‌شوند؟

هرمس رمزها را از پیکربندی عادی جدا نگه می‌دارد:

  • رمزها و توکن‌ها ← ~/.hermes/.env
  • تنظیمات غیررمزی ← ~/.hermes/config.yaml

آسان‌ترین راهِ درست‌نوشتن مقادیر، استفاده از CLI است:

bash
hermes config set model anthropic/claude-opus-4.6
hermes config set terminal.backend docker
hermes config set OPENROUTER_API_KEY sk-or-...

مقدار درست به‌طور خودکار به فایل درست می‌رود.

۵ گام ۳ — اولین گفتگو را اجرا کنید

bash
hermes            # CLI کلاسیک
hermes --tui      # TUI مدرن (توصیه‌شده)

یک بنر خوش‌آمدگویی با مدل شما، ابزارهای موجود و مهارت‌ها خواهید دید. از پرامپتی استفاده کنید که مشخص و راحتِ تأیید باشد:

💡 رابط خود را انتخاب کنید

هرمس با دو رابط ترمینال عرضه می‌شود: CLI کلاسیکِ prompt_toolkit و TUI جدیدتر با اورلی‌های مودال، انتخاب با موس و ورودی غیرمسدودکننده. هر دو یک نشست‌ها، فرمان‌های اسلش و پیکربندی مشترک دارند — هر کدام را با hermes و hermes --tui امتحان کنید.

پرامپت پیشنهادی
Summarize this repo in 5 bullets and tell me what the main entrypoint is.
پرامپت پیشنهادی
Check my current directory and tell me what looks like the main project file.
پرامپت پیشنهادی
Help me set up a clean GitHub PR workflow for this codebase.

ظاهرِ موفقیت چه هست؟

  • بنر مدل/ارائه‌دهندهٔ انتخابیِ شما را نشان می‌دهد
  • هرمس بدون خطا پاسخ می‌دهد
  • در صورت نیاز می‌تواند از ابزار استفاده کند (ترمینال، خواندن فایل، جستجوی وب)
  • گفتگو برای بیش از یک نوبت به‌طور عادی ادامه پیدا می‌کند

اگر این کار کرد، از سخت‌ترین بخش عبور کرده‌اید.

۶ گام ۴ — کار کردن نشست‌ها را تأیید کنید

قبل از ادامه، مطمئن شوید ازسرگیری (resume) کار می‌کند:

bash
hermes --continue    # ازسرگیری جدیدترین نشست
hermes -c            # شکل کوتاه

باید شما را به همان نشستی که همین الان داشتید برگرداند. اگر برنگشت، بررسی کنید آیا در همان پروفایل هستید و آیا نشست واقعاً ذخیره شده است. این بعداً وقتی با چند راه‌اندازی یا چند ماشین سروکار دارید اهمیت پیدا می‌کند.

۷ گام ۵ — قابلیت‌های کلیدی را امتحان کنید

استفاده از ترمینال

پرامپت
❯ What's my disk usage? Show the top 5 largest directories.

ایجنت از طرف شما دستورات ترمینال را اجرا و نتایج را نشان می‌دهد.

فرمان‌های اسلش

/ را تایپ کنید تا فهرست تکمیل-خودکار همهٔ فرمان‌ها باز شود:

فرمانچه می‌کند
/helpنمایش همهٔ فرمان‌های موجود
/toolsفهرست ابزارهای موجود

ورودی چندخطی

برای افزودن خط جدید، Alt+Enter، Ctrl+J یا Shift+Enter را بزنید. Shift+Enter به ترمینالی نیاز دارد که آن را به‌صورت دنباله‌ای مجزا بفرستد (به‌طور پیش‌فرض Kitty / foot / WezTerm / Ghostty؛ iTerm2 / Alacritty / ترمینال VS Code پس از فعال‌سازی پروتکل کیبورد Kitty). Alt+Enter و Ctrl+J در همهٔ ترمینال‌ها کار می‌کنند.

قطع کردن ایجنت

اگر ایجنت زیادی طول می‌کشد، یک پیام جدید تایپ کرده و Enter بزنید — کار فعلی قطع و به دستور جدید شما سوئیچ می‌شود. Ctrl+C هم کار می‌کند.

۸ گام ۶ — لایهٔ بعدی را اضافه کنید

فقط بعد از کار کردنِ گفتگوی پایه. هر چه لازم داشتید انتخاب کنید:

بات یا دستیار مشترک

bash
hermes gateway setup    # پیکربندی تعاملی پلتفرم‌ها

اتصال تلگرام، دیسکورد، اسلک، واتساپ، سیگنال، ایمیل، هوم‌اسیسنت یا مایکروسافت تیمز.

اتوماسیون و ابزارها

  • hermes tools — تنظیم دسترسی ابزارها برای هر پلتفرم
  • hermes skills — مرور و نصب گردش‌کارهای قابل‌استفادهٔ مجدد
  • کرون — فقط بعد از پایدار شدنِ راه‌اندازی بات یا CLI

ترمینال ایزوله (Sandbox)

برای ایمنی، ایجنت را در کانتینر داکر یا روی سرور راهن اجرا کنید:

bash
hermes config set terminal.backend docker    # ایزوله‌سازی با داکر
hermes config set terminal.backend ssh       # سرور راهن

برای سندباکس‌های داکری می‌توانید پروکسی خروجیِ تزریق اعتبارنامه را هم فعال کنید تا سندباکس هرگز کلیدهای واقعی API شما را نبیند — فقط توکن‌های ماتِ پروکسی که منحصراً از پشت یک دیمنِ محلیِ TLS-رهگیر کار می‌کنند. به «پروکسی خروجی» مراجعه کنید. راه‌اندازی: hermes egress setup && hermes egress start؛ hermes setup terminal هم کاربران داکر را به آن راهنمایی می‌کند. Modal، SSH، Daytona و Singularity هنوز به آن متصل نشده‌اند.

حالت صوتی

bash
# از پوشهٔ نصب هرمس (نصب‌کنندهٔ curl آن را در ~/.hermes/hermes-agent روی لینوکس/مک
# یا %LOCALAPPDATA%\hermes\hermes-agent روی ویندوز قرار داده است):
cd ~/.hermes/hermes-agent
uv pip install --python ./venv/bin/python -e ".[voice]"
# شامل faster-whisper برای تبدیل محلی و رایگان گفتار به متن است

سپس در CLI: /voice on. برای ضبط Ctrl+B را بزنید. به «حالت صوتی» مراجعه کنید.

مهارت‌ها (Skills)

مهارت‌ها سندهای دستورالعملِ در-لحظه‌اند که به هرمس یاد می‌دهند یک کار مشخص را چطور انجام دهد — استقرار روی کوبرنتیز، باز کردن PR در گیت‌هاب، فاین‌تیون کردن یک مدل، جستجوی گیف. هر مهارت یک فایل SKILL.md با یک نام، یک توضیح و یک رویهٔ گام‌به‌گام است. ایجنت توضیح‌های کوتاه را رایگان می‌خواند و محتوای کامل مهارت را فقط وقتی بارگذاری می‌کند که یک کار واقعاً به آن نیاز داشته باشد؛ پس افزودن مهارت‌ها هر درخواست را متورم نمی‌کند.

هرمس با کاتالوگی از مهارت‌های داخلی عرضه می‌شود که از قبل در ~/.hermes/skills/ نصب‌اند. می‌توانید از Skills Hub مهارت بیشتری اضافه کنید، یا خودتان بنویسید.

مرور و نصب از هاب:

bash
hermes skills browse                      # فهرست همهٔ موارد موجود
hermes skills search kubernetes           # یافتن مهارت با کلیدواژه
hermes skills install openai/skills/k8s   # نصب یکی (ابتدا اسکن امنیتی اجرا می‌شود)

آرگومان نصب، یک اسلاگ source/path از هاب است — openai/skills/k8s یعنی مهارت k8s از کاتالوگ OpenAI. hermes skills browse اسلاگ‌های دقیقِ مورد نیاز را نشان می‌دهد.

استفاده از مهارت — هر مهارتِ نصب‌شده به‌طور خودکار یک فرمان اسلش می‌شود:

bash
/k8s deploy the staging manifest          # اجرای مهارت همراه با یک درخواست
/k8s                                       # بارگذاری و گذاشتن تصمیم به هرمس

این هم در CLI و هم در هر پلتفرم پیام‌رسانیِ متصل کار می‌کند. لازم نیست همه‌چیز را از اول نصب کنید — ایجنت در طول گفتگوی عادی، وقتی کاری با یکی از مهارت‌ها بخواند، خودش مهارت داخلی درست را برمی‌دارد.

برای نوشتن مهارت خودتان، پوشه‌های مهارت بیرونی و فهرست کامل منابع هاب، به «سیستم مهارت‌ها» مراجعه کنید.

یکپارچه‌سازی با ادیتور (ACP)

پشتیبانی ACP همراه با بستهٔ استاندارد [all] عرضه می‌شود، پس نصب‌کنندهٔ curl از قبل شامل آن است. فقط اجرا کنید:

bash
hermes acp

(اگر بدون [all] نصب کرده‌اید، اول cd ~/.hermes/hermes-agent && uv pip install -e ".[acp]" را اجرا کنید.)

به «یکپارچه‌سازی ادیتور ACP» مراجعه کنید.

hermes doctor مشکلات پیکربندی را علامت می‌زندمقادیر پیکربندی مفقود یا کهنه‌اندپیکربندی را درست کنید و قبل از افزودن قابلیت، یک گفتگوی ساده را دوباره تست کنید

  • راهنمای CLI — تسلط بر رابط ترمینال
