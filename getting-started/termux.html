خانه/شروع کار/ترماکس (اندروید)

هرمس روی اندروید با Termux

⚠️ پلتفرم ردهٔ ۲ (Tier 2)

ترماکس (اندروید) یک پلتفرم ردهٔ ۲ است. اسکریپت نصب و مستندات این صفحه فقط به‌صورت «در حد توان» نگهداری می‌شوند. کامیت‌های شاخهٔ main ممکن است هر لحظه این بسته‌ها را بشکنند.

هرمس ایجنت می‌تواند مستقیم روی یک گوشی اندرویدی از طریق Termux اجرا شود.

این روش به شما یک CLI محلیِ کاری روی گوشی، به‌علاوهٔ بسته‌های جانبیِ اصلی‌ای می‌دهد که در حال حاضر می‌دانیم روی اندروید تمیز نصب می‌شوند.

۱ چه چیزهایی در مسیر تست‌شده پشتیبانی می‌شود؟

بستهٔ تست‌شدهٔ ترماکس این‌ها را نصب می‌کند:

  • CLI هرمس
  • پشتیبانی کرون
  • پشتیبانی ترمینال پس‌زمینه/PTY
  • پشتیبانی گیت‌وی تلگرام (اجراهای پس‌زمینه به‌صورت دستی/در حد توان)
  • پشتیبانی MCP
  • پشتیبانی حافظهٔ Honcho
  • پشتیبانی ACP

به‌طور مشخص، این معادل نصب زیر است:

bash
python -m pip install -e '.[termux]' -c constraints-termux.txt

۲ چه چیزهایی هنوز بخشی از مسیر تست‌شده نیستند؟

چند قابلیت هنوز به وابستگی‌های سبک دسکتاپ/سرور نیاز دارند که برای اندروید منتشر نشده‌اند، یا هنوز روی گوشی‌ها اعتبارسنجی نشده‌اند:

  • بستهٔ .[all] امروز روی اندروید پشتیبانی نمی‌شود
  • بستهٔ voice توسط faster-whisper -> ctranslate2 مسدود است و ctranslate2 ویل اندرویدی منتشر نمی‌کند
  • راه‌اندازی خودکار مرورگر / پلی‌رایت در نصب‌کنندهٔ ترماکس رد می‌شود
  • ایزوله‌سازی ترمینال مبتنی بر داکر داخل ترماکس در دسترس نیست
  • اندروید ممکن است کارهای پس‌زمینهٔ ترماکس را معلق کند، پس ماندگاری گیت‌وی «در حد توان» است نه یک سرویس مدیریت‌شدهٔ معمولی

این مانع از آن نمی‌شود که هرمس به‌عنوان یک ایجنت CLIِ بومیِ گوشی خوب کار کند — فقط یعنی نصب موبایلِ توصیه‌شده عمداً محدودتر از نصب دسکتاپ/سرور است.

۳ گزینهٔ بومی `pkg` نگهداری‌شده توسط جامعه

⚠️ توزیع شخص ثالث

این مخزن APT **توسط جامعه و توسط @adybag14-cyber نگهداری می‌شود و یک توزیع رسمی NousResearch نیست**. NousResearch این بسته‌ها را نمی‌سازد، امضا نمی‌کند، میزبانی نمی‌کند یا بازرسی نمی‌کند. فعال‌سازی این مخزن به معنای اعتماد به مخزن و کلید امضای اپراتور آن است. خود ترماکس همچنان پلتفرمی ردهٔ ۲ / در-حد-توان باقی می‌ماند.

برای کاربرانی که نصب بومی با مدیر پکیج را به ساخت وابستگی‌های پایتون/راست روی گوشی ترجیح می‌دهند، یک مخزن APT نگهداری‌شده توسط جامعه موجود است. بوت‌استرپ مخزن و سورس‌های بسته‌بندی در adybag14-cyber/termux-python و بیلد بستهٔ هرمس در adybag14-cyber/termux-hermes منتشر شده‌اند.

کلید/سورس مخزن و هرمس را نصب کنید:

bash
curl -fsSL https://raw.githubusercontent.com/adybag14-cyber/termux-python/main/scripts/setup_apt_repo.sh | bash
pkg install hermes-agent

اثر انگشت کلید امضای مخزن که توزیع جامعه در حال حاضر مستند کرده:

fingerprint
EAD24A2124EFA7393A78B7B14699F966313F7A6B

نصب‌های هرمسِ مدیریت‌شده با APT با روش نصب apt علامت می‌خورند. بنابراین هرمس خودبه‌روزرسانِ Git خود را روی فایل‌های متعلق به پکیج اجرا نمی‌کند؛ به‌جای آن از مدیر پکیج استفاده کنید:

bash
pkg update
pkg upgrade hermes-agent

مشکلات بسته‌بندی/مخزن/امضای این گزینه را باید به مخازن بسته‌بندی جامعهٔ بالا گزارش کرد. باگ‌های زمانِ اجرای هرمس همچنان می‌توانند اینجا گزارش شوند — با در نظر داشتن اینکه پشتیبانی اندروید/ترماکس «در حد توان» است.

۴ گزینهٔ ۱: نصب‌کنندهٔ یک‌خطی

هرمس اکنون مسیر نصب آگاه از ترماکس دارد:

bash
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

روی ترماکس، نصب‌کننده به‌طور خودکار:

  • برای پکیج‌های سیستمی از pkg استفاده می‌کند
  • venv را با python -m venv می‌سازد
  • اول بستهٔ گستردهٔ .[termux-all] را امتحان می‌کند و به بستهٔ کوچک‌تر .[termux] (و سپس نصب پایه) برمی‌گردد — نصب‌کنندهٔ curl این ترتیب را خودکار رعایت می‌کند
  • hermes را در $PREFIX/bin لینک می‌کند تا روی PATH ترماکس شما بماند
  • راه‌اندازی تست‌نشدهٔ مرورگر / واتساپ را رد می‌کند

اگر فرمان‌های صریح را می‌خواهید یا باید نصبِ شکست‌خورده را عیب‌یابی کنید، از مسیر دستی زیر استفاده کنید.

۵ گزینهٔ ۲: نصب دستی (کاملاً صریح)

۱. به‌روزرسانی ترماکس و نصب پکیج‌های سیستمی

bash
pkg update
pkg install -y git python clang rust make pkg-config libffi openssl nodejs ripgrep ffmpeg

چرا این پکیج‌ها؟

  • python — زمان اجرا + پشتیبانی venv
  • git — کلون/به‌روزرسانی مخزن
  • clang، rust، make، pkg-config، libffi، openssl — برای بیلد چند وابستگی پایتونی روی اندروید لازم‌اند
  • nodejs — زمان اجرای نود، اختیاری برای آزمایش‌های فراتر از مسیر تست‌شدهٔ اصلی
  • ripgrep — جستجوی سریع فایل
  • ffmpeg — تبدیل‌های رسانه/TTS

۲. کلون هرمس

bash
git clone https://github.com/NousResearch/hermes-agent.git
cd hermes-agent

۳. ساخت محیط مجازی

bash
python -m venv venv
source venv/bin/activate
export ANDROID_API_LEVEL="$(getprop ro.build.version.sdk)"
python -m pip install --upgrade pip setuptools wheel

ANDROID_API_LEVEL برای پکیج‌های مبتنی بر Rust/maturin مانند jiter مهم است.

۴. نصب بستهٔ تست‌شدهٔ ترماکس

bash
python -m pip install -e '.[termux]' -c constraints-termux.txt

اگر فقط ایجنتِ هستهٔ مینیمال را می‌خواهید، این هم کار می‌کند:

bash
python -m pip install -e '.' -c constraints-termux.txt

۵. قرار دادن hermes روی PATH ترماکس

bash
ln -sf "$PWD/venv/bin/hermes" "$PREFIX/bin/hermes"

$PREFIX/bin در ترماکس از قبل روی PATH است، پس این کار باعث می‌شود فرمان hermes در شل‌های جدید هم بدون نیاز به فعال‌سازی دوبارهٔ venv در دسترس بماند.

۶. تأیید نصب

bash
hermes --version
hermes doctor

۷. شروع هرمس

bash
hermes

۶ راه‌اندازی‌های توصیه‌شدهٔ بعدی

پیکربندی مدل

bash
hermes model

یا کلیدها را مستقیم در ~/.hermes/.env تنظیم کنید.

اجرای دوبارهٔ ویزارد کامل راه‌اندازی بعداً

bash
hermes setup

نصب دستی وابستگی‌های اختیاری Node

مسیر تست‌شدهٔ ترماکس عمداً راه‌اندازی Node/مرورگر را رد می‌کند. اگر بعداً می‌خواهید با ابزار مرورگر آزمایش کنید، آن‌چه لازم دارید به بک‌اند شما بستگی دارد:

  • ارائه‌دهندگان مرورگر ابری (Browserbase، Browser Use، Firecrawl) کرومیوم خودشان را میزبانی می‌کنند، پس همان Node.js کافی است — agent-browser در اولین استفاده به‌صورت تنبل از طریق npx agent-browser حل می‌شود:
    bash
    pkg install nodejs-lts
  • اتوماسیون مرورگر محلی روی ترماکس به نصب واقعی agent-browser نیاز دارد — مسیر جایگزینِ npxِ خالی در حالت محلی عمداً رد می‌شود چون برای «آماده» اعلام‌کردن بیش از حد شکننده است:
    bash
    pkg install nodejs-lts
npm install -g agent-browser && agent-browser install

ابزار مرورگر به‌طور خودکار پوشه‌های ترماکس (/data/data/com.termux/files/usr/bin) را در جستجوی PATH خود می‌گنجاند، پس agent-browser و npx بدون هیچ پیکربندی اضافیِ PATH پیدا می‌شوند.

ابزار مرورگر/واتساپ روی اندروید را تا اعلام خلاف آن، آزمایشی بدانید.

۷ عیب‌یابی

خطای No solution found هنگام نصب .[all]

به‌جای آن از بستهٔ تست‌شدهٔ ترماکس استفاده کنید:

bash
python -m pip install -e '.[termux]' -c constraints-termux.txt

مانعِ فعلی، بستهٔ voice است:

  • voice به faster-whisper وابسته است
  • faster-whisper به ctranslate2 وابسته است
  • ctranslate2 ویل اندرویدی منتشر نمی‌کند

شکست uv pip install روی اندروید

به‌جای آن از مسیر ترماکس با venv کتابخانهٔ استاندارد + pip استفاده کنید:

bash
python -m venv venv
source venv/bin/activate
export ANDROID_API_LEVEL="$(getprop ro.build.version.sdk)"
python -m pip install --upgrade pip setuptools wheel
python -m pip install -e '.[termux]' -c constraints-termux.txt

شکایت jiter / maturin از ANDROID_API_LEVEL

سطح API را پیش از نصب صریح تنظیم کنید:

bash
export ANDROID_API_LEVEL="$(getprop ro.build.version.sdk)"
python -m pip install -e '.[termux]' -c constraints-termux.txt

hermes doctor می‌گوید ripgrep یا Node غایب است

آن‌ها را با پکیج‌های ترماکس نصب کنید:

bash
pkg install ripgrep nodejs

شکست بیلد هنگام نصب پکیج‌های پایتونی

مطمئن شوید زنجیرهٔ ابزار بیلد نصب است:

bash
pkg install clang rust make pkg-config libffi openssl

سپس دوباره امتحان کنید:

bash
python -m pip install -e '.[termux]' -c constraints-termux.txt

۸ محدودیت‌های شناخته‌شده روی گوشی‌ها

  • بک‌اند داکر در دسترس نیست
  • رونویسی صوتی محلی از طریق faster-whisper در مسیر تست‌شده در دسترس نیست
  • راه‌اندازی اتوماسیون مرورگر عمداً توسط نصب‌کننده رد می‌شود
  • برخی بسته‌های اختیاری ممکن است کار کنند، اما فقط .[termux] و .[termux-all] در حال حاضر به‌عنوان بسته‌های تست‌شدهٔ اندرویدی مستند شده‌اند

اگر به مشکل جدیدِ مخصوص اندروید خوردید، لطفاً یک issue در گیت‌هاب باز کنید همراه با:

  • نسخهٔ اندروید شما
  • خروجی termux-info
  • python --version
  • hermes doctor
  • فرمان دقیق نصب و خروجی کامل خطا
