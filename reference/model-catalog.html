کاتالوگ مدل‌ها

هرمس فهرست‌های منتخب مدل‌ها را برای OpenRouter و Nous Portal از یک مانیفست JSON که کنار سایت مستندات میزبانی می‌شود می‌گیرد. این‌طوری نگه‌دارنده‌ها می‌توانند فهرست‌های انتخاب‌گر را بدون انتشار یک نسخهٔ جدید hermes-agent به‌روز کنند.

وقتی مانیفست در دسترس نباشد (آفلاین، شبکه بسته، خرابی میزبان)، هرمس بی‌سروصدا به اسنپ‌شات داخل مخزن که همراه CLI منتشر می‌شود برمی‌گردد. مانیفست هرگز انتخاب‌گر را نمی‌شکند — بدترین حالت این است که همان فهرستی را ببینید که با نسخهٔ نصب‌شدهٔ شما باندل شده.

۱ URL مانیفست زنده

https://hermes-agent.nousresearch.com/docs/api/model-catalog.json

با هر ادغام در main از طریق پایپ‌لاین فعلی GitHub Pages یعنی deploy-site.yml منتشر می‌شود. منبع حقیقت در مخزن، آدرس website/static/api/model-catalog.json است.

۲ اسکیما

{
  "version": 1,
  "updated_at": "2026-04-25T22:00:00Z",
  "metadata": {},
  "providers": {
    "openrouter": {
      "metadata": {},
      "models": [
        {"id": "z-ai/glm-5.2",         "description": "default", "default": true},
        {"id": "moonshotai/kimi-k3",   "description": "recommended", "metadata": {}},
        {"id": "openai/gpt-5.4",       "description": ""}
      ]
    },
    "nous": {
      "metadata": {},
      "models": [
        {"id": "z-ai/glm-5.2", "default": true},
        {"id": "anthropic/claude-opus-4.7"},
        {"id": "moonshotai/kimi-k3"}
      ]
    }
  }
}

توضیح فیلدها:

  • version — نسخهٔ صحیحِ اسکیما. اسکیماهای آینده این عدد را بالا می‌برند؛ هرمس مانیفست‌هایی را که نسخه‌شان را نمی‌فهمد رد می‌کند و به اسنپ‌شات هاردکدشده برمی‌گردد.
  • metadata — دیکشنری آزاد در سطح مانیفست، ارائه‌دهنده و مدل. هر کلیدی. هرمس فیلدهای ناشناخته را نادیده می‌گیرد، پس می‌توانید بدون هماهنگی برای تغییر اسکیما، ورودی‌ها را حاشیه‌نویسی کنید ("tier": "paid"، ‏"tags": [...] و…).
  • description — فقط OpenRouter. متن بجِ انتخاب‌گر را تعیین می‌کند ("recommended"، ‏"free"، ‏"default" یا خالی). Nous Portal از این استفاده نمی‌کند — محدودسازی پلن رایگان به‌صورت زنده از نقطهٔ پایانی قیمت‌گذاری Portal تعیین می‌شود.
  • default — دقیقاً یک ورودی به‌ازای هر ارائه‌دهنده می‌تواند "default": true داشته باشد. آن مدل پیش‌فرض بی‌سروصدا است: مدلی که هرمس وقتی کاربر مدل انتخاب نکرده رویش می‌نشیند (کارت تأیید onboarding در GUI، ‏provider پیکربندی‌شده بدون model، ‏model.default خالی). در زمان اجرا فقط از کش خوانده می‌شود (get_default_model_from_cache) تا مسیرهای داغِ حل‌کردن مدل هرگز به شبکه نخورند؛ وقتی مانیفستِ کش‌شده وجود ندارد، هرمس به ثابتِ داخل‌مخزنی PREFERRED_SILENT_DEFAULT_MODEL برمی‌گردد که باید با ورودی برچسب‌دار مطابق باشد. این‌طوری نگه‌دارنده‌ها می‌توانند پیش‌فرض بی‌سروصدا را بدون انتشار نسخه بچرخانند. عمداً یک مدل توانمند و کم‌هزینه است، هرگز گران‌ترین مدل پرچم‌دار.
  • قیمت‌گذاری و طول زمینه در مانیفست نیستند. این‌ها در زمان واکشی از APIهای زندهٔ ارائه‌دهنده می‌آیند (نقاط پایانی /v1/models، models.dev).

۳ رفتار واکشی

چه زمانیچه می‌شود
/model یا hermes modelاگر کش دیسک کهنه باشد واکشی می‌کند، وگرنه از کش استفاده می‌کند
کش دیسک تازه است (< TTL)هیچ درخواست شبکه‌ای نمی‌زند
شکست شبکه با وجود کشبازگشت بی‌سروصدای به کش، یک خط لاگ
شکست شبکه بدون کشبازگشت بی‌سروصدای به اسنپ‌شات داخل مخزن
مانیفست اعتبارسنجی اسکیما را رد کندبه‌عنوان غیرقابل‌دسترس تلقی می‌شود

محل کش: ~/.hermes/cache/model_catalog.json.

۴ پیکربندی

model_catalog:
  enabled: true
  url: https://hermes-agent.nousresearch.com/docs/api/model-catalog.json
  ttl_hours: 1
  providers: {}

برای غیرفعال‌کردن کامل واکشی از راه دور و استفادهٔ همیشگی از اسنپ‌شات داخل مخزن، enabled: false بگذارید.

URLهای بازنویسی به‌ازای هر ارائه‌دهنده

اشخاص ثالث می‌توانند فهرست منتخب خودشان را با همین اسکیما خودمیزبان کنند. یک ارائه‌دهنده را به URL سفارشی اشاره دهید:

model_catalog:
  providers:
    openrouter:
      url: https://example.com/my-openrouter-curation.json

مانیفستِ بازنویسی‌کننده فقط لازم است بلاک همان ارائه‌دهنده(هایی) را پر کند که اهمیتش را دارد. بقیهٔ ارائه‌دهندگان همچنان از روی URL اصلی حل می‌شوند.

پنهان‌کردن ارائه‌دهندگان از انتخاب‌گر

‏excluded_providers اجازه می‌دهد ارائه‌دهنده‌های مشخصی را حتی وقتی اعتبارنامهٔ معتبر وجود دارد از انتخاب‌گر /model پنهان کنید. وقتی برای ارائه‌دهنده‌های قدیمی یا آزمایشی اعتبارنامه دارید که نباید در استفادهٔ عادی دیده شوند کاربرد دارد (مثلاً یک توکن Copilot یا OpenRouter قدیمی هنوز داخل auth.json کش‌شده یا کشف‌شده از طریق CLI ی gh).

model_catalog:
  excluded_providers:
    - copilot
    - openrouter
    - openai

انطباقِ حذف، بدون حساسیت به بزرگی/کوچکی حروف، با هر کلیدی که ارائه‌دهنده می‌تواند زیرش ظاهر شود انجام می‌شود — شناسهٔ هرمس و شناسهٔ models.dev (ارائه‌دهندگان نگاشت‌شدهٔ داخلی)، pid لایهٔ روی‌گذار و اسلاگ هرمسِ حل‌شده (ارائه‌دهندگان overlay) و اسلاگ کانونی (ارائه‌دهندگان کانونی) — پس یک ورودی مثل copilot ارائه‌دهنده را صرف‌نظر از اینکه کدام بخش تولیدش کند پنهان می‌کند. این تنظیم در همهٔ سطوح انتخاب‌گر /model رعایت می‌شود: انتخاب‌گرهای تعاملی/متنی گیت‌وی، انتخاب‌گر TUI و انتخاب‌گر تعاملی hermes model در CLI. فهرست خالی (یا حذف کلید) اثری ندارد.

۵ به‌روزرسانی مانیفست

نگه‌دارنده‌ها:

# Re-generate from the in-repo hardcoded lists (keeps manifest in sync after
# editing OPENROUTER_MODELS or _PROVIDER_MODELS["nous"] in hermes_cli/models.py).
python scripts/build_model_catalog.py

بعد نتیجه را با PR به website/static/api/model-catalog.json روی main بفرستید. سایت مستندات با ادغام خودکار منتشر می‌شود و مانیفست جدید ظرف چند دقیقه زنده است.

برای تغییرات ظریف فراداده که جایی در اسنپ‌شات داخل‌مخزنی ندارند، می‌توانید JSON را هم مستقیم دستی ویرایش کنید — اسکریپت مولد یک ابزار راحتی است، نه تنها منبع حقیقت.
