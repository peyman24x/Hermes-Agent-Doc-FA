IRC

آداپتور IRC هرمس را به هر سرور IRCی وصل می‌کند و پیام‌ها را بین یک کانال IRC ‏(یا پیام خصوصی) و ایجنت رله می‌کند. با پروتکل IRC روی asyncio استاندارد پایتون حرف می‌زند — بدون هیچ وابستگی خارجی، بدون SDK، بدون دیمن. با شبکه‌های عمومی مثل Libera.Chat و هر ircd خودمیزبان کار می‌کند.

‏IRC متن ساده است: پشتیبانی صدا، تصویر، فایل، ترد، واکنش، تایپ یا استریم ندارد — ریپلای‌ها به‌صورت خطوط PRIVMSG فرستاده می‌شوند و پیام‌های بلند برای جا شدن در سقف خط IRC تقسیم می‌شوند.

hermes gateway setup را اجرا و IRC را انتخاب کنید تا راهنمای گام‌به‌گام ببینید.

۱ پیش‌نیازها

  • یک سرور IRC برای اتصال ‏(مثل irc.libera.chat)
  • یک کانال برای پیوستن ‏(مثل #hermes) — برای چند کانال با ویرگول جدا کنید
  • یک لقب ‏(nick) برای بات ‏(پیش‌فرض: hermes-bot)
  • اختیاری: nick ثبت‌شده + رمز NickServ اگر شبکه‌تان احراز بخواهد

۲ پیکربندی هرمس

IRC را دو جور می‌شود پیکربندی کرد — متغیرهای محیطی ‏(برای راه‌اندازی سریع فقط-env) یا بلوک gateway در ~/.hermes/gateway-config.yaml.

گزینهٔ A — gateway-config.yaml

yaml
gateway:
  platforms:
    irc:
      enabled: true
      extra:
        server: irc.libera.chat
        port: 6697
        nickname: hermes-bot
        channel: "#hermes"
        use_tls: true
        server_password: ""       # رمز سرور (اختیاری)
        nickserv_password: ""     # احراز NickServ (اختیاری)
        allowed_users: []         # خالی = اجازه به همه، یا فهرست nick ها
        max_message_length: 450   # سقف خط IRC (پیش‌فرض امن)

گزینهٔ B — متغیرهای محیطی

متغیرلازمتوضیح
IRC_SERVER✅هاستنیم سرور IRC ‏(مثل irc.libera.chat)
IRC_CHANNEL✅کانال‌هایی که باید بپیوندد — برای چندتا با ویرگول
IRC_NICKNAME✅لقب بات ‏(پیش‌فرض: hermes-bot)
IRC_PORT—پورت سرور ‏(پیش‌فرض: 6697 با TLS، ‏6667 بدون)
IRC_USE_TLS—استفاده از TLS ‏(true/false؛ پیش‌فرض true روی پورت 6697)
IRC_SERVER_PASSWORD—رمز سرور برای فرمان PASS
IRC_NICKSERV_PASSWORD—رمز NickServ برای IDENTIFY خودکار هنگام اتصال
IRC_ALLOWED_USERS—‏nick های مجازِ گفتگو با بات، جداشده با ویرگول
IRC_ALLOW_ALL_USERS—اجازه به همهٔ افراد کانال برای گفتگو با بات ‏(فقط توسعه)
IRC_HOME_CHANNEL—کانال تحویل کرون / اعلان‌ها ‏(پیش‌فرض همان IRC_CHANNEL)

۳ کنترل دسترسی

به‌طور پیش‌فرض فقط nick هایی که در allowed_users ‏(یا IRC_ALLOWED_USERS) هستند حق حرف زدن با بات را دارند. فهرست را خالی بگذارید و ‏IRC_ALLOW_ALL_USERS=true بگذارید تا هر کسی در کانال بتواند با هرمس چت کند — برای تست مفید است ولی روی شبکه‌های عمومی توصیه نمی‌شود چون nick های IRC مگر شبکه NickServ را اجبار کند احراز نمی‌شوند.

اگر شبکه‌تان nick ثبت می‌کند، ‏IRC_NICKSERV_PASSWORD ‏(یا nickserv_password) را بگذارید تا بات هنگام اتصال به NickServ معرفی شود و nick ثبت‌شده‌اش را نگه دارد.

۴ کانال‌ها در برابر DM ها

  • پیام‌های یک کانالِ عضو‌شده به‌عنوان گفتگوی گروهی پردازش می‌شوند.
  • پیام‌های خصوصی به بات به‌عنوان پیام مستقیم پردازش می‌شوند.

کارهای کرون و اعلان‌ها به کانال خانگی تحویل می‌شوند — اگر IRC_HOME_CHANNEL تنظیم باشد همان، وگرنه اولین IRC_CHANNEL.

۵ اجرای گیت‌وی

bash
hermes gateway start

وضعیت را با hermes gateway status چک کنید — وضعیت اتصال IRC آنجا گزارش می‌شود، حتی برای راه‌اندازی‌های فقط-env.

۶ یادداشت‌ها

  • ریپلای‌های بلند ایجنت خودکار به چند خط PRIVMSG تقسیم می‌شوند تا در سقف خط IRC بمانند ‏(max_message_length، پیش‌فرض ۴۵۰ بایت پس از overhead پروتکل).
  • آداپتور به‌ازای هر ترکیب سرور+nick یک قفل اعتبارنامهٔ scoped می‌گیرد، پس دو پروفایل هرمس سر هویت IRC واحد دعوا نمی‌کنند.
