Yuanbao

هرمس را به ‏Yuanbao، پلتفرم پیام‌رسانی سازمانی تنسنت، وصل کنید. آداپتور از دروازهٔ WebSocket برای تحویل لحظه‌ای پیام استفاده و هم گفتگوهای مستقیم ‏(C2C) هم گروهی را پشتیبانی می‌کند.

📌 نکته

‏Yuanbao پلتفرم پیام‌رسانی سازمانی است که عمدتاً داخل تنسنت و محیط‌های سازمانی استفاده می‌شود. از WebSocket برای ارتباط لحظه‌ای، احراز مبتنی بر HMAC استفاده می‌کند و رسانهٔ غنی شامل تصویر، فایل و پیام صوتی را پشتیبانی می‌کند.

۱ پیش‌نیازها

  • حساب Yuanbao با مجوز ساخت بات
  • ‏APP_ID و APP_SECRET یوان‌بائو ‏(از ادمین پلتفرم)
  • بسته‌های پایتونی: ‏websockets و ‏httpx
  • برای پشتیبانی رسانه: ‏aiofiles

وابستگی‌های لازم را نصب کنید:

pip install websockets httpx aiofiles

۲ راه‌اندازی

۱. ساخت بات در Yuanbao

  1. اپ یوان‌بائو را از ‏https://yuanbao.tencent.com/ دانلود کنید
  2. در اپ به ‏PAI ← My Bot بروید و بات جدیدی بسازید
  3. بعد از ساخت بات، ‏APP_ID و ‏APP_SECRET را کپی کنید

۲. اجرای ویزارد راه‌اندازی

ساده‌ترین راه پیکربندی یوان‌بائو راه‌اندازی تعاملی است:

hermes gateway setup

هنگام پرسش Yuanbao را انتخاب کنید. ویزارد:

  1. ‏APP_ID را می‌پرسد
  2. ‏APP_SECRET را می‌پرسد
  3. پیکربندی را خودکار ذخیره می‌کند
💡 نکته

‏WebSocket URL و دامنهٔ API پیش‌فرض‌های منطقی داخلی دارند. فقط APP_ID و APP_SECRET لازم است تا شروع کنید.

۳. پیکربندی متغیرهای محیطی

بعد از setup اولیه این متغیرها را در ‏~/.hermes/.env تأیید کنید:

bash
# الزامی
YUANBAO_APP_ID=your-app-id
YUANBAO_APP_SECRET=your-app-secret
YUANBAO_WS_URL=wss://api.yuanbao.example.com/ws
YUANBAO_API_DOMAIN=https://api.yuanbao.example.com

# اختیاری: شناسهٔ حساب بات (معمولاً خودکار از sign-token گرفته می‌شود)
# YUANBAO_BOT_ID=your-bot-id

# اختیاری: محیط مسیریابی داخلی (مثلاً test/staging/production)
# YUANBAO_ROUTE_ENV=production

# اختیاری: کانال خانگی کرون/اعلان‌ها (قالب: direct:<account> یا group:<group_code>)
YUANBAO_HOME_CHANNEL=direct:bot_account_id
YUANBAO_HOME_CHANNEL_NAME="Bot Notifications"

# اختیاری: محدودکردن دسترسی (قدیمی — سیاست‌های دقیق را در کنترل دسترسی پایین ببینید)
YUANBAO_ALLOWED_USERS=user_account_1,user_account_2

۴. شروع گیت‌وی

hermes gateway

آداپتور به دروازهٔ WebSocket یوان‌بائو وصل، با امضاهای HMAC احراز و پردازش پیام‌ها را شروع می‌کند.

۳ قابلیت‌ها

  • دروازهٔ WebSocket — ارتباط دوطرفهٔ لحظه‌ای
  • احراز HMAC — امضای امن درخواست با APP_ID/APP_SECRET
  • پیام‌رسانی C2C — گفتگوهای مستقیم کاربر-به-بات
  • پیام‌رسانی گروهی — گفتگوها در چت گروهی
  • پشتیبانی رسانه — تصویر، فایل و پیام صوتی از طریق COS ‏(Cloud Object Storage)
  • قالب‌بندی مارک‌داون — پیام‌ها خودکار مطابق سقف حجم یوان‌بائو تکه می‌شوند
  • حذف تکرار پیام — مانع پردازش دوبارهٔ همان پیام می‌شود
  • ضربان/keep-alive — حفظ پایداری اتصال WebSocket
  • نشانگر تایپ — حین پردازش ایجنت وضعیت «typing…» نشان داده می‌شود
  • اتصال‌مجدد خودکار — هندل قطعی WebSocket با backoff نمایی
  • پرس‌وجوی اطلاعات گروه — گرفتن جزئیات گروه و فهرست اعضا
  • استیکر/ایموجی — ارسال استیکرها و ایموجی TIMFaceElem در گفتگوها
  • پشتیبانی تاریخچهٔ چت فورواردشدهٔ WeChat — وقتی کاربر بستهٔ تاریخچهٔ چت ویکام را به یوان‌بائو فوروارد کند، آداپتور رکوردهای فورواردشده ‏(لقب فرستنده‌ها، متن و ورودی‌های چندرسانه‌ای شامل فورواردهای تودرتو) را decode و داخل گفتگو تزریق می‌کند تا ایجنت کل رشتهٔ فورواردشده را بخواند
  • Auto-sethome — اولین کاربری که به بات پیام دهد خودکار مالک کانال خانگی می‌شود
  • اعلان پاسخ-کند — وقتی ایجنت بیشتر از انتظار طول بکشد پیام «منتظر بمانید» می‌فرستد

۴ گزینه‌های پیکربندی

قالب‌های Chat ID

‏Yuanbao بسته به نوع گفتگو شناسه‌های پیشونددار استفاده می‌کند:

نوع چتقالبمثال
پیام مستقیم ‏(C2C)direct:<account>direct:user123
پیام گروهیgroup:<group_code>group:grp456

آپلودهای رسانه‌ای

آداپتور یوان‌بائو آپلود رسانه را خودکار از طریق COS ‏(Tencent Cloud Object Storage) هندل می‌کند:

  • تصاویر: JPEG، ‏PNG، ‏GIF، ‏WebP
  • فایل‌ها: همهٔ انواع سند رایج
  • صوت: WAV، ‏MP3، ‏OGG

URL های رسانه قبل از آپلود برای جلوگیری از حملهٔ SSRF اعتبارسنجی و دانلود می‌شوند.

۵ کانال خانگی

فرمان ‏/sethome را در هر گفتگوی یوان‌بائو ‏(DM یا گروه) بزنید تا همانجا کانال خانگی شود. کارهای زمان‌بندی‌شده ‏(کرون) نتایجشان را به همین کانال تحویل می‌دهند.

💡 Auto-sethome

اگر کانال خانگی پیکربندی نشده باشد اولین کاربری که به بات پیام دهد خودکار مالک کانال خانگی می‌شود. اگر کانال خانگی فعلی یک چت گروهی باشد، اولین DM آن را به کانال مستقیم ارتقا می‌دهد.

دستی هم در ‏~/.hermes/.env می‌شود گذاشت:

YUANBAO_HOME_CHANNEL=direct:user_account_id
# یا برای گروه:
# YUANBAO_HOME_CHANNEL=group:group_code
YUANBAO_HOME_CHANNEL_NAME="My Bot Updates"

مثال: تنظیم کانال خانگی

  1. با بات در یوان‌بائو گفتگو شروع کنید
  2. فرمان را بفرستید: ‏/sethome
  3. بات جواب می‌دهد: «Home channel set to [chat_name] with ID [chat_id]. Cron jobs will deliver to this location.»
  4. کارهای کرون و اعلان‌های بعدی به همین کانال فرستاده می‌شوند

مثال: تحویل کار کرون

یک کار کرون بسازید:

/cron "0 9 * * *" Check server status

خروجی زمان‌بندی‌شده هر روز ساعت ۹ صبح به کانال خانگی یوان‌بائوی شما تحویل داده می‌شود.

۶ نکات استفاده

شروع گفتگو

هر پیامی به بات در یوان‌بائو بدهید:

hello

بات در همان رشتهٔ گفتگو جواب می‌دهد.

فرمان‌های موجود

همهٔ فرمان‌های استاندارد هرمس روی یوان‌بائو کار می‌کنند:

فرمانتوضیح
/newشروع گفتگوی تازه
/model [provider:model]نمایش یا تغییر مدل
/sethomeتعیین این چت به‌عنوان کانال خانگی

ارسال فایل

برای فرستادن فایل به بات کافی است مستقیم داخل چت یوان‌بائو پیوستش کنید. بات خودکار پیوست فایل را دانلود و پردازش می‌کند.

می‌توانید همراه پیوست پیام هم داشته باشید:

دریافت فایل

وقتی از بات بخواهید فایلی بسازد یا export کند، فایل را مستقیم به چت یوان‌بائوی شما می‌فرستد.

۷ عیب‌یابی

بات آنلاین است ولی به پیام‌ها جواب نمی‌دهد

علت: احراز حین دست‌دادن WebSocket شکست خورده.

راه‌حل:

  1. درستی APP_ID و APP_SECRET را تأیید کنید
  2. قابل‌دسترس بودن WebSocket URL را چک کنید
  3. مطمئن شوید حساب بات مجوزهای مناسب را دارد
  4. لاگ‌های گیت‌وی را بازبینی کنید: ‏tail -f ~/.hermes/logs/gateway.log

خطای «Connection refused»

علت: WebSocket URL غیرقابل‌دسترس یا اشتباه است.

راه‌حل:

  1. قالب WebSocket URL را تأیید کنید ‏(باید با wss:// شروع شود)
  2. اتصال شبکه به دامنهٔ API یوان‌بائو را چک کنید
  3. تأیید کنید فایروال اتصالات WebSocket را اجازه می‌دهد
  4. URL را تست کنید: ‏curl -I https://[YUANBAO_API_DOMAIN]

آپلودهای رسانه شکست می‌خورند

علت: اعتبارنامه‌های COS نامعتبرند یا سرور رسانه در دسترس نیست.

راه‌حل:

  1. درستی API_DOMAIN را تأیید کنید
  2. چک کنید مجوز آپلود رسانه برای بات‌تان فعال باشد
  3. مطمئن شوید فایل رسانه قابل‌دسترس و سالم است
  4. پیکربندی bucket ‏COS را با ادمین پلتفرم چک کنید

پیام‌ها به کانال خانگی تحویل نمی‌شوند

علت: قالب شناسهٔ کانال خانگی اشتباه است یا کار کرون هنوز تریگر نشده.

راه‌حل:

  1. تأیید کنید ‏YUANBAO_HOME_CHANNEL قالب درست دارد
  2. با فرمان ‏/sethome تست کنید تا قالب درست خودکار تشخیص داده شود
  3. زمان‌بندی کار کرون را با ‏/status چک کنید
  4. تأیید کنید بات در چت هدف مجوز ارسال دارد

قطعی‌های مکرر

علت: اتصال WebSocket ناپایدار یا شبکه نامطمئن است.

راه‌حل:

  1. لاگ‌های گیت‌وی را برای الگوهای خطا چک کنید
  2. timeout ضربان را در تنظیمات اتصال بالا ببرید
  3. اتصال شبکهٔ پایدار به API یوان‌بائو را تأمین کنید
  4. لاگ پرجزئیات را فعال کنید: ‏hermes gateway run -vv

۸ کنترل دسترسی

‏Yuanbao کنترل دسترسی دقیق برای گفتگوهای DM و گروهی دارد:

bash
# سیاست DM: open (پیش‌فرض) | allowlist | disabled
YUANBAO_DM_POLICY=open
# شناسه‌های کاربر جداشده با ویرگول مجازِ DM (فقط وقتی DM_POLICY=allowlist)
YUANBAO_DM_ALLOW_FROM=user_id_1,user_id_2

# سیاست گروه: open (پیش‌فرض) | allowlist | disabled
YUANBAO_GROUP_POLICY=open
# کدهای گروه جداشده با ویرگول مجاز (فقط وقتی GROUP_POLICY=allowlist)
YUANBAO_GROUP_ALLOW_FROM=group_code_1,group_code_2

در config.yaml هم می‌شود:

yaml
platforms:
  yuanbao:
    extra:
      dm_policy: allowlist
      dm_allow_from: "user1,user2"
      group_policy: open
      group_allow_from: ""

۹ پیکربندی پیشرفته

تکه‌تکه‌کردن پیام

‏Yuanbao سقف حجم پیام دارد. هرمس پاسخ‌های بزرگ را خودکار با تقسیم آگاه-از-مارک‌داون تکه می‌کند ‏(code fence ها، جدول‌ها و مرزهای پاراگراف را رعایت می‌کند).

پارامترهای اتصال

پارامترهای اتصال زیر با پیش‌فرض‌های منطقی داخل آداپتور ساخته شده‌اند:

پارامترمقدار پیش‌فرضتوضیح
timeout اتصال WebSocket۱۵ ثانیهزمان انتظار برای دست‌دادن WS
فاصلهٔ ضربان۳۰ ثانیهفراوانی ping برای زنده نگه‌داشتن اتصال
حداکثر تلاش reconnect۱۰۰حداکثر تعداد تلاش اتصال‌مجدد
backoff اتصال‌مجدد۱ ← ۶۰ ثانیه ‏(نمایی)زمان انتظار بین تلاش‌های اتصال‌مجدد
فاصلهٔ ضربان ریپلای۲ ثانیهفراوانی ارسال وضعیت RUNNING
timeout ارسال۳۰ ثانیهtimeout برای پیام‌های WS خروجی
📌 یادداشت

این مقادیر الان از طریق متغیرهای محیطی قابل‌پیکربندی نیستند. برای استقرارهای معمول یوان‌بائو بهینه شده‌اند.

لاگ پرجزئیات

برای عیب‌یابی مشکلات اتصال لاگ دیباگ را فعال کنید:

hermes gateway run -vv

۱۰ یکپارچگی با سایر قابلیت‌ها

کارهای کرون

کارهایی روی یوان‌بائو زمان‌بندی کنید:

/cron "0 */4 * * *" Report system health

نتایج به کانال خانگی شما تحویل می‌شوند.

کارهای پس‌زمینه

عملیات طولانی را بدون مسدودکردن گفتگو اجرا کنید:

/background Analyze all files in the archive

پیام‌های بین-پلتفرمی

از CLI به یوان‌بائو پیام بفرستید:

hermes chat -q "Send 'Hello from CLI' to yuanbao:group:group_code"
