راه‌اندازی سیگنال

هرمس از طریق دیمن signal-cli در حالت HTTP به سیگنال وصل می‌شود. آداپتور پیام‌ها را از طریق SSE ‏(Server-Sent Events) در لحظه استریم و پاسخ‌ها را با JSON-RPC می‌فرستد.

سیگنال حریم-خصوصی‌محورترین پیام‌رسان جریان اصلی است — رمزنگاری سرتاسری پیش‌فرض، پروتکل متن‌باز، حداقل جمع‌آوری متادیتا. این آن را برای گردش‌کارهای ایجنتیِ حساس به امنیت ایده‌آل می‌کند.

📌 بدون وابستگی پایتون جدید

آداپتور سیگنال برای همهٔ ارتباطات از httpx استفاده می‌کند ‏(از قبل وابستگی هستهٔ هرمس). هیچ بستهٔ پایتون اضافه‌ای لازم نیست. فقط باید signal-cli را بیرونی نصب کنید.

۱ پیش‌نیازها

  • signal-cli — کلاینت سیگنال مبتنی بر جاوا ‏(GitHub)
  • ‏runtime ‏جاوا ۱۷+ — توسط signal-cli لازم است
  • یک شماره تلفن با سیگنال نصب‌شده ‏(برای اتصال به‌عنوان دستگاه ثانویه)

نصب signal-cli

bash
# macOS
brew install signal-cli

# Linux (دانلود آخرین ریلیز)
VERSION=$(curl -Ls -o /dev/null -w %{url_effective} \
  https://github.com/AsamK/signal-cli/releases/latest | sed 's/^.*\/v//')
curl -L -O "https://github.com/AsamK/signal-cli/releases/download/v${VERSION}/signal-cli-${VERSION}.tar.gz"
sudo tar xf "signal-cli-${VERSION}.tar.gz" -C /opt
sudo ln -sf "/opt/signal-cli-${VERSION}/bin/signal-cli" /usr/local/bin/
⚠️ توجه

signal-cli در مخازن apt یا snap نیست. نصب لینوکسی بالا مستقیم از ریلیزهای GitHub دانلود می‌کند.

۲ گام ۱: اتصال حساب سیگنال

signal-cli به‌عنوان یک دستگاه متصل کار می‌کند — مثل WhatsApp Web ولی برای سیگنال. گوشی شما دستگاه اصلی می‌ماند.

bash
# تولید URI اتصال (کد QR یا لینک نمایش می‌دهد)
signal-cli link -n "HermesAgent"
  1. ‏Signal را روی گوشی باز کنید
  2. به Settings ← Linked Devices بروید
  3. Link New Device را بزنید
  4. کد QR را اسکن یا URI را وارد کنید

۳ گام ۲: اجرای دیمن signal-cli

bash
# ‎+1234567890 را با شماره سیگنال خودتان جایگزین کنید (قالب E.164)
signal-cli --account +1234567890 daemon --http 127.0.0.1:8080
💡 نکته

این را در پس‌زمینه نگه دارید. می‌توانید از systemd، ‏tmux، ‏screen استفاده کنید یا به‌صورت سرویس اجرایش کنید.

تأیید اجرا:

bash
curl http://127.0.0.1:8080/api/v1/check
# باید برگرداند: {"versions":{"signal-cli":...}}

۴ گام ۳: پیکربندی هرمس

ساده‌ترین راه:

bash
hermes gateway setup

Signal را از منوی پلتفرم انتخاب کنید. ویزارد:

  1. چک می‌کند signal-cli نصب باشد
  2. ‏HTTP URL را می‌پرسد ‏(پیش‌فرض: http://127.0.0.1:8080)
  3. اتصال به دیمن را تست می‌کند
  4. شماره تلفن حساب شما را می‌پرسد
  5. کاربران مجاز و سیاست‌های دسترسی را پیکربندی می‌کند

پیکربندی دستی

به ~/.hermes/.env اضافه کنید:

bash
# الزامی
SIGNAL_HTTP_URL=http://127.0.0.1:8080
SIGNAL_ACCOUNT=+1234567890

# امنیت (توصیه‌شده)
SIGNAL_ALLOWED_USERS=+1234567890,+0987654321    # شماره‌های E.164 یا UUID جدا با ویرگول

# اختیاری
SIGNAL_GROUP_ALLOWED_USERS=groupId1,groupId2     # فعال‌سازی گروه‌ها (حذف = خاموش، * = همه)
SIGNAL_HOME_CHANNEL=+1234567890                  # هدف تحویل پیش‌فرض کارهای کرون

سپس گیت‌وی را شروع کنید:

bash
hermes gateway              # پیش‌زمینه
hermes gateway install      # نصب به‌عنوان سرویس کاربر
sudo hermes gateway install --system   # فقط لینوکس: سرویس سیستمی زمان‌بوت

۵ کنترل دسترسی

دسترسی DM

دسترسی DM همان الگوی همهٔ پلتفرم‌های دیگر هرمس را دنبال می‌کند:

  1. ‏SIGNAL_ALLOWED_USERS تنظیم شده ← فقط آن کاربران می‌توانند پیام دهند
  2. لیست مجاز تنظیم نشده ← کاربران ناشناس کد جفت‌سازی DM می‌گیرند ‏(تأیید با hermes pairing approve signal CODE)
  3. ‏SIGNAL_ALLOW_ALL_USERS=true ← هر کسی می‌تواند پیام دهد ‏(با احتیاط)

دسترسی گروه

دسترسی گروه با متغیر محیطی SIGNAL_GROUP_ALLOWED_USERS کنترل می‌شود:

پیکربندیرفتار
تنظیم نشده ‏(پیش‌فرض)همهٔ پیام‌های گروه نادیده گرفته می‌شوند. بات فقط به DM پاسخ می‌دهد.
تنظیم‌شده با شناسه‌های گروهفقط گروه‌های فهرست‌شده پایش می‌شوند ‏(مثل groupId1,groupId2).
تنظیم روی *بات در هر گروهی که عضو است پاسخ می‌دهد.

۶ قابلیت‌ها

پیوست‌ها

آداپتور ارسال و دریافت رسانه را در هر دو جهت پشتیبانی می‌کند.

ورودی ‏(کاربر ← ایجنت):

  • تصاویر — PNG، ‏JPEG، ‏GIF، ‏WebP ‏(تشخیص خودکار با magic bytes)
  • صوت — MP3، ‏OGG، ‏WAV، ‏M4A ‏(پیام‌های صوتی اگر Whisper پیکربندی شده رونویسی می‌شوند)
  • اسناد — PDF، ‏ZIP و سایر انواع فایل

خروجی ‏(ایجنت ← کاربر):

ایجنت می‌تواند فایل‌های رسانه را از طریق تگ‌های MEDIA: در پاسخ‌ها بفرستد. روش‌های تحویل پشتیبانی‌شده:

  • تصاویر — ‏send_multiple_images و send_image_file تصاویر PNG، ‏JPEG، ‏GIF، ‏WebP را به‌صورت پیوست بومی سیگنال می‌فرستند
  • صوت — ‏send_voice فایل‌های صوتی ‏(OGG، ‏MP3، ‏WAV، ‏M4A، ‏AAC) را پیوست می‌کند
  • ویدیو — ‏send_video فایل‌های ویدیویی MP4 را می‌فرستد
  • اسناد — ‏send_document هر نوع فایلی را می‌فرستد ‏(PDF، ‏ZIP و غیره)

همهٔ رسانه‌های خروجی از API استاندارد پیوست سیگنال می‌گذرند. برخلاف بعضی پلتفرم‌ها، سیگنال در سطح پروتکل بین پیام صوتی و پیوست فایل تمایز نمی‌گذارد.

سقف حجم پیوست: ۱۰۰ مگابایت ‏(هر دو جهت).

⚠️ هشدار

سرورهای سیگنال آپلود پیوست را rate-limit می‌کنند؛ آداپتور برای ارسال چند تصویر از زمان‌بندی‌کننده‌ای استفاده می‌کند که تصاویر را دسته‌های ۳۲تایی batch کرده و آپلودها را مطابق سیاست سرور سیگنال throttle می‌کند.

قالب‌بندی بومی، نقل‌قول ریپلای و واکنش‌ها

پیام‌های سیگنال با قالب‌بندی بومی رندر می‌شوند نه کاراکترهای تحت‌اللفظی مارک‌داون. آداپتور مارک‌داون ‏(**bold**، ‏*italic*، ‏`code`، ‏~~strike~~، ‏||spoiler||، تیترها) را به bodyRanges سیگنال تبدیل می‌کند تا متن با استایل واقعی روی کلاینت گیرنده نشان داده شود نه کاراکترهای مرئی ** / ‏`.

نقل‌قول ریپلای. وقتی هرمس به پیام مشخصی ریپلای می‌دهد، الان یک ریپلای بومی پست می‌کند که پیام اصلی را نقل می‌کند — همان UI که کاربران سیگنال هنگام استفاده از «Reply» می‌بینند. برای ریپلای‌های تولیدشده در پاسخ به پیام ورودی خودکار است.

واکنش‌ها. ایجنت می‌تواند از طریق API استاندارد واکنش به پیام‌ها react کند؛ واکنش‌ها در سیگنال به‌صورت ایموجی روی پیام مرجع ظاهر می‌شوند نه متن اضافه.

هیچ‌کدام پیکربندی اضافه نمی‌خواهد — در build های اخیر signal-cli به‌طور پیش‌فرض فعال است. اگر نسخهٔ signal-cli خیلی قدیمی باشد، هرمس به تحویل متنی ساده سقوط و یک هشدار یک‌بارمصرف لاگ می‌کند.

نشانگر تایپ

بات حین پردازش پیام‌ها نشانگر تایپ می‌فرستد و هر ۸ ثانیه refresh می‌شود.

نمایش پیشرفت ابزار

سیگنال ویرایش پیام‌های ارسال‌شده را پشتیبانی نمی‌کند. بنابراین هرمس حباب‌های پیشرفت ابزار گیت‌وی را روی سیگنال سرکوب می‌کند، حتی وقتی /verbose فعال است و حالت غیر-off برای پلتفرم ذخیره شده.

فعالیت ابزار را همچنان در CLI می‌بینید و ریپلای‌های نهایی سیگنال خروجی عادی دستیار را شامل می‌شوند. اگر پیشرفت زندهٔ به‌ازای-ابزار در چت لازم دارید، از پیام‌رسانی با پشتیبانی ویرایش پیام استفاده کنید.

سانسور شماره تلفن

همهٔ شماره‌های تلفن در لاگ‌ها خودکار سانسور می‌شوند:

  • ‏+15551234567 ← ‏+155****4567
  • این هم روی لاگ‌های گیت‌وی هرمس اعمال می‌شود هم روی سیستم سانسور سراسری

یادداشت به خود (راه‌اندازی تک‌شماره‌ای)

اگر signal-cli را به‌عنوان دستگاه ثانویهٔ متصل روی شماره تلفن خودتان اجرا کنید ‏(نه شمارهٔ بات جدا)، می‌توانید از طریق قابلیت «Note to Self» سیگنال با هرمس تعامل کنید.

فقط از گوشی‌تان به خودتان پیام بدهید — signal-cli دریافتش می‌کند و هرمس در همان گفتگو پاسخ می‌دهد.

نحوهٔ کار:

  • پیام‌های «Note to Self» به‌صورت پاکت syncMessage.sentMessage می‌رسند
  • آداپتور تشخیص می‌دهد این‌ها خطاب به حساب خود بات‌اند و به‌عنوان پیام ورودی عادی پردازششان می‌کند
  • محافظت از پژواک ‏(ردیابی timestamp ارسال) حلقهٔ بی‌نهایت را می‌شکند — ریپلای‌های خود بات خودکار فیلتر می‌شوند

پیکربندی اضافه لازم نیست. تا وقتی SIGNAL_ACCOUNT با شماره تلفن‌تان بخواند خودکار کار می‌کند.

پایش سلامت

آداپتور اتصال SSE را پایش و در این موارد خودکار reconnect می‌کند:

  • قطع اتصال ‏(با backoff نمایی: ‏۲ ثانیه ← ۶۰ ثانیه)
  • ۱۲۰ ثانیه بی‌فعالیتی ‏(به signal-cli پینگ می‌زند تا تأیید شود)

۷ عیب‌یابی

مشکلراه‌حل
«Cannot reach signal-cli» هنگام راه‌اندازیمطمئن شوید دیمن signal-cli اجراست: ‏signal-cli --account +YOUR_NUMBER daemon --http 127.0.0.1:8080
پیام‌ها دریافت نمی‌شوندچک کنید SIGNAL_ALLOWED_USERS شمارهٔ فرستنده را در قالب E.164 دارد ‏(با پیشوند +)
«signal-cli not found on PATH»signal-cli را نصب و در PATH بگذارید، یا از Docker استفاده کنید
اتصال مدام قطع می‌شودلاگ‌های signal-cli را برای خطا چک کنید. مطمئن شوید جاوا ۱۷+ نصب است.
پیام‌های گروه نادیده گرفته می‌شوند‏SIGNAL_GROUP_ALLOWED_USERS را با شناسه‌های گروه مشخص، یا * برای همهٔ گروه‌ها تنظیم کنید.
بات به هیچ‌کس پاسخ نمی‌دهد‏SIGNAL_ALLOWED_USERS را پیکربندی کنید، از جفت‌سازی DM استفاده کنید، یا اگر دسترسی گسترده‌تر می‌خواهید همهٔ کاربران را از طریق سیاست گیت‌وی صریحاً مجاز کنید.
پیام‌های تکراریمطمئن شوید فقط یک نمونه signal-cli روی شماره تلفن‌تان گوش می‌دهد

۸ امنیت

⚠️ هشدار

همیشه کنترل‌های دسترسی را پیکربندی کنید. بات به‌طور پیش‌فرض دسترسی ترمینال دارد. بدون SIGNAL_ALLOWED_USERS یا جفت‌سازی DM، گیت‌وی به‌عنوان اقدام ایمنی همهٔ پیام‌های ورودی را رد می‌کند.

  • شماره‌های تلفن در همهٔ خروجی لاگ سانسور می‌شوند
  • برای onboarding امن کاربران جدید از جفت‌سازی DM یا لیست‌مجاز صریح استفاده کنید
  • گروه‌ها را مگر واقعاً پشتیبانی گروه لازم دارید خاموش نگه دارید، یا فقط گروه‌های مورداطمینان را مجاز کنید
  • رمزنگاری سرتاسری سیگنال محتوای پیام را در انتقال محافظت می‌کند
  • دادهٔ نشست signal-cli در ~/.local/share/signal-cli/ اعتبارنامهٔ حساب را دارد — مثل رمز عبور ازش محافظت کنید
