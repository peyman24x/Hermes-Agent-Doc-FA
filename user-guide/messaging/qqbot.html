QQ Bot

هرمس را از طریق ‏API رسمی QQ Bot ‏(v2) به QQ وصل کنید — پشتیبانی از پیام خصوصی ‏(C2C)، منشن @ گروهی، گیلد و پیام مستقیم با رونویسی صوت.

۱ نمای کلی

آداپتور QQ Bot از API رسمی QQ Bot استفاده می‌کند تا:

  • پیام‌ها را از طریق اتصال دائمی WebSocket به دروازهٔ QQ دریافت کند
  • ریپلای‌های متنی و مارک‌داونی از طریق REST API بفرستد
  • تصاویر، پیام‌های صوتی و پیوست‌های فایل را دانلود و پردازش کند
  • پیام‌های صوتی را با ASR داخلی Tencent یا ارائه‌دهندهٔ STT قابل‌پیکربندی رونویسی کند

۲ پیش‌نیازها

  1. اپلیکیشن QQ Bot — در q.qq.com ثبت‌نام کنید:
    • اپلیکیشن جدیدی بسازید و App ID و App Secret را یادداشت کنید
    • intent های لازم را فعال کنید: پیام‌های C2C، پیام‌های @ گروهی، پیام‌های گیلد
    • بات را برای تست در حالت sandbox پیکربندی کنید یا برای تولید publish کنید
  2. وابستگی‌ها — آداپتور ‏aiohttp و httpx می‌خواهد: 
    pip install aiohttp httpx

۳ پیکربندی

راه‌اندازی تعاملی

hermes gateway setup

QQ Bot را از فهرست پلتفرم‌ها انتخاب و طبق پرسش‌ها پیش بروید.

پیکربندی دستی

متغیرهای محیطی الزامی را در ‏~/.hermes/.env تنظیم کنید:

QQ_APP_ID=your-app-id
QQ_CLIENT_SECRET=your-app-secret

۴ متغیرهای محیطی

متغیرتوضیحپیش‌فرض
QQ_APP_IDApp ID بات QQ ‏(الزامی)—
QQ_CLIENT_SECRETApp Secret بات QQ ‏(الزامی)—
QQBOT_HOME_CHANNELOpenID برای تحویل کرون/اعلان—
QQBOT_HOME_CHANNEL_NAMEنام نمایشی کانال خانگیHome
QQ_ALLOWED_USERS‏OpenID های کاربر جداشده با ویرگول برای دسترسی DMopen ‏(همهٔ کاربران)
QQ_GROUP_ALLOWED_USERS‏OpenID های گروه جداشده با ویرگول برای دسترسی گروهی—
QQ_ALLOW_ALL_USERS‏true برای اجازه به همهٔ DM هاfalse
QQ_PORTAL_HOSToverride میزبان portal QQ ‏(برای مسیریابی سندباکس روی ‏sandbox.q.qq.com)q.qq.com
QQ_STT_API_KEYکلید API ارائه‌دهندهٔ صوت-به-متن—
QQ_STT_BASE_URL‏(مستقیم خوانده نمی‌شود — به‌جایش ‏platforms.qqbot.extra.stt.baseUrl را در config.yaml بگذارید)n/a
QQ_STT_MODELنام مدل STTglm-asr

۵ پیکربندی پیشرفته

برای کنترل دقیق‌تر تنظیمات پلتفرم را به config.yaml اضافه کنید:

yaml
platforms:
  qqbot:
    enabled: true
    extra:
      app_id: "your-app-id"
      client_secret: "your-secret"
      markdown_support: true       # فعال‌سازی مارک‌داون QQ (msg_type 2). فقط-config؛ معادل env ندارد.
      dm_policy: "open"          # open | allowlist | disabled
      allow_from:
        - "user_openid_1"
      group_policy: "open"       # open | allowlist | disabled
      group_allow_from:
        - "group_openid_1"
      stt:
        provider: "zai"          # zai (GLM-ASR)، openai (Whisper) و غیره
        baseUrl: "https://open.bigmodel.cn/api/coding/paas/v4"
        apiKey: "your-stt-key"
        model: "glm-asr"

۶ پیام‌های صوتی ‏(STT)

رونویسی صوت دو مرحله دارد:

  1. ASR داخلی QQ ‏(رایگان، همیشه اول امتحان می‌شود) — QQ فیلد ‏asr_refer_text را داخل پیوست پیام صوتی فراهم می‌کند که از تشخیص گفتار خود Tencent استفاده می‌کند
  2. ارائه‌دهندهٔ STT پیکربندی‌شده ‏(fallback) — اگر ASR متن برنگرداند، آداپتور یک API سازگار-با-OpenAI صدا می‌زند:
    • ‏Zhipu/GLM ‏(zai): ارائه‌دهندهٔ پیش‌فرض، مدل ‏glm-asr
    • ‏OpenAI Whisper: ‏QQ_STT_BASE_URL و ‏QQ_STT_MODEL را تنظیم کنید
    • هر endpoint سازگار-با-OpenAI دیگری

۷ عیب‌یابی

بات بلافاصله قطع می‌شود ‏(قطع سریع)

معمولاً یعنی:

  • ‏App ID / Secret نامعتبر — اعتبارنامه‌ها را در q.qq.com دوباره چک کنید
  • دسترسی‌های جاافتاده — مطمئن شوید intent های لازم برای بات فعال‌اند
  • بات فقط-سندباکس — اگر بات در حالت sandbox است فقط می‌تواند پیام‌های کانال تست sandbox خود QQ را بگیرد

پیام‌های صوتی رونویسی نمی‌شوند

  1. چک کنید ‏asr_refer_text داخلی QQ در دادهٔ پیوست موجود باشد
  2. اگر ارائه‌دهندهٔ STT سفارشی دارید، تأیید کنید ‏QQ_STT_API_KEY درست تنظیم شده
  3. پیام‌های خطای STT را در لاگ‌های گیت‌وی چک کنید

پیام‌ها تحویل نمی‌شوند

  • تأیید کنید intents بات در q.qq.com فعال‌اند
  • اگر دسترسی DM محدود است ‏QQ_ALLOWED_USERS را چک کنید
  • برای پیام‌های گروهی، مطمئن شوید بات @منشن شده ‏(سیاست گروه ممکن است لیست مجاز بخواهد)
  • ‏QQBOT_HOME_CHANNEL را برای تحویل کرون/اعلان چک کنید

خطاهای اتصال

  • مطمئن شوید ‏aiohttp و ‏httpx نصب‌اند: ‏pip install aiohttp httpx
  • اتصال شبکه به ‏api.sgroup.qq.com و دروازهٔ WebSocket را چک کنید
  • پیام‌های خطای تفصیلی و رفتار reconnect را در لاگ‌های گیت‌وی بازبینی کنید
