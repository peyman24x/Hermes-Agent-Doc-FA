خانه/پیام‌رسان‌ها/LINE

راه‌اندازی LINE

هرمس ایجنت را به‌عنوان یک بات ‏LINE از طریق LINE Messaging API رسمی اجرا کنید. آداپتور به‌عنوان یک افزونهٔ پلتفرم همراه‌بسته زیر مسیر ‏plugins/platforms/line/ زندگی می‌کند — بدون ویرایش هسته، مثل هر پلتفرم دیگری فعالش کنید.

‏LINE پیام‌رسان غالب ژاپن، تایوان و تایلند است. اگر کاربرانتان آنجا هستند، راه رسیدنشان به شما همین است.

hermes gateway setup را اجرا و LINE را انتخاب کنید تا راهنمای گام‌به‌گام ببینید.

۱ نحوهٔ پاسخ بات

زمینهرفتار
چت ۱:۱ ‏(شناسه‌های U)به همهٔ پیام‌ها پاسخ می‌دهد
چت گروهی ‏(شناسه‌های C)وقتی گروه در لیست مجاز باشد پاسخ می‌دهد
اتاق چندنفره ‏(شناسه‌های R)وقتی اتاق در لیست مجاز باشد پاسخ می‌دهد

متن، تصویر، صوت، ویدیو، فایل، استیکر و موقعیت مکانی ورودی همه هندل می‌شوند. متن خروجی اول از توکن ریپلای رایگان استفاده می‌کند ‏(تک‌مصرف، پنجرهٔ ~۶۰ ثانیه) و وقتی توکن منقضی شد به Push API مترشح برمی‌گردد.

۲ گام ۱: ساخت کانال LINE Messaging API

  1. به کنسول توسعه‌دهندگان LINE بروید.
  2. یک Provider بسازید و زیر آن یک کانال Messaging API.
  3. از تب Basic settings کانال، Channel secret را کپی کنید.
  4. از تب Messaging API به Channel access token (long-lived) اسکرول و Issue را کلیک کنید. توکن را کپی کنید.
  5. در همان تب Messaging API، گزینه‌های Auto-reply messages و Greeting messages را هم خاموش کنید که با ریپلای‌های بات‌تان تداخل نکنند.

۳ گام ۲: expose کردن پورت وب‌هوک

‏LINE وب‌هوک‌ها را روی HTTPS عمومی تحویل می‌دهد. پورت پیش‌فرض ‏8646 است — در صورت نیاز با ‏LINE_PORT عوضش کنید.

bash
# Cloudflare Tunnel (برای تولید توصیه‌شده — hostname ثابت)
cloudflared tunnel --url http://localhost:8646

# ngrok (مناسب توسعه)
ngrok http 8646

# devtunnel
devtunnel create hermes-line --allow-anonymous
devtunnel port create hermes-line -p 8646 --protocol https
devtunnel host hermes-line

URL ‏https://... را کپی کنید — پایین به‌عنوان URL وب‌هوک تنظیمش می‌کنید. حین تست تونل را روشن نگه دارید. برای تولید یک تونل نام‌دار ثابت کلادفلر راه بیندازید تا URL وب‌هوک با ری‌استارت عوض نشود.

۴ گام ۳: پیکربندی هرمس

به ~/.hermes/.env اضافه کنید:

bash
LINE_CHANNEL_ACCESS_TOKEN=YOUR_LONG_LIVED_TOKEN
LINE_CHANNEL_SECRET=YOUR_CHANNEL_SECRET

# لیست مجاز — دست‌کم یکی از این‌ها (یا LINE_ALLOW_ALL_USERS=true برای توسعه)
LINE_ALLOWED_USERS=U1234567890abcdef...           # شناسه‌های U-دار جداشده با ویرگول
LINE_ALLOWED_GROUPS=C1234567890abcdef...          # شناسه‌های گروه اختیاری
LINE_ALLOWED_ROOMS=R1234567890abcdef...           # شناسه‌های اتاق اختیاری

# الزامی برای ارسال تصویر / صوت / ویدیو — base URL عمومی HTTPS
# که تونل بهش حل می‌شود. بدون این، send_image/voice/video از ارسال امتناع می‌کند.
LINE_PUBLIC_URL=https://my-tunnel.example.com

سپس در config.yaml:

yaml
gateway:
  platforms:
    line:
      enabled: true

همین کافی است — اسکن افزونه‌های همراه‌بسته در ‏gateway/config.py خودکار ‏plugins/platforms/line/ را برمی‌دارد. نه ویرایش enum ‏Platform.LINE لازم است نه ثبت ‏_create_adapter.

۵ گام ۴: تنظیم URL وب‌هوک

به کنسول LINE برگردید:

  1. کانال‌تان ← تب Messaging API را باز کنید.
  2. تحت Webhook settings ← Webhook URL مقدار ‏https://<your-tunnel>/line/webhook را بچسبانید ‏(به مسیر ‏/line/webhook دقت کنید — آداپتور همانجا گوش می‌دهد).
  3. Verify را کلیک کنید. LINE به URL پینگ می‌زند؛ باید ۲۰۰ ببینید.
  4. ‏Use webhook را روی On بگذارید.

۶ گام ۵: اجرای گیت‌وی

hermes gateway

لاگ ایجنت نشان می‌دهد:

LINE: webhook listening on * (all interfaces, IPv4+IPv6):8646/line/webhook (public: https://my-tunnel.example.com)

از اپ LINE بات را به‌عنوان دوست اضافه کنید ‏(QR تب Messaging API کانال را اسکن کنید) و بهش پیام بدهید.

۷ پاسخ‌های کند LLM

توکن ریپلای LINE تک‌مصرف است و تقریباً ۶۰ ثانیه بعد از رویداد ورودی منقضی می‌شود. LLM های کند نمی‌توانند به‌موقع جواب دهند، که معمولاً یعنی فراخوانی پرداخت‌دار Push API.

وقتی LLM از ‏LINE_SLOW_RESPONSE_THRESHOLD ثانیه ‏(پیش‌فرض ‏45) هم گذشت و هنوز در حال اجراست، آداپتور توکن ریپلای اصلی را صرف ارسال حباب Template Buttons می‌کند:

🤔 Still thinking. Tap below to fetch the answer when it's ready.

[ Get answer ]

کاربر هر وقت خواست روی Get answer ضربه می‌زند — آن postback یک توکن ریپلای تازه تحویل می‌دهد که آداپتور برای فرستادن جواب کش‌شده استفاده می‌کند ‏(هنوز رایگان).

ماشین حالت: ‏PENDING → READY → DELIVERED به‌اضافهٔ ‏ERROR برای اجراهای لغوشده ‏(PENDING بی‌صاحب بعد از ‏/stop به «Run was interrupted before completion.» حل می‌شود تا دکمهٔ ماندگار حلقه نزند).

برای خاموش‌کردن دکمهٔ postback و همیشه fallback به Push:

LINE_SLOW_RESPONSE_THRESHOLD=0

برای شلیک مطمئن جریان postback، چرت‌وپرتی را که قبل از آستانه توکن ریپلای را مصرف کند سرکوب کنید:

yaml — ~/.hermes/config.yaml
display:
  interim_assistant_messages: false
  platforms:
    line:
      tool_progress: off

۸ تحویل کرون / اعلان

LINE_HOME_CHANNEL=Uxxxxxxxxxxxxxxxxxxxx     # هدف تحویل پیش‌فرض

کارهای کرون با ‏deliver: line به ‏LINE_HOME_CHANNEL مسیریابی می‌شوند. آداپتور یک فرستندهٔ مستقلِ فقط-Push دارد تا کارهای کرون حتی وقتی کرون در پروسهٔ جدا از گیت‌وی اجرا می‌شود کار کنند.

۱۰ عیب‌یابی

«invalid signature» هنگام تأیید وب‌هوک. یا ‏Channel secret اشتباه کپی شده یا تونلتان بدنهٔ درخواست را بازنویسی کرده. اول با ‏curl -i https://<tunnel>/line/webhook/health تست کنید — باید ‏{"status":"ok","platform":"line"} برگرداند.

بات در گروه‌ها هیچ چیزی نمی‌گیرد. چک کنید ‏LINE_ALLOWED_GROUPS شناسهٔ گروه ‏C... را داشته باشد. برای یافتن شناسهٔ گروه، پیام تستی بدهید و در ‏~/.hermes/logs/gateway.log دنبال ‏LINE: rejecting unauthorized source بگردید — dict مبدأ ردشده شناسه‌ها را دارد.

‏send_image با «LINE_PUBLIC_URL must be set» شکست می‌خورد. ‏Messaging API لاین آپلود باینری نمی‌پذیرد — تصاویر، صدا و ویدیو باید URL های HTTPS قابل‌رسید باشند. ‏LINE_PUBLIC_URL را روی hostname عمومی تونل بگذارید؛ آداپتور فایل‌ها را خودکار از ‏/line/media/<token>/<filename> سرو می‌کند.

دکمهٔ postback هرگز ظاهر نمی‌شود. یا LLM سریع‌تر از ‏LINE_SLOW_RESPONSE_THRESHOLD جواب داده، یا حباب دیگری ‏(پیشرفت ابزار، استریم) توکن ریپلای را زودتر مصرف کرده. بلوک سرکوب بخش «پاسخ‌های کند LLM» را ببینید.

«already in use by another profile». همان توکن دسترسی کانال به پروفایل هرمس دیگری که در حال اجراست قفل شده. گیت‌وی دیگر را متوقف کنید یا کانال جداگانه‌ای بسازید.

۱۱ محدودیت‌ها

  • سقف حباب و طول. هر حباب متنی LINE سقف ۵۰۰۰ کاراکتر دارد. پاسخ‌های بلندتر هوشمندانه در ~۴۵۰۰ کاراکتر بین حداکثر ۵ حباب به‌ازای هر فراخوانی Reply/Push تکه می‌شوند، با شکستن روی مرزهای طبیعی هرجا ممکن باشد.
  • بدون ویرایش بومی پیام. ‏LINE API ویرایش پیام ندارد — پاسخ‌های استریم همیشه حباب تازه می‌فرستند، هرگز حباب قبلی را ویرایش نمی‌کنند.
  • بدون رندر مارک‌داون. ضخیم ‏(**)، ایتالیک ‏(*)، بلوک کد و تیترها به‌صورت کاراکتر تحت‌اللفظی رندر می‌شوند. آداپتور قبل از ارسال حذفشان می‌کند؛ URL ها حفظ می‌شوند ‏([label](url) تبدیل به ‏label (url) می‌شود).
  • نشانگر بارگذاری فقط DM است. ‏LINE API ‏chat/loading را برای گروه‌ها و اتاق‌ها رد می‌کند، پس نشانگر تایپ فقط در چت‌های ۱:۱ نمایش داده می‌شود.
