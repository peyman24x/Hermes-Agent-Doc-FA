‏A2A ‏(Agent-to-Agent)

A2A پروتکل باز Agent2Agent است ‏(v1.0، تحت نظارت بنیاد لینوکس) برای ارتباط بین ایجنت‌های هوش مصنوعی مستقل. افزونهٔ A2A هرمس در هر دو جهت کار می‌کند: ایجنت شما می‌تواند ایجنت‌های A2A دیگر را به‌عنوان ابزار صدا بزند و ایجنت‌های دیگر می‌توانند از طریق HTTP به هرمس شما کار بسپارند.

با هر همتای سازگار-با-A2A تعامل دارد — یک هرمس دیگر، ‏LangChain، ‏CrewAI، ایجنت‌های Google ADK یا هر چیز ساخته‌شده روی ‏a2a-sdk رسمی.

۱ کِی از A2A استفاده کنیم

  • هرمس ↔ هرمس بین ماشین‌ها — ایجنت دسکتاپ‌تان کارها را به یک هرمس روی سرور بسپارد یا برعکس؛ هرکدام حافظه، ابزار و اعتبارنامهٔ خودشان را دارند.
  • واگذاری به ایجنت‌های متخصص — همتایی که روی Agent Card خود مهارت‌های ‏web_search/research/coding را اعلان کند وسط گفتگو کشف و فراخوانی می‌شود.
  • تبدیل‌شدن به سرویس قابل-فراخوانی — هرمس خود را expose کنید تا ایجنت‌های سایر فریم‌ورک‌ها بهش کار بفرستند.

وقتی چند ایجنت روی همان ماشین می‌خواهید، ‏واگذاری ‏(زیرایجنت‌های درون-پروسه) یا تخته کانبان ‏(صف کار ماندگار چند-پروفایلی) را ترجیح دهید — ‏A2A برای عبور از مرزهای پروسه/ماشین/فریم‌ورک است.

۲ فعال‌سازی

hermes gateway setup      # A2A را انتخاب کنید

یا در config.yaml:

yaml
gateway:
  platforms:
    a2a:
      enabled: true
      extra:
        port: 9900

ابزارهای کلاینت خروجی به‌عنوان تول‌ست a2a عرضه می‌شوند، به‌طور پیش‌فرض خاموش — به‌ازای پلتفرم فعالش کنید:

bash
hermes tools enable a2a --platform cli        # نشست‌های CLI/TUI
hermes tools enable a2a --platform telegram   # یا هر پلتفرم پیام‌رسانی
hermes tools enable a2a --platform a2a        # اجازه به کارهای ورودی A2A برای صدا زدن همتاها (زنجیره‌سازی ایجنت)

ابزارها در همهٔ انواع پروسه در دسترس‌اند — CLI، ‏TUI، گیت‌وی و کرون — بدون نیاز به فعال بودن پلتفرم ورودی.

۳ خروجی: صدا زدن ایجنت‌های دیگر

با تول‌ست a2a فعال، ایجنت این‌ها را می‌گیرد:

ابزارکارکرد
a2a_discover(url)دریافت و خلاصه‌سازی Agent Card همتا
a2a_call(agent, message, context_id?)ارسال کار و گرفتن پاسخ؛ چندنوبتی با ‏context_id
a2a_list()همتاهای پیکربندی‌شده، گفتگوهای ذخیره‌شده، متریک‌ها
a2a_history(context_id)بازیابی گفتگوی ماندگار A2A
a2a_orchestrate(capability, message, mode?)پخش کار به همهٔ همتاهای اعلان‌کنندهٔ یک قابلیت ‏(all / ‏first / ‏best)

همتاهای شناخته‌شده را در config.yaml پیکربندی کنید:

yaml
a2a_agents:
  researcher:
    url: "http://research-box.local:9900"
    auth: { type: bearer, token: "..." }
    timeout: 120
    capabilities: [web_search, research]

سپس فقط بپرسید: «از ایجنت researcher بخواه پست‌های امروز arXiv را خلاصه کند.» URL مستقیم هم کار می‌کند — ‏a2a_call هر endpoint سازگار-با-A2A را می‌پذیرد.

۴ ورودی: قابل-فراخوانی بودن

با فعال بودن پلتفرم، هرمس این‌ها را سرو می‌دهد:

  • ‏Agent Card روی ‏GET /.well-known/agent-card.json ‏(مسیر مرجع v1.0؛ مسیر قدیمی ‏agent.json هم جواب می‌دهد) — نام ایجنت، مهارت‌ها ‏(مشتق از تول‌ست‌های فعال) و الزامات احراز را اعلان می‌کند.
  • JSON-RPC 2.0 روی ‏POST / — روش‌های مرجع v1.0 ‏(SendMessage، ‏SendStreamingMessage، ‏GetTask، ‏ListTasks، ‏CancelTask، ‏SubscribeToTask، CRUD پیکربندی اعلان push) به‌اضافهٔ alias های مسیری قبل-از-1.0 ‏(message/send و...).
  • استریم SSE برای ‏SendStreamingMessage با فریم‌های محصور JSON-RPC مطابق مشخصات.
  • اعلان‌های push ‏(وب‌هوک) برای کارهای طولانی، با امضای HMAC-SHA256.

کارهای ورودی به یک نشست زندهٔ گیت‌وی تزریق می‌شوند — همان ایجنت، حافظه و ابزارهایی که سایر کانال‌ها را سرویس می‌دهند — و ریپلای نهایی به‌عنوان نتیجهٔ کار به فراخواننده برمی‌گردد. گفتگوها با ‏contextId مربوط به A2A کلید می‌خورند، پس همتا می‌تواند تبادل چندنوبتی داشته باشد.

تعامل‌پذیری با ‏a2a-sdk رسمی پایتون تأیید شده ‏(حل card، ‏SendMessage، استریم).

۵ مدل امنیت

امن به‌طور پیش‌فرض؛ هر گام گشادشدن صریح است:

  • بدون توکن ⇒ فقط localhost. سرور روی ‏127.0.0.1 بایند می‌شود. در معرض گذاشتن راه‌دور توکن bearer و ‏A2A_HOST صریح می‌خواهد.
  • توکن به‌ازای-همتا — ‏A2A_PEER_TOKENS="alice:tok1,bob:tok2" به هر همتا اعتبارنامهٔ خودش را می‌دهد؛ نام احرازشده پیشران سقف نرخ، اعتماد و audit است.
  • فیلتر prompt-injection — متن ورودی فیلتر و به‌عنوان ورودی غیرقابل‌اعتمادِ همتا قاب می‌شود. همتاهای راه‌دور نمی‌توانند فرمان‌های اسلش اپراتوری را invoke کنند.
  • سانسور خروجی — رشته‌های شبیه-اعتبارنامه ‏(کلیدهای API، ‏JWT، توکن‌ها) از پاسخ‌ها پاک می‌شوند.
  • لاگ حسابرسی — هر تبادل به ‏~/.hermes/a2a_audit.jsonl الصاق می‌شود.
  • ضدحلقه — سقف نوبت به‌ازای-زمینه مانع ping-pong بی‌پایان دو ایجنت می‌شود.

۶ مرجع پیکربندی

متغیر envپیش‌فرضمعنی
A2A_PEER_TOKENS—اعتبارنامه‌های به‌ازای-همتا ‏name:token,… ‏(ترجیحی)
A2A_BEARER_TOKEN—توکن مشترک؛ هویت به IP فراخواننده برمی‌گردد
A2A_HOST127.0.0.1میزبان bind — فقط وقتی توکن تنظیم باشد گشاد می‌شود
A2A_PORT9900پورت ورودی
A2A_AGENT_NAMEمشتق از hostnameنام روی Agent Card
A2A_PUBLIC_URL—URL مسیریابی‌پذیر اعلان‌شده روی کارت ‏(پروکسی معکوس / k8s)
A2A_TRUSTED_PEERS—لیست مجاز هویت‌های احرازشده
A2A_ALLOW_ALL_USERSfalseاجازه به هر همتای احرازشده ‏(فقط توسعه)
A2A_RATE_LIMIT60درخواست/دقیقه به‌ازای هر هویت
A2A_MAX_PINGPONG_TURNS5سقف نوبت ضدحلقه به‌ازای هر زمینه ‏(حداکثر ۲۰)
A2A_REPLY_TIMEOUT300ثانیه انتظار برای ریپلای ایجنت
A2A_PUSH_SECRETbearer tokenرمز HMAC برای امضای اعلان‌های push
A2A_ADVERTISED_TOOLSETSهمهٔ ثبت‌شده‌هامحدودکردن اینکه کدام مهارت‌ها روی Agent Card ظاهر شوند

پشت پروکسی معکوس یا Kubernetes Service مقدار ‏A2A_PUBLIC_URL را بگذارید ‏(یا به ‏X-Forwarded-Host/X-Forwarded-Proto اتکا کنید) تا Agent Card URLی را اعلان کند که همتاها واقعاً بتوانند به آن callback بزنند.

۷ تست سریع

bash
# از ماشین / ایجنت دیگر:
curl http://your-host:9900/.well-known/agent-card.json

curl -X POST http://your-host:9900/ \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer <token>' \
  -d '{"jsonrpc":"2.0","id":1,"method":"SendMessage",
       "params":{"message":{"messageId":"m1","role":"ROLE_USER",
                 "parts":[{"text":"What tools do you have?"}]}}}'

۸ عیب‌یابی

  • همتاها به URL کارت نمی‌رسند — کارت آدرس bind شما را اعلان کرده بود؛ ‏A2A_PUBLIC_URL را روی URL خارجیِ مسیریابی‌پذیر بگذارید.
  • ‏401 Unauthorized — عدم‌تطبیق توکن؛ ‏A2A_PEER_TOKENS/A2A_BEARER_TOKEN سمت سرور و بلوک ‏auth: همتا را چک کنید.
  • سرور روی غیر-localhost بایند نمی‌شود — عمدی است: اول bearer token بگذارید بعد ‏A2A_HOST=0.0.0.0.
  • ریپلای‌ها در کارهای طولانی timeout می‌شوند — ‏A2A_REPLY_TIMEOUT را بالا ببرید، یا فراخواننده را وادار کنید پیکربندی اعلان push ثبت و ‏GetTask را poll کند.
