راه‌اندازی پیامک ‏(Twilio)

هرمس از طریق API ‏Twilio به پیامک وصل می‌شود. مردم به شمارهٔ Twilio شما SMS می‌زنند و پاسخ هوش مصنوعی می‌گیرند — همان تجربهٔ گفتگویی تلگرام یا دیسکورد، ولی روی پیامک استاندارد.

📌 اعتبارنامهٔ مشترک

گیت‌وی SMS اعتبارنامه‌اش را با مهارت تلفنی اختیاری به اشتراک می‌گذارد. اگر از قبل Twilio را برای تماس صوتی یا SMS تک‌موردی راه انداخته‌اید، گیت‌وی با همان TWILIO_ACCOUNT_SID، ‏TWILIO_AUTH_TOKEN و TWILIO_PHONE_NUMBER کار می‌کند.

۱ پیش‌نیازها

  • حساب Twilio — ‏ثبت‌نام در twilio.com ‏(نسخهٔ آزمایشی رایگان موجود است)
  • یک شماره تلفن Twilio با قابلیت SMS
  • یک سرور قابل‌دسترس عمومی — Twilio وقتی SMS می‌رسد وب‌هوک به سرور شما می‌فرستد
  • aiohttp — ‏cd ~/.hermes/hermes-agent && uv pip install -e ".[sms]"

۲ گام ۱: دریافت اعتبارنامه‌های Twilio

  1. به کنسول Twilio بروید
  2. ‏Account SID و Auth Token را از داشبورد کپی کنید
  3. به Phone Numbers ← Manage ← Active Numbers بروید — شماره تلفن‌تان را در قالب E.164 یادداشت کنید ‏(مثل +15551234567)

۳ گام ۲: پیکربندی هرمس

راه‌اندازی تعاملی ‏(توصیه‌شده)

bash
hermes gateway setup

SMS (Twilio) را از فهرست پلتفرم‌ها انتخاب کنید. ویزارد اعتبارنامه‌ها را می‌پرسد.

راه‌اندازی دستی

به ~/.hermes/.env اضافه کنید:

bash
TWILIO_ACCOUNT_SID=ACxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
TWILIO_AUTH_TOKEN=your_auth_token_here
TWILIO_PHONE_NUMBER=+15551234567

# امنیت: محدودکردن به شماره‌های خاص (توصیه‌شده)
SMS_ALLOWED_USERS=+15559876543,+15551112222

# اختیاری: کانال خانگی برای تحویل کارهای کرون
SMS_HOME_CHANNEL=+15559876543

۴ گام ۳: پیکربندی وب‌هوک Twilio

Twilio باید بداند پیام‌های ورودی را کجا بفرستد. در کنسول Twilio:

  1. به Phone Numbers ← Manage ← Active Numbers بروید
  2. روی شماره تلفن‌تان کلیک کنید
  3. تحت Messaging ← A MESSAGE COMES IN تنظیم کنید:
    • Webhook: ‏https://your-server:8080/webhooks/twilio
    • HTTP Method: ‏POST
💡 در معرض گذاشتن وب‌هوک

اگر هرمس را محلی اجرا می‌کنید، برای expose کردن وب‌هوک از یک تونل استفاده کنید:

bash
# با cloudflared
cloudflared tunnel --url http://localhost:8080

# با ngrok
ngrok http 8080

URL عمومی حاصل را به‌عنوان وب‌هوک Twilio تنظیم کنید.

‏SMS_WEBHOOK_URL را روی همان URLی که در Twilio پیکربندی کردید بگذارید. برای اعتبارسنجی امضای Twilio الزامی است — آداپتور بدون آن از شروع امتناع می‌کند:

bash
# باید با URL وب‌هوک کنسول Twilio مطابق باشد
SMS_WEBHOOK_URL=https://your-server:8080/webhooks/twilio

پورت وب‌هوک پیش‌فرض 8080 است. با این override کنید:

bash
SMS_WEBHOOK_PORT=3000

۵ گام ۴: شروع گیت‌وی

bash
hermes gateway

باید این را ببینید:

text
[sms] Twilio webhook server listening on 127.0.0.1:8080, from: +1555***4567

اگر Refusing to start: SMS_WEBHOOK_URL is required دیدید، ‏SMS_WEBHOOK_URL را روی URL عمومیِ پیکربندی‌شده در کنسول Twilio بگذارید ‏(گام ۳).

به شمارهٔ Twilio‌تان پیامک بزنید — هرمس از طریق SMS پاسخ می‌دهد.

۶ متغیرهای محیطی

متغیرلازمتوضیح
TWILIO_ACCOUNT_SIDبله‏Account SID تویلیو ‏(با AC شروع می‌شود)
TWILIO_AUTH_TOKENبله‏Auth Token تویلیو ‏(برای اعتبارسنجی امضای وب‌هوک هم استفاده می‌شود)
TWILIO_PHONE_NUMBERبلهشماره تلفن Twilio شما ‏(قالب E.164)
SMS_WEBHOOK_URLبلهURL عمومی برای اعتبارسنجی امضای Twilio — باید با URL وب‌هوک کنسول Twilio مطابق باشد
SMS_WEBHOOK_PORTخیرپورت گوش‌دهندهٔ وب‌هوک ‏(پیش‌فرض: 8080)
SMS_WEBHOOK_HOSTخیرآدرس bind وب‌هوک ‏(پیش‌فرض: 127.0.0.1)
SMS_INSECURE_NO_SIGNATUREخیر‏true برای غیرفعال‌کردن اعتبارسنجی امضا ‏(فقط توسعه محلی — برای تولید نه)
SMS_ALLOWED_USERSخیرشماره‌های E.164 جداشده با ویرگول که حق چت دارند
SMS_ALLOW_ALL_USERSخیر‏true برای اجازه به همه ‏(توصیه نمی‌شود)
SMS_HOME_CHANNELخیرشماره تلفن مقصد تحویل کارهای کرون / اعلان‌ها
SMS_HOME_CHANNEL_NAMEخیرنام نمایشی کانال خانگی ‏(پیش‌فرض: Home)

۷ رفتار مخصوص SMS

  • فقط متن ساده — مارک‌داون خودکار حذف می‌شود چون SMS آن را به‌صورت کاراکترهای تحت‌اللفظی رندر می‌کند
  • سقف ۱۶۰۰ کاراکتر — پاسخ‌های بلندتر در مرزهای طبیعی ‏(اول خط جدید، بعد فاصله) بین چند پیام تقسیم می‌شوند
  • پیشگیری از پژواک — پیام‌های شمارهٔ Twilio خودتان نادیده گرفته می‌شوند تا حلقه ساخته نشود
  • سانسور شماره تلفن — شماره‌ها برای حریم خصوصی در لاگ‌ها سانسور می‌شوند

۸ امنیت

اعتبارسنجی امضای وب‌هوک

هرمس با تأیید هدر X-Twilio-Signature ‏(HMAC-SHA1) اعتبارسنجی می‌کند که وب‌هوک‌های ورودی واقعاً از Twilio آمده‌اند. این مانع تزریق پیام جعلی توسط مهاجمان می‌شود.

‏SMS_WEBHOOK_URL الزامی است. آن را روی URL عمومی پیکربندی‌شده در کنسول Twilio بگذارید. آداپتور بدون آن از شروع امتناع می‌کند.

برای توسعه محلی بدون URL عمومی می‌توانید اعتبارسنجی را خاموش کنید:

bash
# فقط توسعه محلی — برای تولید نیست
SMS_INSECURE_NO_SIGNATURE=true

لیست مجاز کاربران

گیت‌وی به‌طور پیش‌فرض همهٔ کاربران را رد می‌کند. لیست مجاز پیکربندی کنید:

bash
# توصیه‌شده: محدودکردن به شماره‌های مشخص
SMS_ALLOWED_USERS=+15559876543,+15551112222

# یا اجازه به همه (برای بات‌های دارای دسترسی ترمینال توصیه نمی‌شود)
SMS_ALLOW_ALL_USERS=true
⚠️ هشدار

‏SMS رمزنگاری داخلی ندارد. مگر پیامدهای امنیتی‌اش را بدانید، از SMS برای عملیات حساس استفاده نکنید. برای موارد حساس، سیگنال یا تلگرام را ترجیح دهید.

۹ عیب‌یابی

پیام‌ها نمی‌رسند

  1. چک کنید URL وب‌هوک Twilio درست و عمومی‌دسترس است
  2. تأیید کنید TWILIO_ACCOUNT_SID و TWILIO_AUTH_TOKEN درست‌اند
  3. در کنسول Twilio ← Monitor ← Logs ← Messaging خطاهای تحویل را چک کنید
  4. مطمئن شوید شماره‌تان در SMS_ALLOWED_USERS است ‏(یا SMS_ALLOW_ALL_USERS=true)

پاسخ‌ها ارسال نمی‌شوند

  1. چک کنید TWILIO_PHONE_NUMBER درست تنظیم شده ‏(قالب E.164 با +)
  2. تأیید کنید حساب Twilio‌تان شماره‌های دارای قابلیت SMS دارد
  3. خطاهای API تویلیو را در لاگ‌های گیت‌وی هرمس چک کنید

تداخل پورت وب‌هوک

اگر پورت 8080 اشغال است عوضش کنید:

bash
SMS_WEBHOOK_PORT=3001

URL وب‌هوک را در کنسول Twilio هم مطابق به‌روز کنید.
