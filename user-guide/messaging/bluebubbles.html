‏BlueBubbles ‏(iMessage)

هرمس را از طریق BlueBubbles به iMessage اپل وصل کنید — سرور متن‌باز رایگان macOS که iMessage را به هر دستگاهی پل می‌زند.

۱ پیش‌نیازها

  • یک مک ‏(همیشه روشن) با اجرای ‏BlueBubbles Server
  • ‏Apple ID وارد‌شده در Messages.app روی همان مک
  • ‏BlueBubbles Server نسخهٔ ۱.۰.۰+ ‏(وب‌هوک‌ها این نسخه را می‌خواهند)
  • اتصال شبکه بین هرمس و سرور BlueBubbles

۲ راه‌اندازی

۱. نصب BlueBubbles Server

از bluebubbles.app دانلود و نصب کنید. ویزارد راه‌اندازی را کامل کنید — با Apple ID وارد شوید و روش اتصال را پیکربندی کنید ‏(شبکهٔ محلی، ‏Ngrok، ‏Cloudflare یا DNS داینامیک).

۲. گرفتن Server URL و رمز

در BlueBubbles Server ← Settings ← API این‌ها را یادداشت کنید:

  • Server URL ‏(مثل ‏http://192.168.1.10:1234)
  • Server Password

۳. پیکربندی هرمس

ویزارد راه‌اندازی را اجرا کنید:

hermes gateway setup

BlueBubbles (iMessage) را انتخاب و URL سرور و رمز را وارد کنید.

یا متغیرهای محیطی را مستقیم در ‏~/.hermes/.env بگذارید:

BLUEBUBBLES_SERVER_URL=http://192.168.1.10:1234
BLUEBUBBLES_PASSWORD=your-server-password

اختیاری: منشن اجباری در چت‌های گروهی

به‌طور پیش‌فرض هرمس به همهٔ DM ها/پیام‌های گروه مجازِ BlueBubbles/iMessage پاسخ می‌دهد. برای انتخابی‌کردن چت گروهی گیت منشن را فعال کنید:

yaml
platforms:
  bluebubbles:
    enabled: true
    extra:
      require_mention: true

با ‏require_mention: true، ‏DM ها عادی کار می‌کنند ولی پیام‌های چت گروهی مگر الگوی منشن بخوانند نادیده گرفته می‌شوند. اگر الگوی سفارشی نگذارید، هرمس برای واریانت‌های «Hermes» و «‎@Hermes agent» پیش‌فرض‌های محافظه‌کارانه دارد.

برای نام ایجنت سفارشی، الگوهای regex بگذارید:

yaml
platforms:
  bluebubbles:
    extra:
      require_mention: true
      mention_patterns:
        - '(?<![\w@])@?amos\b[,:\-]?'

۴. مجوز کاربران

یک رویکرد انتخاب کنید:

جفت‌سازی DM ‏(توصیه‌شده):
وقتی کسی به iMessage شما پیام دهد، هرمس خودکار کد جفت‌سازی می‌فرستد. تأیید کنید:

hermes pairing approve bluebubbles <CODE>

با ‏hermes pairing list کدهای در انتظار و کاربران تأییدشده را ببینید.

پیش-مجوز کاربران خاص ‏(در ‏~/.hermes/.env):

BLUEBUBBLES_ALLOWED_USERS=user@icloud.com,+15551234567

دسترسی باز ‏(در ‏~/.hermes/.env):

BLUEBUBBLES_ALLOW_ALL_USERS=true

۵. شروع گیت‌وی

hermes gateway run

هرمس به سرور BlueBubbles شما وصل، وب‌هوک ثبت و گوش‌دادن به پیام‌های iMessage را شروع می‌کند.

۳ نحوهٔ کار

text
iMessage → Messages.app → BlueBubbles Server → Webhook → Hermes
Hermes → BlueBubbles REST API → Messages.app → iMessage
  • ورودی: BlueBubbles وقتی پیام جدید می‌رسد رویدادهای وب‌هوک به شنوندهٔ محلی می‌فرستد. بدون polling — تحویل آنی.
  • خروجی: هرمس از طریق REST API بلابابلز پیام می‌فرستد.
  • رسانه: تصویر، پیام صوتی، ویدیو و سند در هر دو جهت پشتیبانی می‌شود. پیوست‌های ورودی دانلود و محلی کش می‌شوند تا ایجنت پردازششان کند.

۴ متغیرهای محیطی

متغیرلازمپیش‌فرضتوضیح
BLUEBUBBLES_SERVER_URLبله—URL سرور BlueBubbles
BLUEBUBBLES_PASSWORDبله—رمز سرور
BLUEBUBBLES_WEBHOOK_HOSTخیر127.0.0.1آدرس bind شنوندهٔ وب‌هوک
BLUEBUBBLES_WEBHOOK_PORTخیر8645پورت شنوندهٔ وب‌هوک
BLUEBUBBLES_WEBHOOK_PATHخیر/bluebubbles-webhookمسیر URL وب‌هوک
BLUEBUBBLES_HOME_CHANNELخیر—شماره/ایمیل مقصد تحویل کرون
BLUEBUBBLES_ALLOWED_USERSخیر—کاربران مجاز جداشده با ویرگول
BLUEBUBBLES_ALLOW_ALL_USERSخیرfalseاجازه به همهٔ کاربران
BLUEBUBBLES_REQUIRE_MENTIONخیرfalseالزام الگوی منشن قبل از پاسخ در چت‌های گروهی
BLUEBUBBLES_MENTION_PATTERNSخیرواژه‌های بیداری هرمسآرایه JSON یا الگوهای regex جداشده با خط‌جدید/ویرگول برای تطبیق منشن گروهی

علامت‌گذاری خودکار پیام‌ها به‌عنوان خوانده‌شده با کلید ‏send_read_receipts زیر ‏platforms.bluebubbles.extra در config.yaml کنترل می‌شود ‏(پیش‌فرض: true). متغیر محیطی معادلی ندارد.

۵ قابلیت‌ها

پیام متنی

ارسال و دریافت iMessage. مارک‌داون برای تحویل تمیزِ متن ساده خودکار حذف می‌شود.

رسانه غنی

  • تصاویر: عکس‌ها به‌صورت بومی در گفتگوی iMessage ظاهر می‌شوند
  • پیام‌های صوتی: فایل‌های صوتی به‌عنوان پیام صوتی iMessage
  • ویدیوها: پیوست ویدیویی
  • اسناد: فایل‌ها به‌عنوان پیوست iMessage

واکنش‌های Tapback

واکنش‌های Love، like، dislike، laugh، emphasize و question. نیازمند helper ‏Private API بلابابلز.

نشانگر تایپ

حین پردازش ایجنت «typing...» در گفتگوی iMessage نشان داده می‌شود. Private API لازم دارد.

تیک خوانده‌شدن

پس از پردازش پیام‌ها خودکار خوانده‌شده علامت می‌خورند. Private API لازم دارد.

خطاب چت‌ها

می‌توانید چت‌ها را با ایمیل یا شماره تلفن خطاب کنید — هرمس خودکار آنها را به GUID های چت بلابابلز حل می‌کند. لازم نیست از فرمت خام GUID استفاده کنید.

۶ Private API

بعضی قابلیت‌ها helper ‏Private API بلابابلز را می‌خواهند:

  • واکنش‌های Tapback
  • نشانگرهای تایپ
  • تیک خوانده‌شدن
  • ساخت چت جدید با آدرس

بدون Private API، پیام‌رسانی متنی پایه و رسانه همچنان کار می‌کنند.

۷ عیب‌یابی

«Cannot reach server»

  • درستی URL سرور و روشن بودن مک را تأیید کنید
  • چک کنید BlueBubbles Server اجراست
  • اتصال شبکه را مطمئن شوید ‏(فایروال، port forwarding)

پیام‌ها نمی‌رسند

  • چک کنید وب‌هوک در BlueBubbles Server ← Settings ← API ← Webhooks ثبت شده باشد
  • تأیید کنید URL وب‌هوک از مک قابل‌دسترس است
  • خطاهای وب‌هوک را در ‏hermes logs gateway چک کنید ‏(یا ‏hermes logs -f برای دنبال‌کردن زنده)

«Private API helper not connected»

  • helper ‏Private API را نصب کنید: ‏docs.bluebubbles.app
  • پیام‌رسانی پایه بدون آن کار می‌کند — فقط واکنش‌ها، تایپ و تیک خوانده‌شدن لازمش دارند
