پروکسی خروجی ‏(Egress proxy)

فایروال اختیاریِ تزریق-credential ی خروجی برای sandbox های ترمینال راه‌دور. sandbox فقط توکن‌های پروکسی opaque را می‌بیند؛ کلیدهای API ی واقعی هرگز host را ترک نمی‌کنند.
