حالت تحویل‌دادنی ‏(آرتیفکت‌ها در چت)

وقتی هرمس ایجنت داخل یک گیت‌وی پیام‌رسانی اجرا می‌شود ‏(Slack، ‏Discord، ‏Telegram، ‏WhatsApp، ‏Signal و...)، می‌تواند فایل‌های تولیدی را مستقیم داخل چت تحویل دهد — نه به‌صورت مسیرهایی که کاربر باید کپی کند بلکه به‌عنوان پیوست بومی.

نمودار به‌صورت تصویر درون‌خطی ظاهر می‌شود. گزارش PDF به‌صورت دانلود فایل می‌آید. صفحه‌گسترده به‌صورت ‏.xlsx آپلود می‌شود. ایجنت لازم نیست تگ ‏MEDIA: بنویسد یا کار خاصی بکند — فقط فایل را تولید و مسیر مطلقش را در پاسخ ذکر می‌کند. گیت‌وی مسیر را از متن بیرون می‌کشد، از پیام مرئی حذف و فایل را native آپلود می‌کند.

۱ نحوهٔ کار

سه قطعه کنار هم می‌نشینند:

  1. ایجنت ابزارهایی دارد که فایل تولید می‌کنند. ‏execute_code برای نمودار با matplotlib، مهارت ‏docx برای اسناد Word، مهارت ‏xlsx برای صفحات گسترده، مهارت‌های ‏pdf و ‏latex-pdf-report برای PDF ها، مهارت ‏powerpoint برای اسلایدها، ‏image_generate برای تصاویر، ‏text_to_speech برای صدا و غیره.
  2. گیت‌وی پاسخ‌های ایجنت را برای مسیرهای فایل اسکن می‌کند. هر مسیر مطلق ‏(/tmp/...) یا مسیر نسبی-به-خانه ‏(~/...) که با پسوند پشتیبانی‌شده تمام شود استخراج می‌شود. مسیرهای داخل بلوک‌های کد و کد درون‌خطی نادیده گرفته می‌شوند تا نمونه‌کدها هرگز مثله نشوند.
  3. گیت‌وی بر اساس نوع فایل dispatch می‌کند. تصاویر هرجا پلتفرم پشتیبانی کند درون‌خطی embed می‌شوند؛ ویدیوها درون‌خطی؛ صدا به پیوست voice/audio مسیریابی می‌شود؛ بقیه به‌عنوان پیوست فایل آپلود می‌شوند.

۳ تشویق ایجنت به تولید آرتیفکت

ایجنت پیش‌فرض سراغ آرتیفکت نمی‌رود — باید بداند که باید. دو راه سرکش کردنش:

به‌ازای-نشست: صریحاً بخواهید ‏(«مقایسه را به‌صورت نمودار برایم بفرست»، «داده را CSV برگردان») یا دستورالعمل سفارشی/ورودی شخصیتی خودتان را طوری بنویسید که روی پلتفرم‌های پیام‌رسانی به ریپلای‌های سبک-آرتیفکت تمایل پیدا کند.

در سطح پروژه: تمایل را به ‏AGENTS.md / ‏CLAUDE.md / ‏.cursorrules پروژه‌ای که ایجنت از آن کار می‌کند، به persona سراسری‌تان در ‏~/.hermes/SOUL.md، یا به‌عنوان preset نام‌دار زیر ‏agent.personalities در ‏~/.hermes/config.yaml بیفزایید ‏(قابل تعویض به‌ازای نشست با ‎/personality).

مکانیکی که ایجنت باید استفاده کند ساده است: فایل را به یک مسیر مطلق رندر کنید ‏(مثلاً ‏/tmp/q3-revenue.png) و آن مسیر را به‌صورت متن ساده در ریپلای ذکر کنید. بقیه‌اش با گیت‌وی است. مسیرهای داخل بلوک‌های کد محصور یا backtick ها نادیده گرفته می‌شوند تا نمونه‌کدها هرگز مثله نشوند.

۴ کانبان: آرتیفکت‌ها سوار اعلان‌های تکمیل می‌شوند

اگر از گردش‌کار چند-ایجنتیِ کانبان هرمس استفاده می‌کنید، worker ها می‌توانند فایل‌های deliverable را به فراخوانی ‏kanban_complete خودشان الصاق کنند:

python
kanban_complete(
    summary="rendered Q3 revenue chart and report",
    artifacts=[
        "/tmp/q3-revenue.png",
        "/tmp/q3-report.pdf",
    ],
)

وقتی notifier گیت‌وی پیام «task تکمیل شد» را به مشترکِ task در Slack/Telegram/و... تحویل می‌دهد، هر آرتیفکت را هم به‌عنوان پیوست native به همان چت آپلود می‌کند. انسان deliverable و خلاصه را یک‌جا می‌گیرد.

فایل‌هایی که موقع اجرای notifier روی دیسک موجود نباشند بی‌صدا رد می‌شوند.

۵ اتصال سرویس‌های بیشتر با MCP

فراتر از خط‌لوله تحویل آرتیفکت، ایجنت می‌تواند از طریق MCP ‏(Model Context Protocol) به سرویس‌های دیگر دست بزند. اکوسیستم MCP سرورهای اجتماعی برای اغلب ابزارهای محبوب دارد — هرکدام که لازم دارید نصب کنید:

سرویسچه چیزی باز می‌کند
Notionخواندن/نوشتن صفحات Notion، دیتابیس‌ها، query ورک‌اسپیس
GitHubissue ها، PR ها، کامنت‌ها، جست‌وجوی repo فراتر از CLI ‏gh
Linearتیکت‌ها، پروژه‌ها، چرخه‌ها
Slackجست‌وجوی کل-ورک‌اسپیس، خواندن کانال‌های دیگر
Gmailtriage صندوق ورودی، ارسال ایمیل، مدیریت برچسب‌ها
Salesforceلیدها، فرصت‌ها، دادهٔ حساب‌ها
Snowflake / BigQuerySQL علیه انبارهای داده
Google Driveجست‌وجوی فایل، محتویات، مدیریت اشتراک‌گذاری

سرورهای MCP را از طریق بخش ‏mcp_servers در ‏~/.hermes/config.yaml نصب کنید. راهنمای کامل setup در یکپارچه‌سازی MCP.

۶ مقایسه با Perplexity Computer در Slack

یکپارچه‌سازی Slack مربوط به Perplexity Computer حول همان ایده ساخته شده: ایجنت یک deliverable تولید ‏(نمودار، PDF، اسلاید) و به‌عنوان پیوست native به همان ترد پست برمی‌گرداند. حالت deliverable مربوط به هرمس ایجنت همان الگوی رو-به-کاربر را محلی فراهم می‌کند:

  • تولید داخل venv/sandbox خود کاربر اتفاق می‌افتد ‏(بدون tenant راه‌دور).
  • فایل‌ها از طریق همان API ‏files.uploadV2 اسلک وارد چت می‌شوند.
  • پهنای connector از طریق MCP می‌آید به‌جای کاتالوگ منتخبِ ۴۰۰ یکپارچه‌سازی میزبانی‌شده — همان‌هایی که واقعاً استفاده می‌کنید نصب کنید.

توکن‌های OAuth روی ماشین کاربر در ‏auth.json/.env می‌مانند. بدون مخزن توکن میزبانی‌شده. بدون microVM چند-مستأجری. همان نتیجهٔ نهایی.
