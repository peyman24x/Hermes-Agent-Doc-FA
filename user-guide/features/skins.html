پوسته‌ها و تم‌ها ‏(Skins & Themes)

‏پوسته‌ها ارائهٔ بصری مربوط به CLI هرمس را کنترل می‌کنند: رنگ‌های بنر، صورتک‌ها و فعل‌های spinner، برچسب‌های جعبه پاسخ، متن برندینگ و پیشوند فعالیت ابزار.

سبک گفتاری و سبک بصری مفاهیم جدایند:

  • شخصیت لحن و واژگان ایجنت را عوض می‌کند.
  • پوسته ظاهر CLI را عوض می‌کند.

۱ تغییر پوسته‌ها

bash
/skin                # show the current skin and list available skins
/skin ares           # switch to a built-in skin
/skin mytheme        # switch to a custom skin from ~/.hermes/skins/mytheme.yaml

یا پوستهٔ پیش‌فرض را در config.yaml ست کنید:

yaml
display:
  skin: default

warm-lightmodeمتن قهوه‌ای/طلایی گرم برای پس‌زمینه‌های روشن ترمینال‏Hermes Agentتن‌های پوست‌مانند گرم برای ترمینال‌های روشن. متن قهوه‌ای تیره با اکسنت‌های قهوه‌ای زین، سطوح وضعیت کرم. جایگزین خاکیِ گزینهٔ سردتر daylight.

charizardتم آتشفشانی — نارنجی سوخته و اخگر‏Charizard Agentگرادیان نارنجی سوخته گرم تا اخگری. spinner های آتشین ‏(«banking into the draft»، «measuring burn»). بنر ASCII سیلوئت اژدها.

۳ فهرست کامل کلیدهای قابل پیکربندی

Spinner ‏(spinner:)

spinner متحرکی که حین انتظار برای پاسخ API نمایش داده می‌شود را کنترل می‌کند.

کلیدنوعتوضیحمثال
waiting_facesفهرست رشتهصورتک‌های چرخان حین انتظار پاسخ API‏["(⚔)", "(⛨)", "(▲)"]
thinking_facesفهرست رشتهصورتک‌های چرخان حین استدلال مدل‏["(⚔)", "(⌁)", "(<>)"]
thinking_verbsفهرست رشتهافعالی که در پیام‌های spinner نشان داده می‌شوند‏["forging", "plotting", "hammering plans"]
wingsفهرست جفت [چپ، راست]براکت‌های تزئینی دور spinner‏[["⟪⚔", "⚔⟫"], ["⟪▲", "▲⟫"]]

وقتی مقادیر spinner خالی باشند ‏(مثل ‏default و ‏mono) از پیش‌فرض‌های هاردکد ‏display.py استفاده می‌شود.

برندینگ ‏(branding:)

رشته‌های متنی استفاده‌شده در سراسر interface مربوط به CLI.

کلیدتوضیحپیش‌فرض
agent_nameنام نشان‌داده‌شده در عنوان بنر و نمایش وضعیتHermes Agent
welcomeپیام خوش‌آمد هنگام شروع CLIWelcome to Hermes Agent! Type your message or /help for commands.
goodbyeپیام هنگام خروجGoodbye! ⚕
response_labelبرچسب روی سربرگ جعبه پاسخ ⚕ Hermes

help_headerمتن سربرگ خروجی فرمان ‏/help(^_^)? Available Commands

۴ پوسته‌های سفارشی

فایل‌های YAML زیر ‏~/.hermes/skins/ بسازید. پوسته‌های کاربری مقادیر غایب را از پوستهٔ داخلی ‏default ارث می‌برند، پس فقط کلیدهایی که می‌خواهید عوض شوند را لازم است مشخص کنید.

قالب کامل YAML پوسته سفارشی

yaml — ~/.hermes/skins/mytheme.yaml
# Complete skin template — all keys shown. Delete any you don't need;
# missing values automatically inherit from the 'default' skin.

name: mytheme
description: My custom theme

colors:
  banner_border: "#CD7F32"
  banner_title: "#FFD700"
  banner_accent: "#FFBF00"
  banner_dim: "#B8860B"
  banner_text: "#FFF8DC"
  ui_accent: "#FFBF00"
  ui_label: "#4dd0e1"
  ui_ok: "#4caf50"
  ui_error: "#ef5350"
  ui_warn: "#ffa726"
  prompt: "#FFF8DC"
  input_rule: "#CD7F32"
  response_border: "#FFD700"
  session_label: "#DAA520"
  session_border: "#8B8682"
  status_bar_bg: "#1a1a2e"
  voice_status_bg: "#1a1a2e"
  selection_bg: "#333355"
  completion_menu_bg: "#1a1a2e"
  completion_menu_current_bg: "#333355"
  completion_menu_meta_bg: "#1a1a2e"
  completion_menu_meta_current_bg: "#333355"

spinner:
  waiting_faces:
    - "(⚔)"
    - "(⛨)"
    - "(▲)"
  thinking_faces:
    - "(⚔)"
    - "(⌁)"
    - "(<>)"
  thinking_verbs:
    - "processing"
    - "analyzing"
    - "computing"
    - "evaluating"
  wings:
    - ["⟪⚡", "⚡⟫"]
    - ["⟪●", "●⟫"]

branding:
  agent_name: "My Agent"
  welcome: "Welcome to My Agent! Type your message or /help for commands."
  goodbye: "See you later! ⚡"
  response_label: " ⚡ My Agent "
  prompt_symbol: "⚡"
  help_header: "(⚡) Available Commands"

tool_prefix: "┊"

# Per-tool emoji overrides (optional)
tool_emojis:
  terminal: "⚔"
  web_search: "🔮"
  read_file: "📄"

# Custom ASCII art banners (optional, Rich markup supported)
# banner_logo: |
#   [bold #FFD700] MY AGENT [/]
# banner_hero: |
#   [#FFD700]  Custom art here  [/]

۵ ‏Hermes Mod — ویرایشگر بصری پوسته

Hermes Mod یک UI وب ساخته‌شده توسط جامعه برای ساخت و مدیریت بصری پوسته‌هاست. به‌جای نوشتن دستی YAML، یک ویرایشگر اشاره-و-کلیک با پیش‌نمایش زنده می‌گیرید.

چه کاری می‌کند:

  • همهٔ پوسته‌های داخلی و سفارشی را فهرست می‌کند
  • هر پوسته را در یک ویرایشگر بصری با همهٔ فیلدهای پوسته هرمس باز می‌کند ‏(رنگ‌ها، spinner، برندینگ، پیشوند ابزار، ایموجی ابزارها)
  • هنر متنی ‏banner_logo را از یک پرامپت متنی تولید می‌کند
  • تصاویر آپلودی ‏(PNG، ‏JPG، ‏GIF، ‏WEBP) را به هنر ASCII ‏banner_hero با چند سبک رندر تبدیل می‌کند ‏(braille، ramp مربوط به ASCII، بلوک‌ها، نقاط)
  • مستقیم در ‏~/.hermes/skins/ ذخیره می‌کند
  • پوسته را با به‌روزرسانی ‏~/.hermes/config.yaml فعال می‌کند
  • YAML تولیدشده و یک پیش‌نمایش زنده نشان می‌دهد

نصب

گزینه ۱ — Pinokio ‏(یک کلیک): آن را در ‏pinokio.computer پیدا و با یک کلیک نصب کنید.

گزینه ۲ — npx ‏(سریع‌ترین از ترمینال):

npx -y hermes-mod

گزینه ۳ — دستی:

bash
git clone https://github.com/cocktailpeanut/hermes-mod.git
cd hermes-mod/app
npm install
npm start

استفاده

  1. اپ را اجرا کنید ‏(از طریق Pinokio یا ترمینال).
  2. Skin Studio را باز کنید.
  3. یک پوسته داخلی یا سفارشی برای ویرایش انتخاب کنید.
  4. لوگو را از متن تولید و/یا تصویری برای هنر hero آپلود کنید. سبک رندر و عرض را انتخاب کنید.
  5. رنگ‌ها، spinner، برندینگ و سایر فیلدها را ویرایش کنید.
  6. Save را کلیک کنید تا YAML پوسته در ‏~/.hermes/skins/ نوشته شود.
  7. Activate را کلیک کنید تا به‌عنوان پوسته فعلی ست شود ‏(display.skin را در config.yaml به‌روز می‌کند).

‏Hermes Mod متغیر محیطی ‏HERMES_HOME را رعایت می‌کند، پس با پروفایل‌ها هم کار می‌کند.

۶ یادداشت‌های عملیاتی

  • پوسته‌های داخلی از ‏hermes_cli/skin_engine.py لود می‌شوند.
  • پوسته‌های ناشناخته خودکار به ‏default برمی‌گردند.
  • ‏/skin تم فعال CLI را برای نشست جاری فوراً به‌روز می‌کند.
  • پوسته‌های کاربری در ‏~/.hermes/skins/ بر پوسته‌های داخلی هم‌نام مقدم‌اند.
  • تغییرات پوسته از طریق ‏/skin مخصوص همان نشست است. برای دائمی کردن، در config.yaml ست کنید.
  • فیلدهای ‏banner_logo و ‏banner_hero از markup کنسول Rich ‏(مثل ‏[bold #FF0000]text[/]) برای هنر ASCII رنگی پشتیبانی می‌کنند.
