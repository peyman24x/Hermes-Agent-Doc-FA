گیت‌وی ابزار Nous ‏(Nous Tool Gateway)

یک اشتراک. هر ابزار از قبل ساخته‌شده.

گیت‌وی ابزار با هر اشتراک پولی Nous Portal ارائه می‌شود. فراخوانی‌های ابزار هرمس — جستجوی وب، تولید تصویر، تبدیل متن به گفتار و اتوماسیون مرورگر ابری — را از طریق زیرساختی که خود Nous اجرا می‌کند مسیریابی می‌کند، پس لازم نیست فقط برای کارا شدن ایجنتتان سراغ Firecrawl، ‏FAL، ‏OpenAI، ‏Browser Use یا هر شرکت دیگری بروید.

💡 مدیریت اشتراک

شروع یا مدیریت اشتراک ←

۱ چه چیزهایی شامل می‌شود

ابزارچه می‌گیرید
🔍جستجو و استخراج وبجستجوی وبِ درجه-ایجنت و استخراج تمام‌صفحه از طریق Firecrawl. نگران rate limit نباشید — گیت‌وی مقیاس‌پذیری را هندل می‌کند.
🎨تولید تصویرنه مدل زیر یک نقطهٔ پایانی: ‏FLUX 2 Klein 9B، ‏FLUX 2 Pro، ‏Z-Image Turbo، ‏Nano Banana Pro ‏(Gemini 3 Pro Image)، ‏GPT Image 1.5، ‏GPT Image 2، ‏Ideogram V3، ‏Recraft V4 Pro، ‏Qwen Image. هر-تولید با یک فلگ انتخاب کنید یا اجازه دهید هرمس پیش‌فرض FLUX 2 Klein باشد.
🔊تبدیل متن به گفتارصداهای TTS ی OpenAI متصل به ابزار text_to_speech. ویس‌نوت در تلگرام بیندازید، برای خط‌لوله‌ها صدا بسازید، هر چیزی را روایت کنید.
🌐اتوماسیون مرورگر ابرینشست‌های Chromium بدون-سر از طریق Browser Use. ‏browser_navigate، ‏browser_click، ‏browser_type، ‏browser_vision — همهٔ primitiveهای راندن ایجنت، بدون نیاز به حساب Browserbase.

هر چهار مورد pay-as-you-use هستند و روی اشتراک Nous شما صورتحساب می‌شوند. هر ترکیبی را به کار ببرید — گیت‌وی را برای وب و تصویر روشن کنید و کلید ElevenLabs خودتان را برای TTS نگه دارید، یا همه‌چیز را از Nous عبور دهید.

۲ چرا اینجا هست

ساختن ایجنتی که واقعاً کاری انجام دهد یعنی به‌هم دوختن بیش از ۵ اشتراک API — هر کدام با ثبت‌نام، rate limit، صورتحساب و عادت‌های خودشان. گیت‌وی همهٔ آن را در یک حساب جمع می‌کند:

  • یک قبض. به Nous پرداخت کنید؛ بقیه با ما.
  • یک ثبت‌نام. نه حساب Firecrawl، نه FAL، نه Browser Use، نه OpenAI audio برای مدیریت.
  • یک کلید. OAuth ی Nous Portal شما همهٔ ابزارها را پوشش می‌دهد.
  • همان کیفیت. همان بک‌اندهایی که مسیر مستقیم-با-کلید استفاده می‌کند — فقط ما جلویشان ایستاده‌ایم.

هر وقت خواستید کلیدهای خودتان را بیاورید — per-tool، هر لحظه. گیت‌وی قفل نیست، میان‌بر است.

۳ شروع کنید

سه راه ورود هست — هر کدام که به وضعیت شما می‌خورد:

hermes setup --portal     # Fresh install: Nous OAuth + set Nous as provider + turn on the Tool Gateway in one go
hermes model              # Switch your inference provider to Nous Portal — Hermes then offers to turn on the gateway for all tools
hermes tools              # Enable the gateway per-tool — pick "Nous Subscription" for any tool you want

‏hermes setup --portal و hermes model مسیرهای یکجا هستند: یک بار وارد شوید، در صورت تمایل همهٔ ابزارها را به گیت‌وی بزنید. ‏hermes tools مسیر à la carte است — فقط ابزارهایی که می‌خواهید یکی‌یکی روشن کنید.

لازم نیست اول وارد شوید. با hermes tools بک‌اندهای مدیریت‌شده-توسط-Nous ‏(Web search، ‏Image، ‏Video، ‏TTS، ‏Browser) همیشه فهرست می‌شوند حتی اگر هرگز وارد Nous Portal نشده باشید. یکی را انتخاب کنید و هرمس اگر احراز هویت نباشید همان‌جا ورود Portal را اجرا می‌کند — نیازی به اجرای قبلی hermes model نیست. اگر OAuth ی Nous تان فعال است انتخابِ بک‌اند فوراً آن را روشن می‌کند بدون پرامپت اضافه. این مسیر فقط لاگین‌تان می‌کند و همان یک ابزار انتخابی را روشن می‌کند — ارائه‌دهندهٔ inference شما را عوض نمی‌کند و برای فعال کردن گیت‌وی روی بقیهٔ ابزارها پرامپت نمی‌دهد.

هر لحظه بررسی کنید چه چیزی فعال است:

hermes portal info        # Portal auth + Tool Gateway routing summary
hermes portal tools       # Gateway catalog with current routing per tool
hermes status             # Full system status (Tool Gateway is one section)

‏hermes portal info بخشی مثل این نشان می‌دهد:

◆ Nous Tool Gateway
  Nous Portal     ✓ managed tools available
  Web tools       ✓ active via Nous subscription
  Image gen       ✓ active via Nous subscription
  TTS             ✓ active via Nous subscription
  Browser         ○ active via Browser Use key

ابزارهایی با برچسب «active via Nous subscription» از گیت‌وی عبور می‌کنند. بقیه از کلیدهای خودتان استفاده می‌کنند.

۴ شرایط استفاده

گیت‌وی ابزار یک قابلیت اشتراک-پولی است. حساب‌های رایگان Nous می‌توانند از Portal برای inference استفاده کنند ولی ابزارهای مدیریت‌شده شاملشان نمی‌شود — برای باز کردن گیت‌وی پلنتان را ارتقا دهید.

بعضی حساب‌ها همچنین مشمول یک استخر ابزار رایگان هستند — سهم کوچکی از ابزارهای مدیریت‌شده که فراخوانی‌های گیت‌وی را بدون اشتراک پولی پوشش می‌دهد. وقتی استخر رایگان موجود باشد گیت‌وی آن را نمایش می‌دهد و در اولین استفاده یک پرامپت راه‌اندازی نشان می‌دهد تا شرکت کنید و همین حالا شروع کنید.

۵ چک‌لیست فعال‌سازی

انتخاب یک مدل Nous ‏(hermes model) یک چک‌لیست per-tool از بک‌اندهای گیت‌وی پیشنهاد می‌کند. رفتارش به پیکربندی فعلی شما احترام می‌گذارد:

  • ابزارهایی که صریحاً به بک‌اند دیگری اشاره داده‌اید ‏(مثلاً web.backend: searxng، ‏browser.cloud_provider: camofox) هرگز پیشنهاد نمی‌شوند — انتخاب‌تان نمی‌تواند تصادفی بازنویسی شود.
  • ابزارهایی که فقط از طریق متغیر محیطی پیکربندی شده‌اند ‏(مثلاً SEARXNG_URL، ‏CAMOFOX_URL) تیک‌خورده پیشنهاد می‌شوند، با برچسبی که می‌گوید بک‌اند خودتان حفظ می‌شود.
  • فقط ابزارهای واقعاً پیکربندی‌نشده از قبل تیک می‌خورند.
  • رد کردن‌ها می‌ماند: اگر چک‌لیست را با ابزاری تیک‌نخورده ثبت کنید در تعویض‌های بعدی مدل Nous دیگر تیک‌خورده پیشنهاد نمی‌شود ‏(در tool_gateway_declined_tools داخل config.yaml ذخیره می‌شود؛ تیک زدن بعدی ردشدگی را پاک می‌کند).

۶ ترکیب دلخواه

گیت‌وی per-tool است. فقط برای چیزی که می‌خواهید روشنش کنید:

  • همهٔ ابزارها از Nous — ساده‌ترین؛ یک اشتراک، تمام.
  • گیت‌وی برای وب + تصویر، TTS از خودتان — صدای ElevenLabs تان را نگه دارید، بقیه با Nous.
  • گیت‌وی فقط برای چیزهایی که کلیدشان را ندارید — «برای Browserbase پول می‌دهم اما حوصلهٔ حساب Firecrawl ندارم» کاملاً جواب می‌دهد.

هر ابزار را هر لحظه سوئیچ کنید:

hermes tools          # Interactive picker for each tool category

ابزار را انتخاب و Nous Subscription را به‌عنوان ارائه‌دهنده برگزینید ‏(یا هر ارائه‌دهندهٔ مستقیم دیگری). هیچ ویرایش config لازم نیست. اگر هنوز وارد Nous Portal نشده‌اید انتخابِ «Nous Subscription» ورود Portal را inline راه می‌اندازد — لازم نیست اول از hermes model احراز هویت کنید.

۸ مرجع پیکربندی

بیشتر کاربران هرگز به این نیاز پیدا نمی‌کنند — ‏hermes model و hermes tools همهٔ گردش‌کارها را تعاملی پوشش می‌دهند. این بخش برای نوشتن مستقیم config.yaml یا اسکریپت‌کردن راه‌اندازی‌هاست.

یک کلید انتخاب به‌ازای هر دستهٔ ابزار

هر دستهٔ ابزار یک کلید انتخاب-ارائه‌دهنده دارد که توسط picker ی hermes tools ‏(یا GUI دسکتاپ) نوشته می‌شود. انتخاب ردیف Nous Subscription مقدار nous را ذخیره می‌کند که آن دسته را از گیت‌وی ابزار مدیریت‌شده عبور می‌دهد. انتخاب ردیف BYOK نام فروشنده را ذخیره می‌کند ‏(fal، ‏openai، ‏firecrawl، ‏browser-use و…) که مستقیم با اعتبارنامه‌های خودتان می‌رود:

yaml
web:
  backend: nous          # web search/extract via the Tool Gateway

image_gen:
  provider: nous         # image generation via the Tool Gateway

tts:
  provider: nous         # TTS via the Tool Gateway

stt:
  provider: nous         # speech-to-text via the Tool Gateway

browser:
  cloud_provider: nous   # cloud browser via the Tool Gateway

runtime همیشه از انتخاب ذخیره‌شده استفاده می‌کند — حضور اعتبارنامه هرگز دسته‌ای را انتخاب یا تغییر مسیر نمی‌دهد. یک FAL_KEY نشسته در .env در حالی که image_gen.provider: nous است نادیده گرفته می‌شود؛ برعکس، ‏image_gen.provider: fal بدون ست بودن FAL_KEY خطای شفاف می‌دهد نه اینکه بی‌سروصدا به گیت‌وی سقوط کند:

image_gen is configured to use fal (set via hermes tools), but FAL_KEY is not set. Run 'hermes tools' to change it.

دسته‌هایی که هرگز پیکربندی نشده‌اند ‏(هیچ کلید انتخابی نوشته نشده) مثل قبل از اعتبارنامه‌های موجود autodetect می‌کنند. اما به‌محض وجود یک انتخاب، اضافه کردن کلیدی به .env مسیر را عوض نمی‌کند — فقط hermes tools ‏(یا ویرایش کلید انتخاب) عوضش می‌کند.

برگشت به کلیدهای خودتان

hermes tools    # pick the tool → choose a direct provider (e.g. Firecrawl)

یا کلید انتخاب را مستقیم ست کنید:

yaml
web:
  backend: firecrawl   # Hermes now uses FIRECRAWL_API_KEY from .env

فلگ قدیمی use_gateway ‏(منسوخ)

نسخه‌های قدیمی‌تر هرمس از بولین per-tool ی use_gateway: true برای عبور از گیت‌وی استفاده می‌کردند. آن فلگ legacy است: دیگر هرگز نوشته نمی‌شود و picker ی hermes tools هنگام بازنویسی انتخاب، آن را از config دسته حذف می‌کند. config های قدیمی که هنوز use_gateway: true دارند موقع خواندن به‌عنوان انتخاب nous تفسیر می‌شوند پس راه‌اندازی‌های فعلی کار می‌کنند. در config های جدید use_gateway نگذارید — به‌جایش ارائه‌دهنده را در hermes tools انتخاب کنید.

گیت‌وی خودمیزبان ‏(پیشرفته)

گیت‌وی سازگار-با-Nous خودتان را اجرا می‌کنید؟ نقاط پایانی را در ~/.hermes/.env بازنویسی کنید:

TOOL_GATEWAY_DOMAIN=your-domain.example.com
TOOL_GATEWAY_SCHEME=https
TOOL_GATEWAY_USER_TOKEN=your-token        # normally auto-populated from Portal login
FIRECRAWL_GATEWAY_URL=https://...         # override one endpoint specifically

این پیچ‌ومهره‌ها برای راه‌اندازی‌های زیرساخت سفارشی‌اند ‏(استقرار سازمانی، محیط توسعه). مشترکان عادی هرگز آنها را ست نمی‌کنند.

۹ سؤالات متداول

با تلگرام / دیسکورد / بقیهٔ گیت‌وی‌های پیام‌رسانی کار می‌کند؟

بله. گیت‌وی ابزار در لایهٔ اجرای ابزار عمل می‌کند نه CLI. هر رابطی که بتواند ابزار صدا بزند — CLI، ‏تلگرام، ‏دیسکورد، ‏اسلک، ‏IRC، ‏Teams، ‏سرور API، هرچه — به‌طور شفاف از آن بهره می‌برد.

اگر اشتراکم منقضی شود چه می‌شود؟

ابزارهایی که از گیت‌وی عبور می‌کنند تا تمدید کنید یا از طریق hermes tools کلیدهای API مستقیم جایگزین کنید از کار می‌افتند. هرمس خطای شفافی به سمت portal نشان می‌دهد.

می‌توانم مصرف یا هزینهٔ هر ابزار را ببینم؟

بله — داشبورد Nous Portal مصرف را به تفکیک ابزار می‌شکند تا ببینید چه چیزی قبضتان را بالا می‌برد.

آیا Modal ‏(ترمینال serverless) شامل است؟

‏Modal به‌عنوان افزونهٔ اختیاری از طریق اشتراک Nous موجود است، نه بخشی از بستهٔ پیش‌فرض Tool Gateway. از طریق hermes setup terminal یا مستقیماً در config.yaml پیکربندی‌اش کنید وقتی sandbox راه‌دوری برای اجرای شل می‌خواهید.

با فعال کردن گیت‌وی باید کلیدهای API موجودم را حذف کنم؟

نه — در .env نگهشان دارید. وقتی انتخاب یک ابزار Nous Subscription است، کلیدهای مستقیمِ آن ابزار صرفاً نادیده گرفته می‌شوند. دوباره ارائه‌دهندهٔ مستقیم را در hermes tools بردارید و کلیدهایتان دوباره منبع می‌شوند. گیت‌وی قفل نیست.
