جستجوی X ‏(توییتر)

ابزار x_search به ایجنت اجازه می‌دهد پست‌ها، پروفایل‌ها و رشته‌های X ‏(توییتر) را مستقیماً جستجو کند. پشتوانه‌اش ابزار داخلیِ x_search ی xAI روی Responses API در https://api.x.ai/v1/responses است — خود Grok جستجو را سمت سرور اجرا و نتایج ترکیب‌شده با ارجاع به پست‌های مبدأ برمی‌گرداند.

وقتی مشخصاً گفتگوها، واکنش‌ها یا ادعاهای فعلی را «در X» می‌خواهید از این به‌جای web_search استفاده کنید. برای صفحات عمومی وب همان web_search / ‏web_extract را نگه دارید.

۱ ‏x_search در برابر xurl

هرمس می‌تواند دو سطح متفاوت X را در اختیار بگذارد:

سطحبرای چه کاریبرای چه کاری نه
‏x_searchکشف فقط-خواندنیِ X عمومی: گفتگوی روز، واکنش‌ها، ادعاها، پروفایل‌ها، رشته‌ها و پاسخ‌های ترکیب‌شده با ارجاع.پست دادن، ریپلای، لایک، DM، آپلود رسانه، حذف، یا اثبات اینکه یک حساب احراز-هویت‌شده وضعیتش عوض شده.
مهارت xurlکار دقیق یا احراز-هویت‌شدهٔ X API: ‏post، ‏reply، ‏read، ‏like، ‏dm، تایم‌لاین‌ها، منشن‌ها، آپلود رسانه، خواندن‌های مخصوص حساب و نقطه‌پایان‌های خام v2.پژوهش گستردهٔ Grok-ترکیب از X عمومی وقتی x_search موجود است و زمینهٔ حسابِ احراز-هویت‌شده لازم نیست.

برای گردش‌کارهای ترکیبی از x_search برای کشف پست‌های عمومی نامزد استفاده کنید و بعد از روشن شدن پست/کاربر/اقدام هدف، به xurl read یا فرمان دقیق دیگرِ xurl سوئیچ کنید. هر اقدام تغییردهندهٔ وضعیت X باید با خروجی xurl یا پاسخ X API تأیید شود؛ پاسخ x_search هرگز مدرکی برای وقوع یک نوشتن نیست.

💡

اگر به هر حال اشتراک Portal را برای مدل xAI پرداخت می‌کنید، فراخوانی‌های Live Search روی همان کلید xAI پیکربندی‌شده برای چت صورتحساب می‌شوند. بخش Nous Portal را ببینید.

۲ احراز هویت

‏x_search وقتی ثبت می‌شود که یکی از دو مسیر اعتبارنامهٔ xAI در دسترس باشد:

اعتبارنامهمنبعراه‌اندازی
SuperGrok / X Premium+ OAuthورود مرورگری در accounts.x.ai، خودکار refresh می‌شود‏hermes auth add xai-oauth — بخش xAI Grok OAuth ‏(SuperGrok / X Premium+)
‏XAI_API_KEY ‏(ارجح)کلید API پولی xAIدر ~/.hermes/.env ست کنید

هر دو به همان نقطهٔ پایانی با همان payload می‌زنند — تنها تفاوت bearer token است. وقتی هر دو پیکربندی شده‌اند کلید صریحِ XAI_API_KEY برنده است — bearer ی اشتراک OAuth مجوزِ /v1/responses را می‌دهد اما x_search را در حالت توضیحیِ تنزل‌یافتهٔ Grok بدون ارجاع جواب می‌دهد، در حالی که کلید API پست‌های واقعی برمی‌گرداند. توجه کنید این یعنی وقتی کلیدی ست باشد x_search روی صورتحساب مصرفی API اجرا می‌شود؛ ‏XAI_API_KEY را حذف کنید تا به سهمیهٔ اشتراک برگردید ‏(با هشدار پاسخِ تنزل‌یافته).

‏check_fn ی ابزار هر بار که فهرست ابزار مدل بازسازی می‌شود، حل‌کنندهٔ اعتبارنامهٔ xAI را اجرا می‌کند. بازگشت True یعنی bearer قابل‌واکشی و غیرخالی و ‏(اگر منقضی شده بود) موفق در refresh. توکن‌های ابطال‌شده با refresh ناموفق ابزار را از schema پنهان می‌کنند؛ مدل اصلاً نمی‌تواند ببینیدش.

۳ فعال‌سازی ابزار

با حضور اعتبارنامه‌های xAI ‏(توکن OAuth یا XAI_API_KEY) خودکار فعال می‌شود. اگر نمی‌خواهیدش صریحاً از مسیر hermes tools ← Search ← x_search خاموشش کنید.

hermes tools
# → 🐦 X (Twitter) Search   (press space to toggle on)

انتخابگر دو گزینهٔ اعتبارنامه پیشنهاد می‌کند:

  1. xAI Grok OAuth ‏(SuperGrok / Premium+) — اگر وارد نشده باشید مرورگر را به accounts.x.ai باز می‌کند
  2. کلید API ی xAI — مقدار XAI_API_KEY را می‌پرسد

هر انتخاب gating را ارضا می‌کند. هر اعتبارنامه‌ای که از قبل دارید را بردارید؛ ابزار با هر دو یکسان کار می‌کند. اگر هر دو آخرش پیکربندی شدند موقع فراخوانی OAuth ترجیح داده می‌شود.

۴ پیکربندی

yaml
# ~/.hermes/config.yaml
x_search:
  # xAI model used for the Responses call.
  # grok-4.5 is the recommended default; any Grok model
  # with x_search tool access works.
  model: grok-4.5

  # Optional reasoning effort: low, medium, high, or xhigh. When omitted,
  # the selected model's default applies. xhigh is supported only by
  # models that document it, such as grok-4.20-multi-agent.
  # reasoning_effort: low

  # Request timeout in seconds. x_search can take 60–120s for
  # complex queries — the default is generous. Minimum: 30.
  timeout_seconds: 180

  # Number of automatic retries on 5xx / ReadTimeout / ConnectionError.
  # Each retry backs off (1.5x attempt seconds, capped at 5s).
  retries: 2

‏reasoning_effort به‌صورت reasoning: {effort: ...} به Responses API ی xAI فرستاده می‌شود. برای مدلی که استدلال قابل‌پیکربندی ندارد unset بگذارید. مقادیر نامعتبر قبل از هر فراخوانی API شکست می‌خورند.

۵ پارامترهای ابزار

ایجنت x_search را با این آرگومان‌ها صدا می‌زند:

پارامترنوعتوضیح
queryرشته ‏(الزامی)چه چیزی در X جستجو شود.
allowed_x_handlesآرایهٔ رشتهفهرست اختیاری handleها که انحصاراً شامل شوند ‏(حداکثر ۱۰). ‏@ ابتدایی strip می‌شود.
excluded_x_handlesآرایهٔ رشتهفهرست اختیاری handleها برای exclude ‏(حداکثر ۱۰). با allowed_x_handles متقابلاً انحصاری است.
from_dateرشتهتاریخ شروع اختیاری YYYY-MM-DD.
to_dateرشتهتاریخ پایان اختیاری YYYY-MM-DD.
enable_image_understandingbooleanاز xAI بخواهد تصاویر پیوستِ پست‌های منطبق را تحلیل کند.
enable_video_understandingbooleanاز xAI بخواهد ویدیوهای پیوستِ پست‌های منطبق را تحلیل کند.

ابزار JSON ای با این محتوا برمی‌گرداند:

  • ‏answer — پاسخ متنیِ ترکیب‌شده از Grok
  • ‏citations — ارجاع‌های برگشتی در فیلد سطح-بالای Responses API
  • ‏inline_citations — حاشیه‌نویسی‌های url_citation استخراج‌شده از بدنهٔ پیام ‏(هر کدام با url، ‏title، ‏start_index، ‏end_index)
  • ‏degraded — ‏true وقتی یکی از فیلترهای تنگ‌کننده ‏(allowed_x_handles، ‏excluded_x_handles، ‏from_date، ‏to_date) ست شده و هر دو کانال ارجاع خالی برگشته‌اند. در آن حالت answer از دانش خودِ مدل ساخته شده نه ایندکس X، پس بدون-منبع تلقی‌اش کنید. در غیر این صورت false ‏(شامل حالت «هیچ فیلتری ست نشده» — یک پاسخ گستردهٔ بدون-منبع فقط یک پاسخ است، نه خطای فیلتر)
  • ‏degraded_reason — رشتهٔ کوتاهی که نام می‌برد کدام فیلترها فعال بودند، یا null وقتی degraded مقدار false دارد
  • ‏credential_source — ‏"xai-oauth" اگر OAuth حل شد، ‏"xai" اگر کلید API حل شد
  • ‏model، ‏query، ‏provider، ‏tool، ‏success

اعتبارسنجی تاریخ

‏from_date / ‏to_date قبل از فراخوانی HTTP سمت کلاینت اعتبارسنجی می‌شوند:

  • هر دو، اگر داده شوند، باید به‌صورت YYYY-MM-DD تجزیه شوند.
  • وقتی هر دو ست‌اند، ‏from_date باید قبل یا برابر to_date باشد.
  • ‏from_date نباید از امروز UTC جلوتر باشد — در بازه‌ای که هنوز شروع نشده هیچ پستی وجود ندارد، پس فراخوانی قطعاً صفر ارجاع برمی‌گرداند.
  • ‏to_date در آینده مجاز است ‏(فراخواننده ممکن است مشروعاً «از دیروز تا فردا» بخواهد تا پست‌ها را همین‌که می‌آیند بگیرد).

شکست‌های اعتبارسنجی به‌صورت نتیجهٔ ابزار ساختاریافتهٔ {"error": "..."} ظاهر می‌شوند، هرگز به‌شکل فراخوانی HTTP به xAI.

۶ مثال

گفتگو با ایجنت:

مردم در X دربارهٔ قابلیت‌های تصویری جدید Grok چه می‌گویند؟ روی پاسخ‌های @xai تمرکز کن.

ایجنت خواهد کرد:

  1. فراخوانی x_search با ‏query="reactions to new Grok image features" و ‏allowed_x_handles=["xai"]
  2. دریافت یک پاسخ ترکیب‌شده به‌علاوهٔ فهرست ارجاع‌هایی که به پست‌های مشخص لینک می‌دهند
  3. پاسخ دادن با جواب و منابع

اگر درخواست بعدی کاربر «به بهترینش ریپلای بده» یا «آن پست را لایک کن» باشد، ایجنت باید به مهارت xurl سوئیچ کند، پست هدف دقیق را تأیید و اقدام X API را انجام دهد. ‏x_search یک ابزار کشف باقی می‌ماند.

۷ عیب‌یابی

«No xAI credentials available»

ابزار وقتی هر دو مسیر احراز هویت شکست بخورند این را نشان می‌دهد. یا XAI_API_KEY را در ~/.hermes/.env ست کنید یا hermes auth add xai-oauth را اجرا و ورود مرورگری را کامل کنید. سپس نشستتان را ری‌استارت کنید تا ایجنت registry ابزار را دوباره بخواند.

«‏x_search is not enabled for this model»

مدل پیکربندی‌شدهٔ x_search.model به ابزار سمت-سرورِ x_search دسترسی ندارد. به grok-4.5 ‏(پیش‌فرض) یا مدل Grok دیگری که پشتیبانی می‌کند سوئیچ کنید. فهرست فعلی را در مستندات xAI ببینید.

ابزار در schema ظاهر نمی‌شود

دو علت ممکن:

  1. تول‌ست فعال نیست. ‏hermes tools را اجرا و مطمئن شوید 🐦 X (Twitter) Search تیک خورده.
  2. بدون اعتبارنامهٔ xAI. ‏check_fn مقدار False برمی‌گرداند پس schema پنهان می‌ماند. با hermes auth status وضعیت ورود xai-oauth را تأیید کنید و بررسی کنید XAI_API_KEY ست است ‏(اگر مسیر کلید-API هستید).

‏degraded: true — پاسخ بدون ارجاع

وقتی از allowed_x_handles، ‏excluded_x_handles یا بازهٔ تاریخ استفاده کرده‌اید و پاسخ با degraded: true برمی‌گردد، یعنی ایندکس X ی xAI هیچ پست منطبقی نداشت ولی Grok همچنان از دادهٔ آموزشی خودش پاسخی ساخته. پاسخ بی‌منبع است — آن را نتیجهٔ واقعی X تلقی نکنید.

علت‌های ارزش‌بررسی:

  • غلط املایی در handle. ‏@ را بردارید، املای نوشتار را دوباره چک کنید و مطمئن شوید حساب وجود دارد.
  • بازهٔ تاریخ خیلی تنگ است یا از پست‌های امروز عبور می‌کند؛ بازش کنید و دوباره تلاش کنید.
  • شکاف ایندکس xAI. بعضی حساب‌های فعال به‌طور متناوب حتی با پست‌دادن مرتب در x_search ظاهر نمی‌شوند. چند دقیقه بعد دوباره تلاش کنید، یا وقتی تایم‌لاین یک handle دقیق را لازم دارید از مهارت xurl برای خواندن مستقیم X API استفاده کنید.
