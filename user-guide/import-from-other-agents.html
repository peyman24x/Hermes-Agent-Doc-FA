درون‌ریزی از ایجنت‌های دیگر ‏(Import from Other Agents)

‏hermes import-agent راه‌اندازی موجود ‏Claude Code یا ‏OpenAI Codex CLI شما را با یک فرمان به هرمس درون‌ریزی می‌کند. همان الگوی اول-پیش‌نمایشِ ‏hermes claw migrate را دنبال می‌کند: همیشه قبل از نوشتن هر چیزی برنامهٔ per-item می‌بینید و ‏--dry-run هرگز به دیسک دست نمی‌زند.

۱ فرمان‌ها

hermes import-agent                    # auto-detect ~/.claude or ~/.codex
hermes import-agent claude-code        # import from ~/.claude
hermes import-agent codex              # import from ~/.codex
hermes import-agent claude-code --dry-run          # preview only
hermes import-agent codex --source /path/to/.codex # custom location
hermes import-agent claude-code --overwrite --yes  # replace conflicts, skip prompts

۲ چه چیزهایی درون‌ریزی می‌شود

Claude Code ‏(‏~/.claude)

Claude CodeHermes
‏CLAUDE.md ‏(دستورالعمل‌های سراسری)ورودی‌های حافظه در ‏~/.hermes/memories/MEMORY.md
‏settings.json ← ‏permissions.allow ‏(قواعد Bash(...))‏command_allowlist در config.yaml
‏settings.json ← ‏permissions.deny ‏(قواعد Bash(...))‏approvals.deny در config.yaml
‏mcpServers ‏(از ~/.claude.json و settings.json)‏mcp_servers در config.yaml
‏skills/<name>/ ‏(دایرکتوری‌های دارای SKILL.md)‏~/.hermes/skills/claude-code-imports/<name>/
‏commands/*.md ‏(دستورات اسلش)با یادداشت skip می‌شود — آنها را به مهارت تبدیل کنید

قواعد پیشوندی ‏Bash(npm run test:*) ی کلاد به glob های ‏npm run test* تبدیل می‌شوند. قواعد مجوز غیر-Bash ‏(Read(...)، ‏WebFetch و…) ابزارهای مخصوص-Claude را گیت می‌کنند و به‌عنوان بدون-نگاشت گزارش می‌شوند نه اینکه درون‌ریزی شوند.

۳ چه چیزهایی هرگز درون‌ریزی نمی‌شود

کلیدهای API و credential ها. فایل‌های credential ‏(~/.claude/.credentials.json، ‏~/.codex/auth.json) هرگز خوانده نمی‌شوند و متغیرهای محیطی یا هدرهای سرور MCP با نام‌های شبیه-secret ‏(*_TOKEN، ‏*_API_KEY، ‏Authorization و…) حذف و در گزارش فهرست می‌شوند تا عمداً دوباره اضافه‌شان کنید. برای پیکربندی ارائه‌دهنده‌ها hermes setup را اجرا یا secrets را به ‏~/.hermes/.env اضافه کنید.

۴ یادداشت‌های رفتاری

  • همیشه اول پیش‌نمایش. فرمان قبل از اعمال، برنامهٔ کامل را چاپ می‌کند؛ در نشست‌های غیرتعاملی روی پیش‌نمایش متوقف می‌شود مگر --yes پاس دهید.
  • ادغام می‌کند، جایگزین نمی‌کند. ورودی‌های حافظه نسبت به MEMORY.md ی موجود dedup می‌شوند؛ الگوهای allowlist/denylist با آنچه از قبل در config.yaml هست ادغام می‌شوند.
  • تداخل‌ها به‌طور پیش‌فرض skip می‌شوند. سرور MCP یا مهارتی که از قبل در هرمس وجود دارد تداخل گزارش می‌شود؛ --overlap را پاس دهید تا جایگزین شود ‏(--overwrite).
  • فایل‌های بدفرم اجرا را abort نمی‌کنند. settings.json یا config.toml ی خراب یک خطای per-item در گزارش می‌شود در حالی که بقیه همچنان درون‌ریزی می‌شوند.
  • از OpenClaw می‌آیید؟ از ‏hermes claw migrate استفاده کنید.
