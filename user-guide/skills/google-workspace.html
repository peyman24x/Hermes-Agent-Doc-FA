گوگل‌ورک‌اسپیس (جیمیل، تقویم…)

یکپارچگی Gmail، Calendar، Drive، Contacts، Sheets و Docs برای Hermes. از OAuth2 با refresh خودکار توکن استفاده می‌کند. وقتی ‏‏CLI ی Google Workspace ‏(gws) در دسترس باشد برای پوشش گسترده‌تر از آن استفاده می‌کند و در غیر این صورت به کتابخانه‌های کلاینت Python ی Google برمی‌گردد.

مسیر مهارت: ‏skills/productivity/google-workspace/

۱ راه‌اندازی

راه‌اندازی کاملاً ایجنت‌ران است — از هرمس بخواهید Google Workspace را راه‌اندازی کند تا شما را قدم‌به‌قدم همراهی کند. روند کار:

  1. یک پروژهٔ Google Cloud بسازید و APIهای لازم را فعال کنید ‏(Gmail، Calendar، Drive، Sheets، Docs، People)
  2. اعتبارنامه‌های OAuth 2.0 بسازید ‏(از نوع Desktop app) و JSON ی client secret را دانلود کنید
  3. مجوزدهی — هرمس یک auth URL می‌سازد، شما در مرورگر تأیید می‌کنید و URL ی redirect را برمی‌گردانید
  4. تمام — از این به بعد توکن خودکار refresh می‌شود
💡 کاربرانِ فقط-ایمیل

اگر فقط ایمیل می‌خواهید ‏(بدون Calendar/Drive/Sheets)، به‌جای این مهارت از مهارت himalaya استفاده کنید — با یک Gmail App Password کار می‌کند و ۲ دقیقه بیشتر طول نمی‌کشد. نیازی به پروژهٔ Google Cloud نیست.

۲ Gmail

جست‌وجو

$GAPI gmail search "is:unread" --max 10
$GAPI gmail search "from:boss@company.com newer_than:1d"
$GAPI gmail search "has:attachment filename:pdf newer_than:7d"

برای هر پیام JSON ای با ‏id، ‏from، ‏subject، ‏date، ‏snippet و ‏labels برمی‌گرداند.

خواندن

$GAPI gmail get MESSAGE_ID

بدنهٔ کامل پیام را به‌صورت متن برمی‌گرداند ‏(plain text را ترجیح می‌دهد، در غیر این صورت به HTML برمی‌گردد).

ارسال

# ارسال ساده
$GAPI gmail send --to user@example.com --subject "Hello" --body "Message text"

# ایمیل HTML
$GAPI gmail send --to user@example.com --subject "Report" \
  --body "<h1>Q4 Results</h1><p>Details here</p>" --html

# هدر From سفارشی (نام نمایشی + ایمیل)
$GAPI gmail send --to user@example.com --subject "Hello" \
  --from '"Research Agent" <user@example.com>' --body "Message text"

# با CC
$GAPI gmail send --to user@example.com --cc "team@example.com" \
  --subject "Update" --body "FYI"

هدر From سفارشی

فلگ ‏--from اجازه می‌دهد نام نمایشی فرستنده را روی ایمیل‌های خروجی سفارشی کنید. وقتی چند ایجنت یک حساب Gmail مشترک دارند ولی می‌خواهید گیرندگان نام‌های متفاوتی ببینند، این کاربرد دارد:

# ایجنت 1
$GAPI gmail send --to client@co.com --subject "Research Summary" \
  --from '"Research Agent" <shared@company.com>' --body "..."

# ایجنت 2  
$GAPI gmail send --to client@co.com --subject "Code Review" \
  --from '"Code Assistant" <shared@company.com>' --body "..."

نحوهٔ کار: مقدار ‏--from به‌عنوان هدر ‏From ی RFC 5322 روی پیام MIME ست می‌شود. Gmail سفارشی‌سازی نام نمایشی روی همان آدرس ایمیل احراز-هویت‌شدهٔ خودتان را بدون هیچ پیکربندی اضافه‌ای اجازه می‌دهد. گیرندگان نام نمایشی سفارشی را می‌بینند ‏(مثلاً «Research Agent») در حالی که آدرس ایمیل همان می‌ماند.

مهم: اگر در ‏--from یک آدرس ایمیل متفاوت به کار ببرید ‏(نه حساب احراز-هویت‌شده)، Gmail نیاز دارد آن آدرس به‌عنوان ‏Send As alias در مسیر Gmail Settings → Accounts → Send mail as پیکربندی شده باشد.

فلگ ‏--from روی هر دوی ‏send و ‏reply کار می‌کند:

$GAPI gmail reply MESSAGE_ID \
  --from '"Support Bot" <shared@company.com>' --body "We're on it"

پاسخ‌دادن

$GAPI gmail reply MESSAGE_ID --body "Thanks, that works for me."

پاسخ را خودکار در همان رشتهٔ گفتگو قرار می‌دهد ‏(هدرهای ‏In-Reply-To و ‏References را ست می‌کند) و از thread ID پیام اصلی استفاده می‌کند.

برچسب‌ها

# فهرست همهٔ برچسب‌ها
$GAPI gmail labels

# افزودن/حذف برچسب‌ها
$GAPI gmail modify MESSAGE_ID --add-labels LABEL_ID
$GAPI gmail modify MESSAGE_ID --remove-labels UNREAD

۳ Calendar

# فهرست رویدادها (پیش‌فرض: 7 روز آینده)
$GAPI calendar list
$GAPI calendar list --start 2026-03-01T00:00:00Z --end 2026-03-07T23:59:59Z

# ساخت رویداد (منطقهٔ زمانی الزامی است)
$GAPI calendar create --summary "Team Standup" \
  --start 2026-03-01T10:00:00-07:00 --end 2026-03-01T10:30:00-07:00

# با مکان و شرکت‌کنندگان
$GAPI calendar create --summary "Lunch" \
  --start 2026-03-01T12:00:00Z --end 2026-03-01T13:00:00Z \
  --location "Cafe" --attendees "alice@co.com,bob@co.com"

# حذف رویداد
$GAPI calendar delete EVENT_ID
⚠️

زمان‌های تقویم باید آفست منطقهٔ زمانی داشته باشند ‏(مثلاً ‏-07:00) یا از UTC ‏(‏Z) استفاده کنند. تاریخ-زمان‌های بی‌آفست مثل ‏2026-03-01T10:00:00 مبهم‌اند و UTC فرض می‌شوند.

۴ Drive

$GAPI drive search "quarterly report" --max 10

۵ Sheets

# خواندن یک بازه
$GAPI sheets get SHEET_ID "Sheet1!A1:D10"

# نوشتن در یک بازه
$GAPI sheets update SHEET_ID "Sheet1!A1:B2" --values '[["Name","Score"],["Alice","95"]]'

# افزودن ردیف در انتها
$GAPI sheets append SHEET_ID "Sheet1!A:C" --values '[["new","row","data"]]'
