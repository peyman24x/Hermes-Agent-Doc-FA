منبع رمز Command Helper

credential ها را با اجرای فرمان helper ی خودتان هنگام startup حل کنید — هر انبار رمزی که CLI دارد کار می‌کند: ‏keepassxc-cli، ‏secret-tool ‏(GNOME Keyring)، ‏pass، ‏gpg، ‏CLI ی Vaultwarden یا اسکریپتی که یک فایل env ی tmpfs را cat می‌کند. helper خطوط KEY=VALUE را روی stdout چاپ می‌کند؛ هرمس آنها را از طریق همان orchestrator ی Bitwarden و ‏1Password اعمال می‌کند، پس می‌توانید هر ترکیبی از منبع‌ها را همزمان فعال کنید.

۱ نحوهٔ کار

  1. فرمان helper را در config.yaml پیکربندی می‌کنید ‏(هرگز در .env — فرمان پیکربندی است، .env مقادیر را نگه می‌دارد).
  2. موقع startup بعد از لود شدن .env، هرمس helper را یک بار از طریق /bin/sh -c اجرا و stdout اش را به‌عنوان یک blob ی dotenv parse می‌کند.
  3. کلیدهای parse‌شده از نردبان اولویت استاندارد عبور می‌کنند: ‏.env/شل برنده‌اند مگر override_existing: true؛ منبع‌های نگاشتی روی متغیرهای مورد-نزاع بر این منبع انبوه می‌چربند؛ اولین ادعا برنده است.
yaml
secrets:
  command:
    enabled: true
    command: "cat /run/user/1000/hermes-secrets.env"
    # or any vault CLI that dumps KEY=VALUE lines:
    # command: "pass show hermes/env"
    # command: "secret-tool lookup service hermes-env"

۳ مدل امنیتی

  • رشتهٔ فرمان helper پیکربندی خود شماست — همان سطح اعتماد فایل .env ای که کنترلش می‌کنید.
  • خروجی روی ‎۱MiB‎ سقف سخت دارد؛ helper ی خارج از کنترل نمی‌تواند startup را گیر بیندازد ‏(گروه پروسه روی timeout کشته می‌شود).
  • stderr ی helper دور ریخته می‌شود — diagنوستیک‌های CLI ی گاوصندوق می‌توانند مواد secret حمل کنند پس هرگز به خروجی هرمس نمی‌رسند. شکست‌ها فقط فیلدهای ساختاریافته لاg می‌کنند ‏(کد خروج / سیگنال / errno)، هرگز رشتهٔ فرمان نه.
  • مقادیر فقط-فضاصفید «بدون مقدار» تلقی می‌شوند — ورودی placeholder هرگز داخل هدر Authorization جریان نمی‌یابد.
  • فقط-POSIX ‏(/bin/sh لازم دارد). روی ویندوز منبع خودش را پیکربندی‌نشده گزارش و startup ادامه می‌یابد.

کی این به‌جای پلاگین

منبع فرمان دریچهٔ فرار برای گاوصندوق‌های بدون یکپارچه‌سازی داخلی است. اگر دیدید دارید یک رقص CLI پیچیده را در اسکریپت بلندی می‌پیچید، به‌جایش یک پلاگین منبع رمز واقعی در نظر بگیرید — پلاگین‌ها caching، برچسب provenance و config ی type-dar می‌گیرند.
