یکپارچه‌سازی‌ها ‏(Integrations)

‏هرمس Agent برای استنتاج AI، سرورهای ابزار، گردش‌کارهای IDE، دسترسی برنامه‌نویسی‌شده و بیشتر به سیستم‌های بیرونی وصل می‌شود. این یکپارچه‌سازی‌ها گسترش می‌دهند که هرمس چه کارهایی بکند و کجا اجرا شود.

۱ ارائه‌دهندگان AI و مسیریابی

هرمس چندین ارائه‌دهندهٔ استنتاج AI را از جعبه پشتیبانی می‌کند. با hermes model تعاملی تنظیم کنید یا مستقیم در config.yaml بگذارید.

  • ارائه‌دهندگان AI — OpenRouter، Anthropic، OpenAI، Google و هر نقطهٔ پایانی سازگار-با-OpenAI. هرمس قابلیت‌هایی مثل بینایی، streaming و مصرف ابزار را per-provider خودآشکار می‌کند.
  • مسیریابی ارائه‌دهنده — کنترل ریزدانه بر اینکه کدام ارائه‌دهندگان زیرین درخواست‌های OpenRouter تان را هندل کنند. بهینه‌سازی برای هزینه، سرعت یا کیفیت با sorting، ‏whitelist، ‏blacklist و ترتیب اولویت صریح.
  • ارائه‌دهندگان پشتیبان — failover ی خودکار به ارائه‌دهندگان LLM ی پشتیبان وقتی مدل اصلی خطا می‌دهد؛ شامل fallback مدل اصلی و fallback مستقل تسک‌های کمکی برای بینایی، فشرده‌سازی و استخراج وب.
💡 از همین‌جا شروع کنید

اگر فقط وقت راه‌اندازی یک یکپارچه‌سازی را دارید، Nous Portal را راه بیندازید — یک ورود OAuth بیش از ۳۰۰ مدل به‌علاوهٔ چهار ابزار Tool Gateway ‏(جستجوی وب، تولید تصویر، TTS و اتوماسیون مرورگر) را پوشش می‌دهد.

سرورهای ابزار ‏(MCP)

  • سرورهای MCP — هرمس را به سرورهای ابزار بیرونی از طریق Model Context Protocol وصل کنید. ابزارهای GitHub، پایگاه‌های داده، فایل‌سیستم‌ها، browser stack ها، API های داخلی و بیشتر را بدون نوشتن ابزار native ی هرمس داشته باشید. هر دو transport ی stdio و SSE، فیلترکردن per-server و ثبت resource/prompt آگاه-از-قابلیت پشتیبانی می‌شود.

۲ بک‌اندهای جستجوی وب

ابزارهای web_search و web_extract از هشت ارائه‌دهندهٔ بک‌اند پشتیبانی می‌کنند که با config.yaml یا hermes tools پیکربندی می‌شوند:

اتوماسیون مرورگر

  • Browserbase — مرورگرهای ابری مدیریت‌شده با ابزارهای ضد-بات، حل CAPTCHA و پروکسی رزیدنشیال
  • Browser Use — ارائه‌دهندهٔ جایگزین مرورگر ابری
  • CDP خانوادهٔ Chromium محلی — اتصال به Chrome/Brave/Chromium/Edge ی در حال اجرا با ‎/browser connect‎
  • Chromium محلی — مرورگر headless محلی از طریق CLI ی agent-browser

راه‌اندازی و مصرف در صفحهٔ اتوماسیون مرورگر.

۳ صدا و TTS

گفتار-به-متن از هشت ارائه‌دهنده پشتیبانی می‌کند: faster-whisper محلی ‏(رایگان، روی دستگاه)، wrapper فرمان محلی، ‏Groq، ‏OpenAI Whisper API، ‏Mistral، ‏xAI، ‏ElevenLabs Scribe و DeepInfra. رونویسی پیام صوتی روی تلگرام، دیسکورد، واتساپ و سایر پلتفرم‌ها کار می‌کند. جزئیات در صفحات صدا و TTS و ‏حالت صوتی.

۴ IDE، دسترسی برنامه‌نویسی‌شده، حافظه و پیام‌رسانی

  • یکپارچگی IDE ‏(ACP) — هرمس Agent داخل ویرایشگرهای سازگار-با-ACP مثل VS Code، ‏Zed و JetBrains. هرمس به‌عنوان سرور ACP اجرا و پیام‌های چت، فعالیت ابزار، diff های فایل و فرمان‌های ترمینال داخل ویرایشگرتان رندر می‌کند.
  • سرور API — هرمس را به‌عنوان نقطهٔ پایانی HTTP سازگار-با-OpenAI expose کنید. هر frontend ی حرف‌زنندهٔ قالب OpenAI — ‏Open WebUI، ‏LobeChat، ‏LibreChat، ‏NextChat، ‏ChatBox — وصل می‌شود و هرمس را با تول‌ست کاملش به‌عنوان backend مصرف می‌کند.
  • حافظهٔ داخلی — حافظهٔ پایدار منتخب از طریق فایل‌های MEMORY.md و USER.md.
  • ارائه‌دهندگان حافظه — بک‌اندهای حافظهٔ بیرونی برای شخصی‌سازی عمیق‌تر: هشت ارائه‌دهنده پشتیبانی می‌شود.

پلتفرم‌های پیام‌رسانی

هرمس به‌عنوان بات گیت‌وی روی +۲۷ پلتفرم پیام‌رسانی اجرا می‌شود، همه از طریق همان زیرسیستم gateway:

فضاهای کاری مشارکتی و خانهٔ هوشمند

  • Buzz — فضای کاری مبتنی-بر-Nostr شرکت Block برای انسان+ایجنت با سه مسیر یکپارچگی؛ صفحهٔ نمای کلی هر سه را مقایسه می‌کند.
  • Home Assistant — کنترل دستگاه‌های خانهٔ هوشمند با چهار ابزار اختصاصی؛ تول‌ست HA با ست شدن HASS_TOKEN خودکار فعال می‌شود.

پلاگین‌ها و آموزش

  • سیستم پلاگین — گسترش هرمس با ابزارها، هوک‌های چرخهٔ حیات و فرمان‌های CLI بدون دست زدن به هسته.
  • ساخت پلاگین — راهنمای گام‌به‌گام ساخت پلاگین‌های هرمس.
  • پردازش گروهی — اجرای ایجنت روی صدها پرامپت موازی با خروجی trajectory ی ساختاریافتهٔ ShareGPT برای تولید دادهٔ آموزشی یا ارزیابی.
