Nous Portal

Nous Portal گیت‌وی اشتراکِ یکپارچهٔ Nous Research و روش توصیه‌شدهٔ اجرای Hermes Agent است. یک ورود OAuth جایگزین بازی پنج‌دستِ حساب‌های جدا، ‏کلیدهای API و روابط صورتحساب در هر آزمایشگاه مدل، ‏API جستجو، ‏تولیدکننده تصویر و ارائه‌دهنده مرورگری می‌شود که وگرنه باید دستی سیم‌کشی‌شان می‌کردید.

فقط وقت راه‌اندازی یک چیز را دارید؟ همین را راه بیندازید. سریع‌ترین مسیر:

hermes setup --portal

این تک‌فرمان OAuth ی Portal را اجرا، مدل Nous را برای انتخاب می‌گذارد، Nous را به‌عنوان ارائه‌دهندهٔ استنتاج در config.yaml ست و Tool Gateway را روشن می‌کند. بلافاصله بعدش آمادهٔ hermes chat هستید.

هنوز اشتراک ندارید؟ ‏portal.nousresearch.com/manage-subscription — ثبت‌نام کنید و بعد برگردید فرمان بالا را اجرا کنید.

+ بقیهٔ همه+۲۸۰ مدل اضافه — کل frontier ی agentic

زیر کاپوت Portal هر مدل را به مناسب‌ترین backend مسیریابی می‌کند — بعضی مدل‌ها از OpenRouter می‌روند، بعضی از ارائه‌دهنده‌های اختصاصی یا ثانویه و مسیریابی یک مدل مشخص ممکن است به مرور تغییر کند. به هر حال صورتحساب روی اشتراک Nous شماست. وسط نشست با ‎/model‎ بین Claude Sonnet 4.6 برای کد و Gemini 3 Pro برای زمینه بلند سوئیچ کنید — بدون credential جدید، بدون شارژ، بدون خطای ناگهانی موجودی صفر.

📌

چون مسیریابی per-model است و همیشه از OpenRouter نمی‌گذرد، افزونه‌های درخواست مخصوص-OpenRouter ‏(مثل ترجیحات مسیریابی provider، ‏sticky routing با session_id یا cache_control سطح-بالا) بخشی از قرارداد API ی Portal نیستند و بسته به اینکه کدام backend سرویس‌دهنده باشد ممکن است نادیده گرفته شوند.

Nous Tool Gateway

همان اشتراک Tool Gateway را باز می‌کند که فراخوانی ابزارهای Hermes Agent را از طریق زیرساخت مدیریت‌شده توسط Nous عبور می‌دهد. پنج بک‌اند، یک ورود:

ابزارشریککارش
جستجو و استخراج وبFirecrawlجستجوی درجه-ایجنت و استخراج تمام‌صفحه. نه کلید Firecrawl، نه نگهبانی rate limit.
تولید تصویرFALنه مدل زیر یک نقطهٔ پایانی: FLUX 2 Klein 9B، ‏FLUX 2 Pro، ‏Z-Image Turbo، ‏Nano Banana Pro ‏(Gemini 3 Pro Image)، ‏GPT Image 1.5، ‏GPT Image 2، ‏Ideogram V3، ‏Recraft V4 Pro، ‏Qwen Image.
متن-به-گفتارOpenAI TTSTTS باکیفیت بدون کلید جداگانهٔ OpenAI. حالت صوتی را روی پلتفرم‌های پیام‌رسانی فعال می‌کند.
اتوماسیون مرورگر ابریBrowser Useنشست‌های Chromium بدون‌سر برای browser_navigate/click/type/vision. بدون نیاز به حساب Browserbase.
سندباکس ترمینال ابریModalسندباکس‌های ترمینال serverless برای اجرای کد ‏(افزونهٔ اختیاری).

بدون گیت‌وی، وصله‌کردن هرکدام یعنی حساب Firecrawl، حساب FAL، حساب Browser Use، کلید OpenAI و حساب Modal — پنج ثبت‌نام جدا، پنج داشبورد جدا، پنج جریان شارژ جدا. با گیت‌وی همه از یک اشتراک عبور می‌کند.

می‌توانید فقط ابزارهای گیت‌وی خاصی را هم روشن کنید ‏(مثلاً جستجوی وب بدون تولید تصویر) — بخش ترکیب گیت‌وی با بک‌اندهای خودتان پایین را ببینید.

بدون credential در dotfiles تان

چون همه‌چیز از طریق یک نشست Portal احراز‌شده-با-OAuth عبور می‌کند، فایل .env ی انباشته از دوجین کلید API بلندعمر جمع نمی‌کنید. refresh token در ~/.hermes/auth.json تنها credential روی دیسک است و هرمس از آن per-request مقدار JWT های کوتاه‌عمر ضرب می‌کند — بخش مدیریت توکن پایین.

برابری بین-پلتفرمی

ویندوز native راه‌اندازی کلید API ی per-tool را خشن‌ترین لبه‌اش می‌داند — ساخت حساب Firecrawl، حساب FAL، حساب Browser Use و کلید OpenAI از ویندوز پراصطکاک‌ترین بخش رسیدن به ایجنتی کاراست. اشتراک Portal این را هموار می‌کند: یک OAuth مدل و همهٔ ابزارهای گیت‌وی را پوشش می‌دهد تا کاربران ویندوز همان تجربهٔ macOS/Linux را داشته باشند بدون پیکربندی دستی چهار بک‌اند.

۲ یادداشتی دربارهٔ Hermes 4

خانوادهٔ خودِ Nous Research یعنی Hermes 4 ‏(Hermes-4-70B، ‏Hermes-4-405B) از طریق Portal با نرخ‌های شدیداً تخفیف‌خورده در دسترس است. اینها مدل‌های چت هیبریدی-استدلالی frontier اند — قوی در ریاضی، علوم، پیروی از دستور، پایبندی به schema، نقش‌آفرینی و نوشتن بلند.

اما برای مصرف داخل Hermes Agent توصیه نمی‌شوند. ‏Hermes 4 برای چت و استدلال تنظیم شده نه حلقهٔ تندِ فراخوانی-ابزاری که ایجنت به آن تکیه دارد. برای گردش‌کارهای پژوهشی یا از طریق پروکسی اشتراک از سایر ابزارها استفاده‌شان کنید — ولی برای کار ایجنت، یک مدل agentic ی frontier از کاتالوگ بردارید:

/model anthropic/claude-sonnet-4.6     # best general-purpose agentic model
/model openai/gpt-5.5-pro              # strong reasoning + tool calling
/model google/gemini-3-pro-preview     # huge context window
/model deepseek/deepseek-v4-pro        # cost-effective coder

صفحهٔ info ی مدل خود Portal همین هشدار را حمل می‌کند؛ پس این نظر سمت-هرمس نیست — راهنمای رسمی Nous Research است.

۳ راه‌اندازی

نصب تازه — یک فرمان

hermes setup --portal

کل setup را یکجا اجرا می‌کند:

  1. مرورگرتان را برای ورود OAuth به portal.nousresearch.com باز می‌کند
  2. refresh token را در ~/.hermes/auth.json ذخیره می‌کند
  3. یک مدل Nous از فهرست منتخب برای انتخاب می‌گذارد ‏(یا skip کنید تا فعلی بماند)
  4. وقتی مدلی بردارید Nous را به‌عنوان ارائه‌دهندهٔ استنتاج در ~/.hermes/config.yaml ست می‌کند
  5. Tool Gateway را روشن می‌کند ‏(مسیریابی وب، تصویر، TTS، مرورگر)
  6. شما را آمادهٔ hermes chat به ترمینال برمی‌گرداند

اشتراک ندارید؟ اول در ‏manage-subscription ثبت‌نام کنید.

نصب موجود — افزودن Portal کنار سایر ارائه‌دهنده‌ها

هرمس تان از قبل با OpenRouter یا Anthropic یا غیره پیکربندی شده و Portal را کنارشان می‌خواهید:

hermes model
# pick "Nous Portal" from the provider list
# browser opens, sign in, done

ارائه‌دهنده‌های فعلی‌تان پیکربندی می‌مانند. وسط نشست با ‎/model‎ یا بین نشست‌ها با hermes model بین‌شان سوئیچ کنید — Portal یکی از ارائه‌دهنده‌های در دسترس‌تان می‌شود نه تنها گزینه.

راه‌اندازی headless / SSH / راه‌دور

‏OAuth مرورگر می‌خواهد ولی callback ی loopback روی ماشینی اجرا می‌شود که هرمس روی آن اجراست. برای host های راه‌دور بخش OAuth از طریق SSH / Host های راه‌دور را ببینید — همان الگوها برای Portal هم مثل هر ارائه‌دهندهٔ OAuth ی دیگر کار می‌کند ‏(port forwarding با ssh -L).

setup ی پروفایل

اگر از پروفایل‌های هرمس مصرف می‌کنید، refresh token ی Portal خودکار بین همهٔ پروفایل‌ها از طریق مخزن توکن مشترک share می‌شود. روی هر پروفیلی یک بار وارد شوید و بقیه خودکار می‌گیرندش — بدون تکرار جریان OAuth per-profil.

۴ مصرف روزمرهٔ Portal

بازرسی سیم‌کشی فعلی

hermes portal            # log in to Nous Portal + set it up (one-shot onboarding)
hermes portal info       # login status, subscription info, model + gateway routing
hermes portal status     # alias for `portal info`
hermes portal tools      # detailed Tool Gateway catalog with per-tool routing
hermes portal open       # open the subscription management page in your browser

‏hermes portal ‏(بدون زیرفرمان) نام مستعار خوانا-برای-انسانِ hermes auth add nous --type oauth است — واردتان می‌کند، مدل Nous برای انتخاب می‌گذارد، Nous را ارائه‌دهندهٔ استنتاج قرار و opt-in ی Tool Gateway را پیشنهاد می‌دهد ‏(همان hermes setup --portal).

‏hermes portal info نمای کلی می‌دهد: وضعیت Auth، ‏Portal، مدل فعال و جدول Tool Gateway نشان‌دهندهٔ اینکه کدام ابزارها via Nous Portal مسیریابی می‌شوند و Cloud terminal هنوز پیکربندی نشده.

تعویض مدل

داخل نشست:

/model anthropic/claude-sonnet-4.6
/model openai/gpt-5.5-pro
/model google/gemini-3-pro-preview

یا انتخاب‌گر را باز کنید ‏(hermes model بیرون نشست؛ فلش‌ها و Enter داخل ‎/model‎).

ترکیب گیت‌وی با بک‌اندهای خودتان

اگر مثلاً حساب Browserbase دارید و می‌خواهید آن را نگه دارید در حالی که جستجوی وب و تولید تصویر از Nous عبور کند، پشتیبانی می‌شود. با hermes tools بک‌اند هر ابزار را بردارید:

hermes tools
# → Web search       → "Nous Subscription"
# → Image generation → "Nous Subscription"
# → Browser          → "Browserbase"  (your existing key)
# → TTS              → "Nous Subscription"

‏Tool Gateway per-ابزار opt-in است نه همه-یا-هیچ. بک‌اندهای مدیریت‌شده در hermes tools ظاهر می‌شوند چه وارد Nous Portal باشید چه نباشید — اگر قبل از احراز هویت Nous Subscription را بردارید هرمس ورود Portal را inline اجرا می‌کند ‏(ارائه‌دهندهٔ استنتاج‌تان را عوض نمی‌کند و به ابزارهای دیگرتان دست نمی‌زند). ماتریس کامل per-tool در مستندات Tool Gateway.

مدیریت اشتراک

  • وب: ‏portal.nousresearch.com/manage-subscription
  • میان‌بر CLI: ‏hermes portal open ‏(همان صفحه در مرورگر پیش‌فرض)

۵ مرجع پیکربندی و مدیریت توکن

بعد از hermes setup --portal مقدار ~/.hermes/config.yaml چنین می‌شود:

model:
  provider: nous
  default: anthropic/claude-sonnet-4.6     # or whatever model you picked
  base_url: https://inference-api.nousresearch.com/v1

تنظیمات Tool Gateway زیر بخش ابزار مربوطه زندگی می‌کنند — هر دسته یک کلید انتخاب دارد و برداشتن Nous Subscription در hermes tools مقدار nous را می‌نویسد: ‏web.backend، ‏image_gen.provider، ‏tts.provider و ‏browser.cloud_provider همگی nous.

runtime همیشه از انتخاب ذخیره‌شده پیروی می‌کند — کلیدهای مستقیم API مانده در .env وقتی دسته nous است نادیده گرفته می‌شوند و برداشتن ارائه‌دهندهٔ مستقیم ‏(مثل image_gen.provider: fal) بدون کلیدش خطای شفاف می‌دهد نه reroute ی بی‌صدای گیت‌وی. ‏(config های قدیمی فلگ legacy ی use_gateway: true داشتند؛ معادل nous خوانده می‌شود ولی دیگر نوشته نمی‌شود.)

توکن refresh ی OAuth جدا در ~/.hermes/auth.json ذخیره می‌شود ‏(نه در config.yaml — credential و config عمداً جدا نگه داشته می‌شوند).

مدیریت توکن

هرمس به‌ازای هر فراخوانی استنتاج از روی refresh token ی ذخیره‌شدهٔ Portal مقدار JWT ی کوتاه‌عمر ضرب می‌کند به‌جای مصرف کلید API ی بلندعمر. چرخهٔ حیات توکن کاملاً خودکار است — refresh، ‏mint، ‏retry روی 401 گذرا — و شما هرگز نمی‌بینیدش.

اگر Portal توکن refresh را باطل کند ‏(تغییر رمز، ‏revoke دستی، ‏انقضای نشست)، توکن باطل محلیاً قرنطینه می‌شود تا هرمس تکرارش نکند و رشته‌ای از 401 های یکسان نبینید. فراخوانی بعدی پیام واضح «re-authentication required» surface می‌کند. ‏hermes auth add nous را اجرا کنید تا دوباره وارد شوید؛ قرنطینه در اولین ورود موفق پاک می‌شود.

۶ عیب‌یابی

‏hermes portal info می‌گوید «not logged in»

جریان OAuth را کامل نکرده‌اید یا refresh token تان پاک شده. ‏hermes portal را اجرا کنید یا با hermes model دوباره Nous Portal را بردارید.

وسط نشست پیام «re-authentication required» گرفتید

توکن refresh ی Portal باطل شده ‏(تغییر رمز، ‏revoke دستی یا انقضای نشست). ‏hermes auth add nous را اجرا کنید؛ درخواست بعدی credential های جدید را مصرف می‌کند و قرنطینهٔ توکن قدیمی روی ورود موفق خودکار پاک می‌شود.

مدل مشخصی از یک ارائه‌دهنده می‌خواهید که Portal expose نمی‌کند

‏Portal هر مدل را به backend مناسبی مسیریابی می‌کند، پس بیشتر مدل‌های پشتیبانی‌شدهٔ OpenRouter معمولاً موجوده. اگر مدلی در ‎/model‎ ظاهر نشد slug سبک-OpenRouter را مستقیم امتحان کنید ‏(/model anthropic/claude-opus-4.6). واقعاً غایب بود؟ issue باز کنید — کاتالوگ Portal را به هرمس surface می‌کنیم و شکاف‌ها معمولاً یعنی config ی مسیریابی قابل‌به‌روزرسانی.

صورتحساب‌ها روی حسابتان Portal ظاهر نمی‌شوند

اول hermes portal info را چک کنید — اگر ارائه‌دهندهٔ دیگری نشان داد ‏(Model: currently openrouter به‌جای using Nous as inference provider)، config محلی‌تان منحرف شده. ‏hermes model را اجرا، Nous Portal را بردارید و درخواست بعدی از اشتراک‌تان عبور خواهد کرد.

ببینید نیز

  • Tool Gateway — جزئیات کامل هر ابزار گیت‌وی، ‏config ی per-tool و قیمت‌گذاری
  • پروکسی اشتراک — مصرف اشتراک Portal از ابزارهای غیر-هرمس
  • حالت صوتی — گفتگوهای صوتی با OpenAI TTS ی Portal
  • ارائه‌دهندگان AI — کاتالوگ کامل برای مقایسهٔ جایگزین‌ها
  • OAuth از طریق SSH — ورود از host های راه‌دور یا محیط‌های فقط-مرورگر
  • پروفایل‌ها — چند پیکربندی هرمس با یک ورود Portal
